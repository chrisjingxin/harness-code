# 快速开始

当前分支入口为独立桌面工作台。目前提供基础窗口和需显式配置服务的最小演示身份；未接入共享会话、Agent或项目读写。

准备 Node.js >=22.12.0 与 npm（声明版本 11.11.0），在仓库根目录运行：

```sh
npm ci
npm run dev
```

不需要 Bun、Python、uv、Harness 或模型 Key。首次启动 Electron 需要下载目标平台二进制；下载未完成或失败时先核对网络/镜像，不能只凭 npm ci 成功判断桌面可用。

窗口中点击“选择目录”打开原生选择器，选择后只显示路径；取消保留先前选择。“外观”可以选择系统、浅色或深色；窗口缩放按 10% 调整，范围 80%～150%，点击百分比恢复 100%。这些选择不跨应用重启保存。

构建后使用本地页面启动：

```sh
npm run build
npm --workspace @workbench/desktop run preview
```

关闭窗口的临时规则：Windows 退出；macOS 保持应用，可从 Dock 重开或菜单明确退出。后续接入 Runner 后会增加后台/托盘与退出前任务收敛；当前没有运行任务。

更多说明见[独立桌面工作台](独立桌面工作台.md)与[安全与沙箱](安全与沙箱.md)。旧 TUI/Web 专题仍是后续迁移资料，其启动方式不是本分支的新默认路径。当前没有正式签名安装包。

需要演示登录时，先按[仓库服务说明](../../README.md#显式启动-java-数据基础)显式启动Java/MySQL，再用 `WORKBENCH_SERVICE_ORIGIN=http://127.0.0.1:18084 npm run dev` 启动桌面。“演示身份”可选择服务返回的普通账号、查看成员并退出/切换；未配置服务不影响基础窗口使用。重开窗口需重登，网络错误与失败退出按[独立桌面工作台](独立桌面工作台.md#演示身份)处理，不提供假登录或自动数据库启动。
