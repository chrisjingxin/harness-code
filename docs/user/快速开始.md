# 快速开始

当前分支入口为独立三栏桌面工作台，提供演示登录、共享会话历史与实时更新、工作区设备与项目浏览、本机项目登记共享和执行器托管。共享会话保存、排队与同步由显式配置的 Java 服务提供；有权时可只读查看会话原项目的文件和 Git 变更。真实 Agent 与 Git 提交推送由后续任务接入。

准备 Node.js >=22.12.0 与 npm（声明版本 11.11.0），在仓库根目录运行：

```sh
npm ci
npm run dev
```

不需要 Bun、Python、uv、Harness 或模型 Key。首次启动 Electron 需要下载目标平台二进制；下载未完成或失败时先核对网络/镜像，不能只凭 npm ci 成功判断桌面可用。

左侧「设置」可切换系统、浅色或深色外观。窗口缩放按 10 个百分点调整，范围 80%～150%，点击百分比恢复 100%。这些选择只在当前窗口有效。

构建后使用本地页面启动：

```sh
npm run build
npm --workspace @workbench/desktop run preview
```

已启动的本机执行器在关窗后保留。macOS可从Dock重开，Windows可从托盘重开，重新打开后需登录，权限确认后恢复个人草稿、页签和阅读位置。明确“停止”或应用退出会等待原执行器收尾。

更多说明见[独立桌面工作台](独立桌面工作台.md)与[安全与沙箱](安全与沙箱.md)。旧 TUI/Web 专题仍是后续迁移资料，其启动方式不是本分支的新默认路径。当前没有正式签名安装包。

需要演示登录时，先显式启动 Java/MySQL，再用 `WORKBENCH_SERVICE_ORIGIN=http://127.0.0.1:18084 npm run dev` 启动桌面。点击左侧「登录」并选择服务返回的账号，确认工作区后可在「共享会话」选择一条已保存会话，查看作者、内容、执行状态和实时连接状态；也可点击「刷新历史」重新读取。还可展开设备和项目选择会话。未配置服务时窗口仍可打开。重开窗口需重新登录。[仓库服务说明](../../README.md#显式启动-java-数据基础) · [演示身份](独立桌面工作台.md#演示身份)

登录后，从「设置」进入「本机设备」，依次选择目录并登记、共享项目、启动本机执行器。服务连接就绪后可关窗重开，再用原所有者账号停止或退出。[本机项目与执行器](独立桌面工作台.md#本机项目与执行器)

选中共享会话并获得原项目访问许可后，在右侧「文件」展开目录、选择文件预览，点击「在主区域打开」可在中央阅读；切换到「变更」可查看实际 Diff。文件读取需要原设备在线并运行执行器，具体限制见[查看原项目文件与变更](独立桌面工作台.md#查看原项目文件与变更)。

## 可选：把 Harness 交给任意 ACP 客户端

上面的桌面窗口不依赖 Python。若本机已经装好 Harness，任意 ACP 客户端都可以把 `harness acp` 当子进程拉起来，走标准输入输出，不经过浏览器桥。Zed 这类编辑器、以及以后的桌面运行时，用的是同一条协议。

不声明 Harness 私有扩展时，这些事仍然能做：新建和恢复会话、流式回复、工具卡、取消、审批、切模型、用量、压缩、撤销已跟踪文件、改标题、`@文件`。提问、计划确认、目标确认和「拒绝并反馈」还要求客户端声明 `elicitation.form`，并打开 ACP 里尚未标成稳定的那部分协议。不声明时，计划模式不会出现，提问会得到一句「当前客户端不支持提问」。

私有扩展只增加侧栏摘要、命令来源、子代理归属和审批范围这类显示，不决定功能能不能走完。文件树、Git 和设置面板不由 `harness acp` 提供。会话级附加目录和 MCP 的边界见[安全与沙箱](安全与沙箱.md)。
