# 快速开始

当前分支入口为独立三栏桌面工作台，提供演示登录、Team/Workspace 与 Project 协作导航、本机工作目录对话与文件只读预览、跨机器只读与主动正文同步、固定引用/项目任务/团队知识以及看板与轻量通知。协作服务与持久化由显式配置的 Java 服务提供；本机 Agent 通过标准 ACP（Agent Client Protocol）接入，支持 Harness、Pi、Qwen 或自定义 ACP 可执行命令。

准备 Node.js `>=22.12.0` 与 npm（声明版本 `11.11.0`），在仓库根目录运行：

```sh
npm ci
npm run dev
```

不需要安装 Bun、Python、uv、Harness 或模型 Key 即可构建和打开基础桌面。首次启动 Electron 需要下载目标平台二进制；下载未完成或失败时先核对网络或镜像，不能仅凭 `npm ci` 成功判断桌面可用。

左侧「设置」可切换系统、浅色或深色外观。窗口缩放按 10 个百分点调整，范围 `80%～150%`，点击百分比恢复 `100%`。

构建后使用本地页面启动：

```sh
npm run build
npm --workspace @workbench/desktop run preview
```

更多操作见[独立桌面工作台](独立桌面工作台.md)与[安全与沙箱](安全与沙箱.md)。原旧版 CLI、TUI 与独立 `/web` 入口已退役，不再作为本分支入口。当前没有正式签名安装包。

需要演示登录与多人协作能力时，先显式启动 Java/MySQL，再用 `WORKBENCH_SERVICE_ORIGIN=http://127.0.0.1:18084 npm run dev` 启动桌面。未配置服务时基础窗口仍可打开，重开窗口需重新登录。见[仓库服务说明](../../README.md#显式启动-java-数据基础)与[演示身份](独立桌面工作台.md#演示身份)。

## 可选：接入本机 ACP Agent（如 Harness / Pi / Qwen）

通用桌面窗口本身不强制依赖 Python。若本机已安装可用的 ACP Agent（例如 Harness 的 `harness-agent acp`、`pi-acp`、`qwen --acp`），桌面主进程会自动探测；也可通过 `WORKBENCH_ACP_EXECUTABLE` 指定绝对路径，通过 `WORKBENCH_ACP_ARGS_JSON` 指定参数数组。

若把独立的 Harness Agent 交给 Zed 等其他标准 ACP 客户端拉起，同样走 `harness-agent acp` 标准输入输出协议：

- 标准 ACP 能力覆盖新建/恢复会话、流式回复、工具卡、取消、审批、模式/配置切换、用量、压缩、改标题与 `@文件`。
- 提问、计划确认、目标确认和「拒绝并反馈」使用 `elicitation` 表单交互。
- 文件树、Git 浏览与桌面设置面板由桌面宿主自身负责，不依赖 Agent 内核提供；会话级附加目录和 MCP 边界见[安全与沙箱](安全与沙箱.md)。
