# 快速开始

最终用户安装后，在任意项目目录输入 `harness` 进入交互界面。开发者仍可从本仓库源码运行。安装脚本已内置企业 npm 与 PyPI 地址，一般不必再配环境变量。

## 安装

macOS / Linux：

```bash
curl -fsSL https://<企业安装入口>/install.sh | bash
```

Windows 请打开 **PowerShell**（不要用 CMD 或 Git Bash）：

```powershell
irm https://<企业安装入口>/install.ps1 | iex
```

安装器会检测 Bun `1.2.19+`、Python 3.11+ 和 uv，缺了就补齐。已有合格版本会跳过运行时安装。Linux musl 与 Windows ARM 会拒绝并说明原因。

装完后若命令找不到，新开一个终端，或把 `~/.bun/bin` 与 `~/.local/bin`（Windows 为 `%USERPROFILE%\.bun\bin` 与 `%USERPROFILE%\.local\bin`）加入 PATH。

已有 Bun 和 uv 时的手动安装：

```bash
bun install -g @za38/cli --registry <企业 npm>
uv tool install za38-agent --index <企业 PyPI>
```

卸载：

```bash
bun remove -g @za38/cli
uv tool uninstall za38-agent
```

## 配置并启动

安装器在没有 `~/.harness/config.toml` 时会写入示例。已有文件不会覆盖。设置模板声明的 API Key 环境变量后，进入项目目录启动：

```bash
export HARNESS_API_KEY='你的企业网关密钥'
harness
```

从源码开发时，在仓库根目录同步依赖并复制模板：

```bash
cd packages/agent && uv sync --extra test && cd ../..
mkdir -p ~/.harness
cp docs/user/examples/config.toml ~/.harness/config.toml
export HARNESS_API_KEY='你的企业网关密钥'
bun run dev
```

环境变量是推荐的密钥来源。如果本机启动流程无法注入环境变量，可在用户配置的模型 Profile 内增加降级值：

```toml
api_key_env = "HARNESS_API_KEY"
api_key = "你的企业网关密钥"
```

Harness 首次加载含字面量密钥的用户级配置时会自动将文件权限收紧为 `600`。非空 `HARNESS_API_KEY` 始终优先；字面量密钥不能出现在 `--config` 指定的文件或项目配置中。

交互启动后直接输入任务即可。首次发送后进入 thread 视图；输入 `/` 可打开已实现的命令菜单。

项目 Skill 放在 `<workspace>/.harness/skills/<name>/SKILL.md` 后会在下一次 Harness 启动时自动发现。可用以下命令检查和管理：

```bash
harness skills list
harness skills inspect project/review
```

## 无头模式

适合脚本或本地验证：

```bash
harness -n --message "总结这个仓库"
harness -n --message "列出风险" --json
bun run dev -- --non-interactive --message "总结这个仓库"
```

使用 `--cwd <路径>` 指定 project。使用无参数的 `--resume` 打开当前 project 的 thread 选择器；不要附带 `thread_id`，它由选择器内部处理。详细行为、数据位置和清理方式见 [交互使用](交互使用.md#恢复-thread)。

应用内自动更新不是本版本范围；升级请重新运行安装命令或手动 `bun install -g` / `uv tool install`。详细安装失败处理见 [故障排查](故障排查.md)。

## OpenTUI 依赖

源码运行依赖企业源提供的 `@opentui/core` / `@opentui/react` `0.4.3`。企业引入 Core 时还必须镜像其当前平台对应的 `@opentui/core-<platform>-<arch>` optional package；安装后由 Bun 按运行平台选择，不需要本地 Zig 或源码快照。
