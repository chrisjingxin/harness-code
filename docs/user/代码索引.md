# 代码索引

代码索引是默认关闭的实验能力。开启后，Harness 会为当前工作区建立本地 `.harness-index/`，后续对话优先用只读工具 `codebase_explore` 定位符号、文件和调用关系。索引找不到、暂时不可用或语言未覆盖时，仍使用原来的搜索和读取；编辑前必须再用 `read_file` 取得当前 Snapshot。

配置和发布状态仍属实验性，但界面只显示“代码索引”，没有实验徽标。本功能不承诺固定的速度、token 或正确率提升。

## 开启

在用户级 `~/.harness/config.toml` 写入：

```toml
[experimental.code_index]
enabled = true
```

保存后必须重启 Harness / AgentHost。缺少该区段、写 `false` 或配置加载失败都不会启动索引。关闭并重启后保留已有数据，但不再查询或同步；删除必须用 `/code-index remove` 并确认。

Slash 菜单在关闭时不推荐 `/code-index`。手工输入会提示上述开启路径，不会把命令发给模型，也不会自动改配置。

## 命令

TUI 和 Web 共用同一套命令，操作的是当前工作区的同一份索引。

| 命令 | 行为 |
| --- | --- |
| `/code-index` | 没有索引时首次建立；健康索引存在时增量更新 |
| `/code-index status` | 查看根目录名、版本、统计、当前任务、查询和自动同步状态 |
| `/code-index rebuild` | 关闭查询后全量重建 |
| `/code-index cancel` | 取消进行中的建图任务；中断不是成功 |
| `/code-index remove` | 先确认，再删除索引和本功能写入的本地 ignore |

未知参数只显示用法。索引不完整时不要用默认 `/code-index` 做增量修复，应执行 `rebuild`。正在使用索引的对话进行时，建立/同步/重建/删除会被拒绝，并提示等待该对话结束。建图期间仍可继续普通对话，新对话暂时没有 `codebase_explore`。

`/code-index status` 在模型 Run 或建图任务期间都可以用。进度只显示实际阶段和数量；没有可信总数时不显示百分比。

## 本地数据

唯一数据目录是当前工作区下的 `.harness-index/`。Harness 会写入目录内 ignore，并在 Git 工作区的 `.git/info/exclude` 加入带标识的精确规则，不修改项目根 `.gitignore`，不安装 Git hooks。

`remove` 只删除 `.harness-index/` 和上述本功能标识块，不会删除 `.harness/` 或其他 ignore。

## 失败恢复

取消、超时、异常退出或完成后状态对不上，都会留下不完整/失败事实，并停止查询。此时 `/code-index status` 会给出重建建议。重启看到未完成标记时只报告状态，不会自动删库。

自动同步不可用时，状态会说明改用 `/code-index` 手工更新。索引结果不是 Snapshot：任何编辑仍须先 `read_file`。

## 运行时不可用

匹配平台的依赖缺失、版本不一致或不支持的系统/架构时，Harness 其他对话和文件工具仍可用。`/code-index status` 会给出可操作的恢复说明，例如安装匹配依赖后重启。Linux musl 与 Windows ARM 不在当前验收范围。
