# 安全与沙箱

本页说明当前桌面身份、项目共享与执行器托管的权限。旧Harness的工具审批与执行沙箱资料供后续ACP和项目服务迁移参考。

React 页面不直接访问 Node、文件系统或 shell。Electron 通过内容隔离、sandbox 和具名 preload 接口提供目录选择与窗口设置；原生请求须来自可信的当前主窗口，并经过参数检查。禁止任意导航、新窗口、通用 IPC 转发与任意代码执行端口。

登录后在「设置」的「本机设备」中选择目录并登记。宿主将原生选择器确认的目录映射为本机项目，明确共享后发布项目标识和展示信息。真实路径只保存在原设备受限账本中。左侧设备与项目列表按当前账号及工作区读取。

主题与窗口缩放只作用于当前应用运行；缩放由主进程控制在80%～150%。演示身份使用显式配置的协作服务，执行器由用户明确启动。关窗保留原执行器，明确停止或退出等待实际收尾，异常中断的未知结果保留在原账本中。

源码安装使用唯一根 npm 锁，旧 Python/CLI/OpenTUI 不在新安装图。Electron 原生二进制需从官方源或受信任镜像取得。当前没有正式签名安装包或完整双平台验收结论。

## Harness ACP 的会话目录和 MCP

这一节只在本机已经用 `harness acp` 或 `harness web` 接上 Agent 时适用。上面的桌面窗口目前没有这项能力。

客户端在新建、打开或恢复会话时可以带两类附加材料。它们只对这一个会话生效，不写进 `~/.harness/config.toml`，会话列表里也不保存。会话关闭或连接断开后撤销。

**附加目录**必须每一项都是绝对路径、真实存在、并且是目录。文件系统根、家目录和系统目录不会被信任。有一项不合格，整个请求被拒绝，响应里带回这一项的路径，会话不会建出来。合格的目录只让这个会话的运行去读，不扩大其他会话的范围。

**会话 MCP**可以是本机命令（stdio）或 HTTP。SSE 和 ACP 传输、字段不合法、以及与已有服务器同名的项会被跳过。诊断里只记服务器名字、传输方式和原因，不记命令、环境变量和请求头。某台服务器连不上时，会话仍然建出来，失败记在诊断里，不替换全局已经配好的 MCP。

演示身份通过独立 `window.collaboration` 具名接口提供，沿用主窗口/顶层frame/固定页面来源校验；没有通用fetch或URL/header参数。Cookie和CSRF仅留主进程内存，禁重定向和Cookie Domain扩大，远程服务使用受信任HTTPS；页面不能读取凭据。退出/切换开始即取消旧读取并隔离会话，迟到响应不能写入新账号；断库503或网络错误不会冒充确认退出。失败退出只确认本机清理，远端未确认会明确提示；关窗同样只丢弃本机会话。演示账号不证明真实人员身份，不建立岗位/角色/密码系统，也不重绑设备身份或Runner。

共享会话列表、详情、历史和实时订阅通过独立具名接口使用同一主进程身份，服务确认工作区和会话的访问范围；页面不能指定服务地址或凭据。实时事件在主进程有界暂存，页面连续应用后才确认，交付中断时从已应用位置补历史。退出、切换或关窗释放订阅；确认失去访问权后清理对应的历史缓存。个人草稿、阅读位置和项目视图选择保存在本机应用数据目录，按服务域、账号及工作区、会话或原项目隔离。关窗和退出账号前等待最新修改保存；保存失败会提示重试。恢复前重新确认会话或原项目权限；文件正文、Diff、共享历史及凭据不写入个人记录。

原项目的目录、候选、文件预览、Git 状态和 Diff 通过具名只读接口进入主进程，由协作服务根据当前会话确定原设备与项目，并分别确认会话和项目访问许可；页面不能指定原设备路径或凭据。当前只开放服务端明确绑定的纯本地演示项目，托管仓库的真实身份和读权尚未接入。请求和结果经过约定格式校验，旧身份或旧会话的迟到结果不会显示。确认失去项目访问权后清除已读取的文件和 Diff；临时断线时保留的内容会标为非实时。Git 提交和推送尚未接入，查看权限不代表写入权限。

设备操作通过具名 `window.devices` 接口进入宿主，当前设备所有者才能登记、共享和停止本机执行器。设备凭据、登记意图与待确认执行结果统一保存在受限 `runner.sqlite` 中，经私有utility进程端口访问。云端只保存凭据摘要，Runner以独立设备身份连接固定服务；用户退出后，原设备身份继续有效。真实Agent端口接入前，界面按实际能力显示未接入状态。
