# 安全与沙箱

本页说明桌面身份、Project 共享、本机目录阅读和 Agent 执行的权限。首版按每人一台设备设计，其他成员的会话用于只读了解进度，协作材料通过固定引用和 Task 带入自己的会话。

React 页面不直接访问 Node、文件系统或 shell。Electron 通过内容隔离、sandbox 和具名 preload 接口提供目录选择与窗口设置；原生请求须来自可信的当前主窗口，并经过参数检查。禁止任意导航、新窗口、通用 IPC 转发与任意代码执行端口。

登录后选择团队与 Project，在新会话准备页通过系统选择器选定本机工作目录，普通非 Git 目录同样可用。会话的目录绑定按账号、团队、Project 和会话保存在本机，真实路径不进入共享历史。左侧按成员展示会话，本人会话的执行还需有效本机目录授权与宿主绑定。

主题与窗口缩放只作用于当前应用运行；缩放由主进程控制在80%～150%。演示身份使用显式配置的协作服务，执行器由用户明确启动。关窗保留原执行器，明确停止或退出等待实际收尾，异常中断的未知结果保留在原账本中。

源码安装使用唯一根 npm 锁，旧 Python/CLI/OpenTUI 不在新安装图。Electron 原生二进制需从官方源或受信任镜像取得。当前没有正式签名安装包或完整双平台验收结论。

## Harness ACP 的会话目录和 MCP

本机桌面已通过通用 ACP 宿主接入 Agent。下面介绍 Harness ACP 的会话级附加目录和 MCP 规则，具体入口按 Agent 实际公开能力提供。

客户端在新建、打开或恢复会话时可以带两类附加材料。它们只对这一个会话生效，不写进 `~/.harness/config.toml`，会话列表里也不保存。会话关闭或连接断开后撤销。

**附加目录**必须每一项都是绝对路径、真实存在、并且是目录。文件系统根、家目录和系统目录不会被信任。有一项不合格，整个请求被拒绝，响应里带回这一项的路径，会话不会建出来。合格的目录只让这个会话的运行去读，不扩大其他会话的范围。

**会话 MCP**可以是本机命令（stdio）或 HTTP。SSE 和 ACP 传输、字段不合法、以及与已有服务器同名的项会被跳过。诊断里只记服务器名字、传输方式和原因，不记命令、环境变量和请求头。某台服务器连不上时，会话仍然建出来，失败记在诊断里，不替换全局已经配好的 MCP。

演示身份通过独立 `window.collaboration` 具名接口提供，沿用主窗口/顶层frame/固定页面来源校验；没有通用fetch或URL/header参数。Cookie和CSRF仅留主进程内存，禁重定向和Cookie Domain扩大，远程服务使用受信任HTTPS；页面不能读取凭据。退出/切换开始即取消旧读取并隔离会话，迟到响应不能写入新账号；断库503或网络错误不会冒充确认退出。失败退出只确认本机清理，远端未确认会明确提示；关窗同样只丢弃本机会话。演示账号不证明真实人员身份，不建立岗位/角色/密码系统，本机执行按当前账号与已绑定会话管理。

项目列表、会话简报、正文与协作动作通过具名接口使用同一主进程身份，服务核对团队、Project 和成员权限。轻量通知只刷新简报、任务等元数据，其他成员的会话正文由查看者主动同步。退出、切换或关窗释放监听，确认失去访问权后清理对应缓存。个人草稿、阅读位置和文件页签按服务域、账号、Project 与会话隔离，恢复前核对当前访问范围。共享正文及凭据不写入个人视图记录。

本机目录、候选、文件预览、Git 状态和 Diff 通过只读接口进入主进程。宿主保存授权目录与会话绑定，通用 project-service 核对路径、链接、根身份与读取版本后返回有界结果。其他成员的会话展示云端已有的只读材料。切换账号或重新选择目录后，旧请求结果不会写入当前页面。产品 Git 提交与推送入口本期暂缓。

本机 Agent 的发送、取消与审批通过具名宿主接口核对当前账号、Project、会话和目录绑定。定稿内容按当前用户身份异步上传到协作服务，其他成员可以读取简报、主动同步正文和创建 Task。被指派人接收 Task 后，在自己的会话中明确开始执行。
