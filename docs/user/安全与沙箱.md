# 安全与沙箱

本页说明独立桌面基础阶段的权限。旧 Harness 的工具审批与执行沙箱资料仍可作为后续迁移参考，当前桌面没有 Agent 执行功能。

React 页面不直接访问 Node、文件系统或 shell。Electron 通过内容隔离、sandbox 和具名 preload 接口提供目录选择与窗口设置；原生请求须来自可信的当前主窗口，并经过参数检查。禁止任意导航、新窗口、通用 IPC 转发与任意代码执行端口。

“选择目录”仅在原生选择器中单选一个目录，返回路径供当前页面显示；不读取文件、不上传、不保存路径，不构成后续项目文件授权。取消保留先前选择。未来文件/Git 服务需另外建立项目与访问边界。

主题与窗口缩放只作用于当前应用运行；缩放由主进程控制在 80%～150%。基础能力不要求云端或模型密钥；可选的演示身份仅通过显式配置的协作服务连接。Runner 未启动，关窗不会假装已有后台任务完成；真实后台执行与退出收敛由后续阶段实现。

源码安装使用唯一根 npm 锁，旧 Python/CLI/OpenTUI 不在新安装图。Electron 原生二进制需从官方源或受信任镜像取得。当前没有正式签名安装包或完整双平台验收结论。

演示身份通过独立 `window.collaboration` 具名接口提供，沿用主窗口/顶层frame/固定页面来源校验；没有通用fetch或URL/header参数。Cookie和CSRF仅留主进程内存，禁重定向和Cookie Domain扩大，远程服务使用受信任HTTPS；页面不能读取凭据。退出/切换开始即取消旧读取并隔离会话，迟到响应不能写入新账号；断库503或网络错误不会冒充确认退出。失败退出只确认本机清理，远端未确认会明确提示；关窗同样只丢弃本机会话。演示账号不证明真实人员身份，不建立岗位/角色/密码系统，也不重绑设备身份或Runner。
