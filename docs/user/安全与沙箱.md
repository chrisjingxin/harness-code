# 安全与沙箱

本页说明当前独立桌面工作台的身份、目录、文件只读及本机 ACP Agent 接入权限边界。

React 渲染页面不直接访问 Node、文件系统或 Shell。Electron 通过 `contextIsolation`、`sandbox` 和具名 Preload 接口提供窗口控制、原生目录选择、协作请求与受控本机执行；主进程校验可信主窗口与顶层 Frame 来源，并逐项校验参数类型，禁止任意导航、新窗口、通用 IPC 转发与任意代码执行端口。

主题与窗口缩放只作用于当前应用运行；缩放由主进程控制在 `80%～150%`。演示身份使用显式配置的 Java 协作服务。源码安装使用唯一根 npm 锁与 4 个新平台 workspace，不依赖 Bun、OpenTUI 或 Python；Electron 原生二进制需从官方源或受信任镜像取得。当前没有正式签名安装包或完整双平台验收结论。

## 协作身份与本地缓存边界

演示身份通过独立 `window.collaboration` 具名接口提供，沿用主窗口、顶层 Frame 与固定页面来源校验；不提供通用 `fetch` 或任意 URL/Header 参数。Cookie 和 CSRF 仅留主进程内存，禁止重定向和 Cookie Domain 扩大，远程服务使用受信任 HTTPS；渲染页面不能读取凭据。退出或账号切换开始即递增代次、取消旧读取并隔离会话，迟到响应不会写入新账号；断库或网络错误不会冒充确认退出。关窗会释放本机身份和监听，重开需重新登录。

项目会话列表、简报、主动同步历史和轻量通知通过具名端口使用同一主进程身份，服务端确认工作区与项目成员访问范围。轻量 SSE 仅推送简报或任务元数据通知，不自动下载正文或触发执行。首版按每人一台设备组织，其他成员的会话统一只读，不提供跨机器实时文件/Git 访问；本机按当前用户登录身份上传定稿内容，其他成员按需读取。

个人视图偏好、草稿、已同步正文缓存与工作区页签状态保存在本机应用数据目录，按服务域、账号、团队与项目/会话隔离；`PersonalStore` 对单条会话同步缓存设 1 MiB 容量上限。关窗与退出账号前等待最新修改落盘，恢复前重新校验权限，服务凭据不写入个人记录。

## 本机目录与只读文件浏览边界

本机会话工作目录必须由用户通过系统原生目录选择器显式选定，主进程校验路径真实存在并拒绝符号链接逃逸、`..` 越界、空字节及反斜杠逃逸路径。支持普通非 Git 目录平稳浏览与 `@` 候选联想；Git 状态与 Diff 仅作本机只读查看，跨端与本机 Git 提交/推送入口已暂缓。切换账号或重新选择目录后，旧请求结果不会写入当前页面。

## 本机 ACP Agent 执行与可选 Harness 边界

主进程按注册表探测受支持的本机 ACP Agent（`harness` / `pi` / `qwen`）或由启动环境变量 `WORKBENCH_ACP_EXECUTABLE`（要求绝对路径）与 `WORKBENCH_ACP_ARGS_JSON`（要求字符串数组）指定的自定义命令；渲染页面不能指定或篡改执行命令。工作区 `@file` 引用经 `realpath` 沙箱核验后才会转为 ACP `resource_link` 附件。

当本机接入可选 Harness Python ACP Agent（`harness-agent acp`）时，客户端在新建或恢复会话中附加的目录与会话级 MCP 还遵守以下限制：

- **附加目录**：必须每一项都是绝对路径、真实存在且是目录；文件系统根、家目录和系统目录不会被信任，任一项不合格整次请求 fail closed（失败关闭）并拒绝建会。合格目录仅允许该会话只读，不扩大其他会话范围，也不写入 `~/.harness/config.toml`。
- **会话 MCP**：仅支持本机 `stdio` 或受控 HTTP；SSE 和 ACP 传输、字段不合法以及与已有服务器同名的项会被跳过。诊断日志仅记录服务器名、传输方式与原因，不记录命令、环境变量或请求头。
