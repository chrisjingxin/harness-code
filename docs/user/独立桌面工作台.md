# 独立桌面工作台

研发可按[仓库启动说明](../../README.md#显式启动-java-数据基础)显式构建、迁移、初始化和启动Java协作服务。桌面已提供演示身份、本机设备及共享项目入口；服务端支持共享会话、排队与实时历史。普通基础窗口可独立启动。

从仓库根目录 `npm ci` 后运行 `npm run dev`。已经构建时也可 `npm --workspace @workbench/desktop run preview`，无需旧 Web server 或网关。

| 操作 | 当前行为 |
| --- | --- |
| 选择目录 | 原生单选目录，显示绝对路径，不读取/上传内容，不创建项目 |
| 取消选择 | 首次仍显示尚未选择；已有路径保留 |
| 外观 | 系统、浅色、深色，当前窗口即时应用 |
| 窗口缩放 | 80%～150%，每次 10 个百分点；点百分比恢复 100% |
| 重新启动 | 主题恢复跟随系统、缩放恢复 100%，不恢复目录 |

基础窗口的“选择目录”用于显示路径。登录后“本机设备”中的“选择目录并登记”会把明确选中的目录登记为本机项目，可继续共享与启动执行器。完整对话界面、Trace、ACP及文件/Git功能按后续任务接入。

macOS 使用原生红黄绿按钮，关窗后可从 Dock 重开，菜单可明确退出。已启动的执行器保留在后台，重新打开沿用原实例。Windows有后台执行器时可从托盘重新打开或退出，实际Windows运行与安装包仍需对应平台验收。

界面设置失败时显示简明错误，可以重试。Electron 二进制下载失败时核对网络、镜像或缓存；构建成功不能替代原生运行验证。安全边界见[安全与沙箱](安全与沙箱.md)。

## 演示身份

需要登录时，由开发者先显式启动协作服务和数据库，并在启动桌面前配置唯一的 `WORKBENCH_SERVICE_ORIGIN`。本机研发命令见[仓库说明](../../README.md#显式启动-java-数据基础)；没有配置时基础窗口仍可使用，身份区域如实显示不可用。

1. 在“演示账号”选择服务返回的user01、user02或user03，点击“演示登录”。这些账号不验证真实人员身份，没有密码或岗位角色。
2. 登录后显示当前用户、工作区和真实成员；“刷新成员”会重新查询服务。没有成员关系时显示“当前账号未加入工作区”。
3. 点击“退出 / 切换账号”，旧成员立即隐藏。退出后可重新选择其他账号；不会沿用上一账号的请求或结果。

断库或断网时暂停业务显示，只保留上次身份提示；恢复后点击“重试连接”重新确认。服务重启或会话失效需要重登。退出失败仍清理本机凭据，并明确“本机已退出，服务端退出未确认”；远端会话可能直到超时前仍存在。关闭窗口会释放本机身份和监听，重开需重新登录。

Cookie和CSRF只保存在主进程内存。用户退出或切换账号时，已启动执行器仍使用原设备身份；只有该设备所有者可以管理它。基础身份结果见[HC-194 Task](../developer/task/HC-194-协作契约与云端基础.md)。

## 本机项目与执行器

1. 登录设备所有者账号，在“本机设备”点击“选择目录并登记”，通过系统目录选择器明确选择项目。项目名称可选。
2. 点击“共享项目”，等待服务确认共享。工作区成员可以看到项目展示信息，本机路径和设备凭据保存在原设备。
3. 点击“启动本机执行器”，观察“正在恢复连接”到“服务已就绪”。当前默认Agent配置显示未接入，真实执行能力由后续ACP任务提供。
4. 关窗后可重新打开并登录。原执行器继续运行，切换其他账号后设备所有者仍保持原值。
5. 点击“撤回共享”结束项目共享，点击“停止”结束本机执行器。应用菜单或托盘中的“退出”会等待执行器退出，停止未确认时保留提示。

共享会话服务可以保存排队输入并同步历史，完整聊天入口将在工作台装配阶段接入。本轮已通过macOS原生登记、共享、关窗重开、账号隔离与停止退出冒烟，Windows、目标TDSQL、真实ACP及文件/Git留整体验证。证据见[HC-195 Task](../developer/task/HC-195-共享会话与实时同步.md)与[HC-196 Task](../developer/task/HC-196-设备接入与本机执行.md)。
