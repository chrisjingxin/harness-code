# 独立桌面工作台

HC-194 已提供独立的 Java 数据基础，研发可按[仓库启动说明](../../README.md#显式启动-java-数据基础)显式构建、迁移、初始化和探测服务。最小演示身份已接入；共享会话仍未接入，普通桌面启动不要求Java或数据库。

从仓库根目录 `npm ci` 后运行 `npm run dev`。已经构建时也可 `npm --workspace @workbench/desktop run preview`，无需旧 Web server 或网关。

| 操作 | 当前行为 |
| --- | --- |
| 选择目录 | 原生单选目录，显示绝对路径，不读取/上传内容，不创建项目 |
| 取消选择 | 首次仍显示尚未选择；已有路径保留 |
| 外观 | 系统、浅色、深色，当前窗口即时应用 |
| 窗口缩放 | 80%～150%，每次 10 个百分点；点百分比恢复 100% |
| 重新启动 | 主题恢复跟随系统、缩放恢复 100%，不恢复目录 |

基础页面没有聊天、Trace 或示例协作数据。桌面已提供最小演示身份，尚未接入共享业务、设备、ACP 和文件/Git；选择路径不是文件读写授权。Runner 工程此阶段不会随窗口启动。

macOS 使用原生红黄绿按钮；关窗后可从 Dock 重开，菜单可明确退出。Windows 保留系统窗口控制，关掉最后窗口退出；Windows 实际运行与安装包仍需对应平台验收。后续有本机任务时将接入后台/托盘语义。

界面设置失败时显示简明错误，可以重试。Electron 二进制下载失败时核对网络、镜像或缓存；构建成功不能替代原生运行验证。安全边界见[安全与沙箱](安全与沙箱.md)。

## 演示身份

需要登录时，由开发者先显式启动协作服务和数据库，并在启动桌面前配置唯一的 `WORKBENCH_SERVICE_ORIGIN`。本机研发命令见[仓库说明](../../README.md#显式启动-java-数据基础)；没有配置时基础窗口仍可使用，身份区域如实显示不可用。

1. 在“演示账号”选择服务返回的user01、user02或user03，点击“演示登录”。这些账号不验证真实人员身份，没有密码或岗位角色。
2. 登录后显示当前用户、工作区和真实成员；“刷新成员”会重新查询服务。没有成员关系时显示“当前账号未加入工作区”。
3. 点击“退出 / 切换账号”，旧成员立即隐藏。退出后可重新选择其他账号；不会沿用上一账号的请求或结果。

断库或断网时暂停业务显示，只保留上次身份提示；恢复后点击“重试连接”重新确认。服务重启或会话失效需要重登。退出失败仍清理本机凭据，并明确“本机已退出，服务端退出未确认”；远端会话可能直到超时前仍存在。关闭窗口会释放本机身份和监听，重开需重新登录。

Cookie和CSRF只保存在主进程内存，不交给页面、不写磁盘或日志。用户退出不影响未来设备身份或Runner；当前没有设备连接。上述已在本机真实Electron窗口验证，Windows、目标TDSQL与完整回归仍待后续；证据见[HC-194 Task](../developer/task/HC-194-协作契约与云端基础.md)。
