# 独立桌面工作台

正式窗口左侧提供协作导航，登录后可以选择工作区、展开真实设备和项目，并读取有权查看的共享会话历史。中央对话和右侧文件/变更显示各自当前的能力状态。研发可显式构建、迁移、初始化和启动 Java 协作服务。[仓库启动说明](../../README.md#显式启动-java-数据基础)

从仓库根目录 `npm ci` 后运行 `npm run dev`。已经构建时也可 `npm --workspace @workbench/desktop run preview`，无需旧 Web server 或网关。

| 操作 | 当前行为 |
| --- | --- |
| 设备与项目 | 在左侧选工作区、展开当前账号的设备读取项目。搜索过滤当前已加载内容 |
| 共享会话 | 从共享列表或原设备/项目下选择会话，查看已保存的消息、执行状态和当前会话的实时更新 |
| 原项目文件与变更 | 经服务确认有权访问且原设备在线时，只读查看文件树、文件预览、中央文件页签与 Git Diff |
| 本机设备 | 在「设置」中登记、共享并管理当前工作区的本机设备 |
| 外观 | 跟随系统、浅色或深色；页面与原生窗口背景同步切换 |
| 窗口缩放 | 80%～150%，每次 10 个百分点；点百分比恢复 100% |
| 重新打开窗口 | 重新登录。外观恢复跟随系统，缩放恢复 100% |

「设置」包含窗口外观、演示身份和本机设备。导航选择、展开状态和栏位偏好按账号与工作区保存在本机应用数据中。草稿和阅读位置按账号、工作区及会话保存；项目页签、阅读位置和 Git 选择按账号、工作区及原设备项目保存。关窗后重新登录并确认对应访问权限，才能恢复这些个人选择。Trace、ACP 和 Git 提交推送按后续任务接入。

## 查看共享历史

登录并选择工作区后，在「共享会话」或原设备与项目下选择一条会话。中央显示其已保存的作者、消息与最近执行状态；窗口顶部显示原设备和项目。无法读取名称时显示原目标标识。列表分批加载时可继续加载，搜索只覆盖已加载内容。历史读取和项目文件访问分别由服务确认权限。

选中会话后，窗口显示实时连接状态，并自动接收服务已保存的更新；阅读较早消息时，新输出不会改变当前位置，可点击提示跳到最新。断线时提示重连，交付中断后先补历史再恢复连接。也可点击「刷新历史」重新读取。输入框可保留个人草稿，重新登录并确认会话权限后恢复；发送和取消尚未接入。[HC-202 Task](../developer/task/HC-202-桌面工作台视图迁移.md)

## 查看原项目文件与变更

在正式窗口选中一条有权访问的共享会话。当前服务只支持明确绑定来源的纯本地演示项目；项目共享本身不会自动开放读取。会话关联的原项目已共享、服务确认访问许可且原设备的执行器在线时：

1. 在右侧「文件」展开目录，选择文件后在右侧预览。点击「在主区域打开」可在中央文件页签阅读；点击页签旁的关闭按钮返回对话。文件打开期间，对话仍接收实时更新，草稿保留。
2. 在对话输入框输入 `@` 和文件名，可查看原项目的文件候选，并选择在右侧预览或中央打开。实际消息发送尚未接入。
3. 在右侧「变更」查看 Git 状态，选择文件查看 Diff。可保留个人勾选和提交说明；提交和推送当前不可用。

同一项目的不同会话共用项目页签、阅读位置和 Git 选择。切换会话时重新确认项目访问许可；项目停止共享或确认无权后，已读取的文件和 Diff 会被清除。原设备离线或连接异常时界面会说明原因，若展示缓存会标为非实时；恢复连接后可刷新。会话历史权限与项目文件权限分别确认。恢复时需要重新确认原项目访问权限；设备不在线时可在连接恢复后重试。托管仓库的真实身份与读权接入和完整双平台验证留待后续阶段。

## 协作导航与三栏预览

在仓库根目录运行以下命令，构建并打开导航布局预览。

```sh
npm --workspace @workbench/desktop run preview:navigation
```

在左侧展开示例设备和项目，再选择会话。中央会显示对话，右侧会显示对应项目的文件与变更入口。左侧「设置」中的「外观」可以选择跟随系统、浅色或深色。预览使用固定示例数据。[HC-208 Task](../developer/task/HC-208-协作导航与桌面布局.md)

## 独立对话预览

在仓库根目录运行以下命令，构建并打开对话预览。

```sh
npm --workspace @workbench/desktop run preview:conversation
```

可以查看用户和 Agent 消息、展开工具输出、试用文件提及、审批和问答。窗口使用固定示例数据，发送、文件打开和审批只记录界面动作。正式工作台的数据与布局由 HC-202 装配。[HC-206 Task](../developer/task/HC-206-既有对话视图复用.md)

## 独立文件与变更预览

研发可从仓库根目录构建并打开已迁出的文件/Git 视图：

```sh
npm --workspace @workbench/desktop run build:project-preview
npm --workspace @workbench/desktop run preview:project
```

在右侧“文件”中展开目录、阅读源码，或打开中央文件标签页并分别关闭；在“变更”中查看 Diff、勾选或全选文件、填写提交说明。预览提供可切换的示例结果，包括提交成功后推送失败，以及只重试推送的交互。

这是独立的受控界面预览，文件、提交与推送均使用示例数据，不读取项目或执行 Git，也不需要云端服务或 ACP。正式工作台的只读文件和变更数据使用单独的真实服务链路。运行预览使用单独的临时用户目录，退出后清理；原有设计稿和旧 Web 来源仍保留。阶段证据与待验项见 [HC-207 Task](../developer/task/HC-207-文件与变更视图复用.md)。

## 基础窗口运行说明

macOS 使用原生红黄绿按钮，关窗后可从 Dock 重开，菜单可明确退出。已启动的执行器保留在后台，重新打开沿用原实例。Windows 可从托盘重新打开或退出，实际 Windows 运行与安装包仍需对应平台验收。

界面设置失败时显示简明错误，可以重试。Electron 二进制下载失败时核对网络、镜像或缓存；构建成功不能替代原生运行验证。安全边界见[安全与沙箱](安全与沙箱.md)。

## 演示身份

需要登录时，由开发者先显式启动协作服务和数据库，并在启动桌面前配置 `WORKBENCH_SERVICE_ORIGIN`。没有配置时窗口仍可使用，身份区域显示连接提示。[仓库说明](../../README.md#显式启动-java-数据基础)

1. 点击导航的「登录」，在「演示账号」选择服务返回的 user01、user02 或 user03，点击「演示登录」。这些账号用于演示普通用户身份。
2. 只有一个工作区时直接进入，有多个时从左侧选择。在「设置 → 演示身份」查看当前工作区成员，「刷新成员」会重新查询服务。
3. 点击“退出 / 切换账号”，旧成员立即隐藏。退出后可重新选择其他账号；不会沿用上一账号的请求或结果。

断库或断网时暂停业务显示，只保留上次身份提示；恢复后点击“重试连接”重新确认。服务重启或会话失效需要重登。退出失败仍清理本机凭据，并明确“本机已退出，服务端退出未确认”；远端会话可能直到超时前仍存在。关闭窗口会释放本机身份和监听，重开需重新登录。

Cookie和CSRF只保存在主进程内存。用户退出或切换账号时，已启动执行器仍使用原设备身份；只有该设备所有者可以管理它。基础身份结果见[HC-194 Task](../developer/task/HC-194-协作契约与云端基础.md)。

## 本机项目与执行器

1. 登录设备所有者账号并选择工作区。在「设置 → 本机设备」点击「选择目录并登记」，通过系统目录选择器选定项目。项目名称可选。
2. 点击“共享项目”，等待服务确认共享。工作区成员可以看到项目展示信息，本机路径和设备凭据保存在原设备。
3. 点击“启动本机执行器”，观察“正在恢复连接”到“服务已就绪”。当前默认Agent配置显示未接入，真实执行能力由后续ACP任务提供。
4. 关窗后可重新打开并登录。原执行器继续运行，切换其他账号后设备所有者仍保持原值。
5. 点击“撤回共享”结束项目共享，点击“停止”结束本机执行器。应用菜单或托盘中的“退出”会等待执行器退出，停止未确认时保留提示。

共享会话服务可以保存排队输入并同步历史，桌面目前可读取已保存历史和获准的原项目只读内容。设备登记、共享、关窗重开、账号隔离与停止退出已通过 macOS 原生冒烟；原项目只读路径另经隔离环境冒烟。Windows、目标 TDSQL、真实 ACP 和 Git 写入留后续验证。证据见[HC-195 Task](../developer/task/HC-195-共享会话与实时同步.md)、[HC-196 Task](../developer/task/HC-196-设备接入与本机执行.md)及[HC-202 Task](../developer/task/HC-202-桌面工作台视图迁移.md)。
