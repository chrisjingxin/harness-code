# 变更检查清单

HC-192 实施期遵守用户逐任务仅冒烟、总体开发后统一测试的要求：

- [ ] 只影响已认领范围，保留已有变更，中文说明符合 [AGENTS](../../../AGENTS.md)。
- [ ] 必要安装/构建/类型/依赖边界和真实宿主冒烟已记录；未运行项目写明限制。
- [ ] 用户可感知变化已同步 docs/user，架构或工程边界已同步 docs/developer。
- [ ] `npm run project:check` 通过，构建变更检查 `npm run build` 与 `npm run typecheck`。
- [ ] 版本变更仅通过 version:set，必要工程管理用例已检查，不前置旧 CLI/Python 协议。
- [ ] Task 证据与 Todo 一致、tasks:sync 通过；只标待验收，完整回归交 HC-204。
- [ ] 向指定统筹回调一次，不轮询，不擅自提交/推送或归档。

[任务看板](../task/任务看板.md)由脚本生成，根 VERSION 是新 workspace 的唯一版本来源。
