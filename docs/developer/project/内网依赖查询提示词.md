# 内网依赖查询提示词

## 使用方式

把本文件与 `docs/developer/project/内网迁移依赖清单.md` 一起提供给能访问内网制品库的模型。推荐先执行提示词 1，再按生态执行提示词 2 和 3，然后执行提示词 4；上下文允许时，也可以直接使用“一次性总控提示词”。

这些提示词只授权读取与查询。不要让内网模型上传、同步、发布、删除或替换任何包，也不要让它修改项目锁文件。返回内容不得包含内网 URL、Token、Cookie、用户名或其他凭据；内部仓库可用稳定别名表示。

## 共同背景

```text
你正在为 Harness Code 做内网迁移前的只读依赖盘点。

Harness Code 是开发态的终端 Coding Agent：前端/CLI 使用 Bun 和 TypeScript，TUI 使用 OpenTUI/React；Python sidecar 使用 deepagents、LangChain 和 LangGraph；两端通过 stdio JSON-RPC 通信。此次任务不是升级依赖，也不是寻找“差不多可用”的替代版本，而是核对当前精确依赖闭包能否从内网取得。

事实基线以随附的《内网迁移依赖清单》为准。基线 commit 为 07bb7880293258614a912454aed1f554e80b6ec8，bun.lock SHA-256 为 e46c7318f4444f1b4b496175ebe16b8369f3e2fc5c66e77a5e956a7819121e15，packages/agent/uv.lock SHA-256 为 d3aeea573138d2b4c9d77363d3e9de11f45fd70a39feaf89c8037919bbe62b24。若你收到的文件哈希不同，请停止并报告 snapshot_mismatch。

只执行只读查询。不得上传、代理、缓存填充、发布、删除或修改内网制品，不得修改项目文件，不得访问或回显凭据。查询命令和 API 由你依据内网环境选择，但结果必须附带可复核的脱敏证据。

“查询失败/无权限/超时”不等于“包不存在”；“存在版本元数据”不等于“目标平台制品可下载”；“只有相近版本”不等于兼容。不得猜测或补全未经查询的结果。
```

## 提示词 1：确认内网环境与目标矩阵

```text
请结合共同背景，先做查询前置盘点，不查询全部依赖。

1. 列出可只读访问的制品能力：npm-compatible registry、Python simple index/package index、Bun/Python/uv 安装介质、浏览器二进制仓库。仓库地址只用 registry_alias 表示，不返回真实 URL。
2. 明确产品实际要支持的 target_environment：OS、CPU、libc（如适用）、Python implementation/minor/ABI。未知项写 unknown，不要自行扩大或缩小支持范围。
3. 记录你实际使用的只读查询方法、客户端版本和查询时间（含时区）。不要输出命令中的认证参数。
4. 验证是否能区分：包不存在、版本不存在、制品不存在、无权限、网络失败。
5. 返回 JSON，不要修改任何仓库或项目文件。

输出结构：
{
  "schema_version": 1,
  "inventory_snapshot": {"git_commit": "...", "bun_lock_sha256": "...", "uv_lock_sha256": "..."},
  "queried_at": "ISO-8601",
  "registries": [{"ecosystem": "npm|pypi|toolchain|browser", "registry_alias": "...", "readable": true, "query_method": "redacted command or API name", "client_version": "..."}],
  "target_environments": [{"id": "...", "os": "...", "cpu": "...", "libc": "...|not_applicable|unknown", "python_implementation": "...|not_applicable", "python_minor": "...|not_applicable", "python_abi": "...|not_applicable"}],
  "unknowns": [],
  "blocking_errors": []
}
```

## 提示词 2：查询 JavaScript/Bun 依赖

```text
请结合共同背景和提示词 1 的 target_environments，查询《内网迁移依赖清单》中“完整 JavaScript 锁定闭包”的全部 98 条外部解析记录，并另外查询 Bun 1.3.13 的目标平台安装介质。

要求：
- 输入中的每个 name + version + lock_key 组合必须恰好返回一次；不要漏掉同名多版本的 typescript 6.0.3/5.9.3 和 ws 8.21.1/7.5.12。
- 分别记录包名存在、精确版本存在、元数据可读、tarball 可读/可下载校验。查询不允许触发上传、远程缓存填充或镜像同步。
- 对 8 个 @opentui/core-* 原生 optional package，按 target_environment 检查 os/cpu/libc 匹配；未在目标矩阵的平台写 not_applicable。
- 保留 bun.lock 中的 integrity 作为后续离线安装比对依据；如果内网重新打包导致哈希不同，只报告 mismatch，不要判定可替换。
- @za38/cli 和 @za38/protocol 是本地 workspace，不应查询内网 registry，也不应出现在 98 条外部结果中。
- 发现精确版本缺失时可以列出内网已有相邻版本，但 status 必须是 alternative_only，不做兼容性判断。

每项输出：
{
  "ecosystem": "npm",
  "name": "...",
  "requested_version": "...",
  "lock_key": "...|null",
  "registry_alias": "...",
  "status": "exact_available|metadata_only|alternative_only|not_found|not_applicable|query_error",
  "exact_version_listed": true,
  "artifact_readable": true,
  "artifact_integrity": "sha512-...|unavailable|redacted",
  "target_environment_ids": ["..."],
  "available_alternatives": [],
  "evidence": "脱敏后的查询方法、状态码或制品元数据摘要",
  "error_class": "none|unauthorized|timeout|registry_error|unsupported_query"
}

最后附 counts：input_records、output_records、exact_available、metadata_only、alternative_only、not_found、not_applicable、query_error，并断言 input_records == output_records == 98。
```

## 提示词 3：查询 Python 依赖与 wheel

```text
请结合共同背景和提示词 1 的 target_environments，查询《内网迁移依赖清单》中“完整 Python 锁定闭包”的全部 92 个包，并额外查询构建隔离依赖 hatchling==1.27.0。

要求：
- 92 个锁定包每个恰好返回一次，hatchling 作为 source=pyproject-build-system 的第 93 条单独返回。
- Python 包名按 PEP 503 规范化匹配，但输出保留清单中的 name。
- 分别验证精确版本元数据、sdist 和目标环境可用 wheel；只有 sdist 时 status=source_build_required，不能写 exact_available。
- 对清单列出的 17 个“原生 wheel 风险包”，逐一按 Python ABI + OS + CPU + libc 返回 wheel filename/tag、可读性和哈希状态。不要因为其他平台存在 wheel 就判当前目标通过。
- 根据 marker 处理 secretstorage、pywin32 等平台条件；未适用时说明 target_environment_id 和 marker 依据。
- 当前 uv.lock 的 URL 指向阿里云镜像。你查询的是内网可用性，不得把外网锁文件中的 URL 存在当作内网可用证据。
- 若内网只有其他版本，可以返回不超过 5 个相邻版本供后续评估，但 status=alternative_only，不得自行修改约束。

每项输出：
{
  "ecosystem": "pypi",
  "name": "...",
  "requested_version": "...",
  "source": "uv.lock|pyproject-build-system",
  "registry_alias": "...",
  "status": "exact_available|metadata_only|source_build_required|alternative_only|not_found|not_applicable|query_error",
  "exact_version_listed": true,
  "sdist": {"available": true, "filename": "...|null", "hash": "sha256-...|unavailable|redacted"},
  "target_artifacts": [{"target_environment_id": "...", "status": "exact_available|source_build_required|not_applicable|query_error", "wheel_filename": "...|null", "wheel_tags": ["..."], "artifact_readable": true, "hash": "sha256-...|unavailable|redacted"}],
  "available_alternatives": [],
  "evidence": "脱敏后的查询方法、状态码或制品元数据摘要",
  "error_class": "none|unauthorized|timeout|registry_error|unsupported_query"
}

最后附 counts：locked_input=92、build_system_input=1、output_records、各 status 数量，并断言 output_records == 93。另列出所有需要源码构建的包及缺少的编译前置，但不要执行构建。
```

## 提示词 4：工具链、浏览器和整体门禁

```text
请结合共同背景以及提示词 1-3 的结果，对非包管理器制品和整体闭包做只读审查。

1. 对每个 target_environment 查询 Bun 1.3.13 安装介质；检查介质是否可读、平台是否匹配以及是否有可复核校验值。
2. 记录内网可用的 Python 小版本和 uv 版本。验证该 uv 版本能读取当前 uv.lock 的 version=1、revision=3；不要重新锁定或安装。
3. 如果迁移验收包含 Web E2E，查询 Playwright 1.62.1 所需浏览器二进制和系统运行库；如果不包含，明确标记 excluded_by_scope，不要误写为通过。
4. 确认仓库已经提交 10 组 tree-sitter WASM/query，日常 build 不需要联网；把 syntax:assets 的 GitHub 下载仅列为维护期外部来源。
5. 汇总 npm 98 条、PyPI 92 条、hatchling 1 条及工具链结果。任何 query_error、metadata_only、source_build_required、alternative_only、适用项 not_found 或未知目标环境都使 overall_status=blocked。

输出一个 JSON 对象：
{
  "schema_version": 1,
  "inventory_snapshot": {"git_commit": "...", "bun_lock_sha256": "...", "uv_lock_sha256": "..."},
  "toolchains": [],
  "browser_artifacts": [],
  "vendored_assets": [],
  "coverage": {"npm_expected": 98, "npm_returned": 0, "pypi_locked_expected": 92, "pypi_locked_returned": 0, "pypi_build_expected": 1, "pypi_build_returned": 0},
  "blocking_items": [{"ecosystem": "...", "name": "...", "version": "...", "reason": "...", "target_environment_id": "...|all"}],
  "overall_status": "ready|blocked",
  "conclusion": "只陈述查询证据支持的结论"
}

同时输出一份简短 Markdown 摘要，包含目标矩阵、覆盖率、阻塞项、只找到替代版本的包、需源码构建的包和查询错误。不要给出升级建议，升级兼容性由外网代码审查阶段另行判断。
```

## 一次性总控提示词

```text
请读取随附的《内网迁移依赖清单》，并严格遵守其中的“内网回填判定”和本提示词的共同背景。依次完成：

1. 只读识别内网 npm/PyPI/toolchain/browser 制品能力与目标环境矩阵；未知项不得猜测。
2. 查询完整 JavaScript 闭包 98 条，保留同名多版本和 lock key，检查 OpenTUI 平台原生包。
3. 查询 Python 锁定闭包 92 条，再单独查询未进入 uv.lock 的 hatchling==1.27.0；按目标 ABI 检查 17 个原生 wheel 风险包。
4. 查询 Bun 1.3.13、可用 Python 小版本、uv 对 lockfile revision 3 的读取能力；按范围处理 Playwright 浏览器。
5. 对输入和输出逐项做集合差异检查，任何漏项、重复项、查询错误、元数据但无制品、仅有替代版本、需要源码构建或未知目标条件都判 overall_status=blocked。

只查询，不安装、不构建、不下载到项目、不填充镜像、不发布、不修改锁文件。不得返回内网真实 URL 或任何凭据。

最终返回两个代码块：
- 第一个是完整 JSON，包含 inventory_snapshot、query_context、target_environments、npm_results、pypi_results、toolchain_results、coverage、blocking_items、overall_status；
- 第二个是 Markdown 摘要。

npm_results 必须恰好 98 条；pypi_results 必须恰好 93 条（92 个 uv.lock 包 + hatchling）；每项使用详细提示词 2/3 的字段。若上下文不足，不要截断或省略，改为按稳定批次输出并给每批 batch_index、batch_count、input_count、output_count，最后再输出合并校验。
```

## 返回给外网审查前的自检提示词

```text
请对你刚才生成的内网依赖查询结果做一次纯数据自检，不再发起新查询：

1. 校验 snapshot 三个值与输入清单一致。
2. 以 ecosystem + name + requested_version + lock_key/source 为键，检查漏项和重复项。
3. 校验 npm 98 条，PyPI 92+1 条；分别列 missing_keys 和 duplicate_keys。
4. 校验每个 target_environment 都覆盖 8 个 OpenTUI 原生包的适用性判断和 17 个 Python 原生 wheel 风险包判断。
5. 查找把 query_error 当 not_found、把 metadata_only 当 exact_available、把 sdist 当 wheel、把 alternative_only 当兼容的记录。
6. 查找 evidence 为空或包含疑似内网 URL、Token、Cookie、Authorization、用户名的记录；敏感值只报告字段路径，不复述内容。
7. 重新计算 blocking_items 与 overall_status，但不得改变原始查询事实。

返回 validation_status=pass|fail、counts、missing_keys、duplicate_keys、semantic_errors、sensitive_field_paths 和 recomputed_overall_status。validation_status=fail 时不要声称盘点完成。
```
