# 开发工作流

本分支默认入口已切换到独立桌面。流程仍为 Task → Spec → Plan → Todo → 实施 → 审查，详见 [AGENTS](../../../AGENTS.md)。HC-192 实施期间用户要求跳过 Skill，逐任务仅做必要冒烟，总体开发后在 HC-204 统一测试；由统筹调度左侧可见对话，完成或阻塞主动回调，不轮询。

根 `npm ci` 按唯一锁安装新 workspace，`npm run dev` 启动基础 Electron 窗口。构建与检查：

```sh
npm run build
npm run typecheck
npm run check:boundaries -- --self-check
npm run project:check
```

必要工程管理小套为 `npm run test:project`；构建后可用 `npm --workspace @workbench/desktop run preview` 验证生产页面。新默认命令不前置旧协议生成或 Python/OpenTUI 同步；旧源码只作迁移来源。

实施先检查状态并保留已有变更。统筹审核上游文档后按停点派发；证据写回 Task、只勾真实完成项、同步看板，阶段通过标待验收，不自动完成归档或提交/推送。版本只通过 `npm run version:set -- <SemVer>` 更新，新 workspace 与 CHANGELOG 共享根 VERSION。

详见[变更检查清单](变更检查清单.md)和[基础桌面 Task](../task/HC-193-独立桌面工程与分包.md)。
