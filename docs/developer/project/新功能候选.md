# 新功能候选

本文只留存产品与平台方向，不是任务看板，也不表示优先级、承诺或实施顺序。架构 P0 收敛完成并重新梳理产品目标前，不从这里直接认领实现。

## 多前端与交互体验

- 多题组合审批与问答表单，以及更完整的复杂 Interaction 呈现（目前仅支持单项审批/单题追问）。
- 交互式 Context Inspector（上下文透视器）、引导式交互压缩面板、Settings/Permissions 可视化管理面板、独立 Skill Manager 图形界面。
- Thread 管理增强：Thread 重命名、物理删除、格式化导出（Markdown/HTML/JSON）、生命周期保留策略、Fork（会话分叉）。
- 快照与变更高级能力：跨任意两轮历史快照的脱机 Diff 视图、完整会话历史转存与复制。
- TUI 偏好与视觉体系：可定制主题、平滑过渡动效、终端兼容策略与自定义输入键位映射。
- active Run replay、断线网络恢复与动态 Command reload。
- TUI 侧边栏深度扩展：在现有右侧侧边栏（HC-149 已交付工作区树/CWD/Context/MCP）中进一步集成 Thread 历史列表、Skill 状态监控等弱状态面。
- TUI 扩展卡片：Skill 专用交互卡、Plugin 自定义 Tool Renderer、独立 StructuredOutput 展示卡。

## Agent 与扩展体系

- 受信任的 AGENTS.md 来源确认与项目上下文自动摘要。
- 动态工作流（Dynamic Workflow）：引入轻量沙箱化 JS 运行时（如 QuickJS wasm32 / langchain-quickjs），支持模型运行时即席编写编排脚本派发子 Agent、进行 `Promise.all` 并发 fan-out 与 PTC（代码直调工具），减少串行 round-trip（参见调研 [162-动态工作流实现调研.md](../research/162-动态工作流实现调研.md)）。
- 崩溃容灾与断点续跑（AgentHarness 耐久化）：引入 intent-before-effect 与纯 Reducer 恢复机制，解决进程异常崩溃后无法续跑已受理 active Run 的问题（参见调研 [167-AgentHarness耐久化设计.md](../research/167-AgentHarness耐久化设计.md)）。
- 跨会话长期记忆检索（Long-term Memory）：借鉴 Grok Build 机制，在 `ContextLifecycle` 中实现跨 Thread 历史事实与记忆的按需检索与动态重注入。
- Plugin Marketplace 与网络安装：Git/GitHub/HTTP 来源解析、下载缓存与离线行为、完整性/签名/发布者信任、更新回滚、代理和企业源；届时根据市场筛选与认证需求重新评估是否公开 `conformance` 字段。
- Agent / Policy catalog 同步或远端 Subagent。
- Agent Team 协作深化：Team 内部成员点对点异步通信的 Mailbox 机制、Team 跨 Agent 统一 Token/Cost 计费体系。
- 第二类原生 Provider：非 OpenAI-compatible 的原生 Provider 适配器（如 Anthropic / Google 原生 SDK）及跨 Provider canonical message。
- 无人值守长任务：脱离人工干预的守护型长任务闭环、自动化错误自愈与超时重试策略。
- Agent 前后端工程模板生成。

## MCP、工具与企业能力

- MCP 能力完善：OAuth 鉴权集成、项目级 MCP 指纹授权管理与可视化 MCP 配置界面（HTTP/SSE 传输与基础快照指纹已支持）。
- 本地容器隔离后端：Docker / Podman 本地容器执行后端（除目前 LocalShell 与远端 Sandbox 之外的受限环境）。
- 企业远端 Sandbox Provider、审计事件与遥测 adapter。
- 企业级配置与策略分发：跨平台 managed TOML（如 `/Library/Application Support/Harness/managed.toml`）集中管理与策略下发、生命周期 Hooks 与企业内部 Plugin 源。
- 危险 Unicode 风险提示（如双向覆盖字符、零宽字符混淆）与受保护的 `AGENTS.md` 管理区块。
- 带 SSRF 严苛防护的网页读取工具（增强现有 `web_fetch`，拦截私网 IP、本地回环及云元数据服务）。

## 分发与工程条件

- macOS、Linux、Windows 自包含运行包与独立安装器。已由 [HC-181](../task/archive/HC-181-CLI安装与分发.md) 承接：对外一条安装命令，缺依赖则补齐，实现走 bun 全局包与 uv 工具包，不打自包含运行时大包。
- 企业 DeepAgents、MCP adapter 依赖升级。

## 架构收敛与已过时方向（不再实施）

- **Thread 恢复时按条保留 Run Mode**：
  - *收敛决策*：架构已在 SQLite 持久层（`harness_thread_modes`）确立单 Thread 模式冻结机制，首次运行即固定为 Build 或 Compose，跨模式运行直接拒绝（`THREAD_MODE_LOCKED`），防止弱模型在混合模式下出现状态混乱。因此“单会话内混用多种 Mode 并按条单独恢复”的设想已被架构否定。
- **旧 WorkItemView 挂载与旧式阶段顶栏**：
  - *收敛决策*：HC-155 已彻底移除重型的 Work Item 账本与 `WorkItemView`，改由轻量固定只读进度条 `ComposeProgressBar` 代替。
