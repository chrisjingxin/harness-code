# HC-235 本机会话消息排队

Agent 正在回复时，用户目前只能把下一条指令留在草稿中。允许用户先提交多条指令，桌面在当前轮正常完成后按顺序发送。

用户确认开发。沿用当前独立 worktree 和桌面主进程归属。见[规格](../spec/HC-235-本机会话消息排队.md)、[计划](../plan/HC-235-本机会话消息排队.md)和[清单](../todo/HC-235-本机会话消息排队.md)。

## 实施与验证

- 本机执行协调器在当前轮成功结束后按顺序发送，复用目录授权、附件解析和 Git 快照。待发消息独立保存在个人存储。退出重开后保留消息，等用户选择「继续发送」。提交结果不确定的待发项保留原文，禁止自动重试。
- macOS 正式 Electron 窗口使用临时用户目录、本地协作服务夹具和标准 ACP 测试进程，验证了运行中排队、重开保留、行内编辑、停止后暂停、手动继续以及两条消息按序收到。输入框上方的独立卡片也通过了折叠、展开和继续发送图标的窗口验证。
- 构建、类型、边界和项目检查通过。桌面定向测试 46 项通过，覆盖停止与终态竞态、重启、换绑定、提交结果不确定以及跨账号拒绝。
