# HC-251 团队Playbook模板

## 当前阶段

2026-11-23 结合企业团队新人上手与高频研发流程标准化诉求拆解立项。待认领，认领后按 Spec → Plan → Todo 推进。

## 要解决的问题

- 企业研发有很多高频固定场景（例如：新接口设计与契约评审、线上 502 故障排查、跨仓接口改造前影响分析、发布前自查），资深工程师能写出精准的 Prompt 并拉齐对应规约与仓库，但新人经常不知如何下手，导致每次对话效果参差不齐。
- 现有的知识（HC-241）是静态“规则与经验”，Skill（HC-245）是“单点工具/能力”，缺少把“推荐步骤 + 推荐知识 + 推荐仓库 + 起手式提问结构”打包在一起的**场景化协作模板（Playbook）**。

## 预期使用过程

```text
沉淀模板：
  输入：成员把一次高质量会话整理成 Playbook 模板提议（或从模板表单编写）
  内容：模板标题、场景描述、含占位变量的引导提示词、建议绑定的团队规约/经验、建议勾选的团队仓库组
  执行：管理员审核并发布（复用 HC-241 提议-审核工作流）

套用模板：
  输入：成员在新建个人会话或 Project 会话时从“团队 Playbook”中点选《线上故障排查模板》
  执行：
    1. 输入草稿自动填充模板引导词与待补全槽位（如告警时间、服务名）
    2. 自动预选推荐引用的知识条目，并在选目录阶段高亮建议该模板关联的本机已克隆仓库
  输出：用户填入具体信息后点击发送，立即获得高一致性、贴合团队实践的 Agent 协作起点
```

## 已确认的范围

1. **结构化模板模型**：包含名称、场景分类、引导提示词正文（支持明确的人类待填占位符）、推荐引用的团队知识列表、建议涉及的 Workspace 仓库列表及可选推荐模型/技能标签。
2. **个人会话与 Project 会话通用**：新建会话准备页展示当前所属团队已发布的 Playbook 卡片，个人私有调试与正式 Project 协作均可一键套用。
3. **审核把关与安全边界**：任何成员可起草提议（可由本机 Agent 从一段优质历史会话协助抽象生成），须经 Workspace 管理员审核发布后才对全员可见；套用模板只填充草稿和建议列表，**绝不跳过用户确认自动发起执行或自动加载未授权目录**。

## 不在本卡范围

- 服务端定时无人值守自动跑批的编排工作流引擎（本产品坚持由本机用户自主发起与控制执行）。
- 跨企业的公开模板商业市场。

## 职责与前置

- 服务端（由后端同事维护）负责 Playbook 模板的存储、版本、提议与审核状态接口；缺口按分工交同事，前端不私自新增后端 API。
- 桌面端负责模板浏览选择、套用至新建会话草稿、占位符交互提示、以及从现有会话抽提 Playbook 提议草稿的 UI。
- 依赖 [HC-239](HC-239-个人优先使用本机Agent.md) 的统一新建会话页、[HC-241](HC-241-知识分级与审核沉淀.md) 的审核机制与 [HC-242](HC-242-多目录本机会话.md) 的仓库建议。
