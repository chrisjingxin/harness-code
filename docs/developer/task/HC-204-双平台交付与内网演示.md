# HC-204 双平台交付与内网演示

## 当前可做与等待范围（2026-11-13）

可先准备目标平台、离线制品及验收材料，部署材料消费同事交付的服务端版本。协作验收采用 HC-217～220 的最新前端范围，详见[任务覆盖与交界](../project/项目协作设计任务衔接.md#31-按最新设计稿回检2026-11-13)。真实 Agent、本机取消/审批/恢复、Trace 采集在同事交付 ACP 与对应装配后验证。

当前演示为跨机器只读了解进展，通过固定引用与产品任务在接收者自己的会话中继续工作。本次更新的是最终 UI 与协作演示的验收目标，服务端和 ACP 设计仍以同事维护的文档为准。

## 需求与交付

交付可在 Windows/macOS 安装并跨设备协作的初版，外网演示后可用同一产品结构进入内网。用户能够按说明安装、升级、启动服务并复现只读同步、引用及任务协作。

属于 [HC-192 总任务](./HC-192-协作工作台与会话交接.md)，共同边界以 [独立桌面总体设计](../architecture/多人协作工作台顶层设计.md) 为准，参考来源见 [Lody 对照](../research/192-Lody协作能力对照.md)。设计基线为本地提交 `0250561`。本文是待审阅的子 Task，不是已确认 Spec 或实施计划，尚未认领或实现。

## 范围与目标归属

- 目标平台 Electron/Runner 安装包、可选 Agent/运行时与原生依赖材料、版本/手工升级和回退说明。
- 将同事已交付的 Java、数据库、代理、账号与设备登记部署说明纳入交付包，按其当前版本核验运行结果。
- 外网真实模型/Agent、两台电脑和匹配数据库的演示；目标 TDSQL 与内网 SDK 的独立验证。
- 当前协作链路的主动同步、轻量通知、本机执行与恢复，以及关机休眠、备份和最终 UI 走查。

## 依赖与范围边界

实现前置包括 [HC-217](./HC-217-项目导航与资料.md)、[HC-218](./HC-218-会话只读与主动同步.md)、[HC-219](./HC-219-引用任务与团队知识.md)、[HC-220](./HC-220-项目看板与轻量通知.md)，以及 [HC-200](./HC-200-Harness独立ACP接入.md)、[HC-201](./HC-201-Harness轨迹与设置扩展.md)、[HC-202](./HC-202-桌面工作台视图迁移.md)、[HC-203](./HC-203-旧入口与依赖退役.md) 子任务的需求/Spec 可先评审，前置依赖未满足时不得宣称集成已经完成。目标包名和具体接口需在对应 Spec 固定，当前目录建议不等于已有源码。

不开发手机端、计费、自动迁机、整目录同步、公网自动更新或真实内网登录系统。没有目标机器、签名证书、TDSQL 或私有 SDK 时按项保留待验收，不把本机交叉构建、mock 或普通 MySQL 结果当作通过。

## 并行认领与接口交付

工程基线和接口明确后即可提前准备目标平台/架构、服务部署、离线制品和统一验收清单，不需要所有业务实现完成才写交付材料。实际双设备/真实 Agent/TDSQL/SDK 与完整回归等待 HC-217～220 新版客户端、HC-203 退役及各对应真实前置；准备材料不等于交付通过。

最终 UI 验收按[当前视觉稿](../previews/project-collaboration/README.md)和 HC-217～220 的验收项逐区核对，复用部分同时沿 HC-205～208 的来源/行为保持清单核对，确认中央对话和右侧文件/变更实际复用，而非截图相似但功能重写。任务可由同事独立认领准备/测试，未验证项、依赖和证据回写仓库 Task；详见[并行开发约定](../project/协作任务并行开发约定.md)。

## 验收结果

- [ ] Windows x64、macOS arm64/x64 分别完成安装、启动、升级、原生依赖和 Agent 启停，最低系统版本与各 Agent 平台支持明确。
- [ ] 至少一次 Mac 用户在项目中讨论，Windows 用户先看到简报，再主动同步只读内容；固定引用经过预览进入自己的会话，明确发布给对方的 Task 由接收者自主确认并在本人会话开始。
- [ ] 原设备离线后服务端已上传材料仍可按权限阅读；跨机器访问包含同账号其他设备均只读，本机实际执行状态与阅读同步状态分别展示。
- [ ] 文件树、预览及中央可关闭文件页签指向本人当前设备的工作目录；远端页显示只读内容；Git 写入口按本期暂缓范围处理。本机发送、取消和审批按实际交付能力验证。
- [ ] 本人会话默认展开占主要空间、其他成员默认收起置底；展开与短窗口滚动可用。项目下拉集中展示项目，独立项目设置打开资料与成员，多项目切换可恢复各自草稿、页签和阅读位置。
- [ ] 任务列表/详情、团队知识及看板定位正确，轻量通知在会话页也更新元数据，成员折叠和未下载正文保持原状态；浅深主题与当前视觉稿一致。
- [ ] 无 Harness/Python 的通用产品和真实第二 ACP 后端通过；Harness 专有设置与完整 Trace 矩阵另验，内网 SDK 证据单列。
- [ ] Java/桌面/Runner 与同事交付的数据库脚本可用同一结构进入内网，所需安装包/运行时/Agent 制品离线准备，首次启动不请求公网下载。
- [ ] 签名/公证和安装体验按实际分发方式核对，更新保留数据并有回退材料，包中无真实会话/设备凭据/模型密钥/个人项目。
- [ ] TDSQL 的迁移/事务/约束、云端与设备两侧备份和恢复分别留证；普通 MySQL 演示与未到位内网条件明确列出。
- [ ] 用户/部署/排障文档与所有相关 Task 验收证据闭环，尚未通过项保持未完成，不按预算或演示结束强行归档。
