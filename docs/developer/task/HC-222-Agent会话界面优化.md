# HC-222 Agent会话界面优化

## 2026-11-17 会话阅读补充

用户要求文件按类型显示图标、回到底部只显示箭头、Markdown 可切换预览与源码、提高语法色可读性，并让行内代码跟随强调色但在浅色下更深。复用现有图标、Markdown 和 Shiki，不新增依赖或文件读取接口。Markdown 图片和相对链接受现有安全渲染能力限制，分别显示替代文字和普通文字。

本次补充已实现并通过构建、类型、依赖边界与文件渲染检查；使用受控会话及项目预览验证了箭头跳转、中央／右侧的 Markdown 与源码切换，以及浅／深色显示。此记录不替代本卡原有停点的验收。

用户随后指出会话文件名仅有图标、无法点击。本人本机会话的消息和工具详情复用既有本机只读预览；只有文件名时先搜索，同名文件交由用户选择。HTML、JSON 和 TS 图标参考截图调整，仍使用已有 `lucide-react` 和文字标识。

## 要解决的问题

HC-221 已把工作台外壳对齐原型稿，但特意没动中央 Agent 会话。现在会话区和外壳不是一套视觉，读起来也费劲：

- 人和 Agent 都靠左、都带 24px 头像，正文统一缩进 34px，一眼分不出谁在说话，阅读宽度也被吃掉。
- 每个工具调用单独占一行 30px，连续十几个工具平铺成一长串；失败时整行红底，比真正的回答还显眼。
- 推理用紫色色块显示，结束后直接消失，事后想回看 Agent 怎么想的看不到。
- 长会话没有按提问跳转的办法，只能手动滚动找。
- 强调色虽能在设置里切换，但色值在 `colors.css`、`base.css`、`desktop-workbench.tsx` 三处各写一份，会话区新加的颜色很容易漏改，变成“切了色但某些地方还是紫的”。

解决思路：参考 t3code 的版面节奏（紧凑日志行、悬停才出现的操作、左侧锚点条），视觉细节按原型稿（气泡、动词+路径写法、徽标、提醒色审批）；强调色收成 workbench-ui 的一个公共出口。改后用户能一眼区分人和 Agent、快速扫过工具过程、回看折叠的思考，并在长会话中按提问直达。

Spec / Plan / Todo 已补齐，按三个停点实施。

## 本卡负责

1. **消息版面（不要头像）**
   - 用户消息靠右，最宽约 82%（不超过 560px），白底细边框气泡，右下角小圆角；气泡上方一行小字显示作者名和时间（多人协作必须能看出是谁发的）。
   - Agent 回复靠左、取消 34px 缩进，上方一行小字显示 Agent 名称与时间，保证人机身份可辨。
   - 复制回复按钮在悬停或键盘聚焦时出现，只在宿主提供复制能力时显示。不新增“引用追问”等新动作。

2. **代码高亮（已有，保持并对齐外观）**
   - 沿用现有 `Markdown → CodeBlock → 语法高亮 worker` 链路，不换高亮方案。
   - 只调整代码块外观与原型稿一致：顶部一行显示语言和复制按钮，圆角卡片，浅/深主题各自的语法配色可读。
   - 工具详情中的文件、Diff、终端块与代码块使用同一套等宽字号和行高。

3. **工具日志与分组**
   - 单个工具改为 24px 紧凑行：灰色图标 → 名称 → 等宽摘要（路径的目录部分可截断、文件名保持完整）→ 状态徽标 → 向右箭头（展开时转 90°）。
   - 失败不再整行红底，只把图标染成危险色并显示“失败”徽标。
   - 同一轮里连续 2 个及以上工具自动合成一组，组头显示“N 个操作”及失败数；有工具在运行时组保持展开，全部结束后默认收起；展开后左侧一条细竖线串起各行，内容过高时组内滚动。
   - 分组只在前端由现有条目推导，展开状态复用现有个人状态 `expandedTools`，不改数据结构。

4. **思考过程自动折叠**
   - 推理条目结束后不再隐藏，而是保留为一行“思考过程”，可点开查看全文。
   - 判断链路：本轮仍在进行（推理进行中，或同组回答仍在流式输出，或同组有工具在运行）→ 展开显示；本轮结束 → 自动收起为一行；用户手动展开过的保持展开。
   - 视觉从紫色色块降为灰色日志行，进行中的标题带轻微文字微光，减少动态效果时改为静态。

5. **运行状态与交互**
   - “运行中 · 已运行 12s”状态行挪到当前一轮的末尾，而不是孤立在时间线最底部。
   - 待处理审批改用 1px 提醒色（橙色）细边加提醒图标，已处理的历史改为一行“标题 · 状态”（结果类型缺失，状态暂用次要色，见 Spec 数据缺口）。
   - 回到底部按钮改为悬浮小药丸，有新输出时用强调色描边；流式光标改为细竖线。

6. **左侧会话锚定（参照 t3code TimelineMinimap）**
   - 时间线左侧一列短刻度，每条用户提问一道；当前阅读位置所在的提问刻度加长并用强调色。
   - 悬停或键盘聚焦刻度时弹出预览：提问原文一行 + 该轮 Agent 最终回答前两行。
   - 点击刻度平滑滚动到对应提问并短暂高亮气泡；上下两个小按钮跳到上一条/下一条提问，聚焦锚点条时支持方向键。
   - 跳转视为用户主动滚动，退出“跟随最新输出”，不破坏现有阅读位置保存与恢复。
   - 宽度不足 980px、只有一条提问或右侧分屏挤压时自动隐藏；触屏不显示。

7. **强调色公共化**
   - workbench-ui 提供唯一的强调色出口：可选项列表（标识、中文名、浅/深色样例）和对应类型，以及一份主题样式，每种强调色只定义基础色值，浅色底、边框、淡色等衍生色由基础色自动计算。
   - 未设置强调色时默认紫罗兰；`colors.css` 不再单独写死紫色，桌面设置页改为引用公共列表，不再自带一份色值。
   - 会话区与本卡改动的样式只使用语义变量（强调、成功、提醒、危险），不出现具体色值；提醒/失败等状态色不随强调色变化。
   - 设置中的强调色入口沿用 HC-221 已交付的界面，点一下即全局生效并记住选择。

## 建议停点

| 停点 | 用户能看到什么 | 交付边界 |
| --- | --- | --- |
| 1. 版面与强调色 | 人右/Agent 左无头像、代码块外观对齐；设置中切换强调色后会话区全部同步变色 | 公共强调色出口与桌面设置改为引用；消息版面与字号变量化 |
| 2. 工具与思考 | 紧凑工具行、连续工具分组、回答完成后思考自动收起、运行状态归入当轮、审批提醒色 | 仅前端推导分组与折叠，个人状态结构不变 |

## 目录归属与并行

- 主要改动：`packages/workbench-ui/src/conversation/`（时间线、工具卡、交互、样式，新增锚点组件）与 `packages/workbench-ui/src/theme/`（强调色单一来源）。
- 共享接点：`apps/desktop/src/renderer/desktop-workbench.tsx` 的强调色设置改为引用公共出口，按 HC-217 约定串行合入。
- HC-218 负责的会话页面与 `local-execution-view.ts` 等数据转换不在本卡修改；验证使用现有 `hc206-preview`、`hc218-preview` 受控夹具。

## 数据缺口（降级显示，不由本卡补齐）

- 当前桌面本机会话转换未产出推理条目，思考折叠能力在夹具中验证；真实会话出现推理需 HC-218/HC-197 在数据转换中补齐。
- 原型稿中的工具/思考耗时、每条回复的模型标签、本轮改动文件汇总、用户消息附带的引用标签，当前显示类型没有对应字段：本卡不显示这些内容，缺口记入 Spec 交给对应卡片。

## 验收标准

- [ ] 用户消息靠右、Agent 回复靠左，两者均无头像，Agent 正文不再缩进 34px；每条消息仍能看到作者名与时间。
- [ ] Agent 回复中的代码块有语法高亮、语言标签与复制按钮，浅/深主题下语法色均清晰可读。
- [ ] 连续 2 个以上工具显示为一组；运行中展开、全部结束后收起；失败工具只显示危险色图标和“失败”徽标，不再整行红底。
- [ ] 推理进行中展开显示；该轮 Agent 回答完成后自动收起为一行“思考过程”，点击可展开，手动展开后不再被自动收起。
- [ ] 宽度 ≥980px 时左侧显示按提问排列的锚点；悬停出现预览，点击跳到对应提问并高亮，上下按钮与方向键可切换；窄于 980px 时锚点隐藏且不遮挡内容。
- [ ] 在设置中依次切换紫罗兰/靛蓝/青碧/墨黑，会话区的发送按钮、链接、行内代码、锚点当前项等强调元素即时变色，重开窗口后保持；仓库内除公共强调色样式外检索不到写死的紫色色值。
- [ ] 待处理审批显示橙色细边与提醒图标，不随强调色变化。
- [ ] 一轮结束时思考与工具组以折叠动效收起；新消息、展开收起、锚点跳转、复制等有轻量动效；系统“减少动态效果”下无位移与扫光但状态变化仍可辨。
- [ ] 浅色/深色、1280/980/760 宽度和系统“减少动态效果”下截图检查无错位、无溢出；微光与平滑滚动在减少动态效果时关闭。
- [ ] 发送、停止、审批提交、草稿保存和阅读位置恢复行为与改动前一致。
