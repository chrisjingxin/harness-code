# HC-248 全局命令面板与全文检索

## 当前阶段

2026-11-23 结合企业级多团队协作演进需求拆解立项。待认领，认领后按 Spec → Plan → Todo 推进。

## 要解决的问题

- 开发者每天会积累大量个人调试会话、多团队下的 Project 共享会话、团队知识、系统地图仓库与历史 Task；目前左栏搜索仅能过滤“当前已加载的成员与会话标题”，无法检索正文内容，更无法跨团队、跨 Project 查找曾经踩过的坑或某个接口讨论记录。
- 没有全局快捷入口（`Cmd+K` / `Ctrl+K`），在写对话或查问题时切换页面、定位仓库或拉入已有材料链路偏长。

## 预期使用过程

```text
输入：用户在桌面端任意页面按下 Cmd+K（Windows 为 Ctrl+K）或点击顶栏搜索，输入关键词（或前缀过滤如 @知识 / #任务）
判断：
  1. 本机层并发检索本地持久化的个人会话全文、已同步到本机的他人会话正文及本机 team.md/personal.md
  2. 云端层在当前账号权限范围内按需检索团队知识、系统地图仓库、Task 及云端可读消息索引
执行：按“个人会话 / 共享会话 / 团队知识 / 系统地图 / Task / 快捷操作”分组融合结果，标注来源范围与更新时间
输出：用户回车直接跳转并定位高亮片段，或按快捷键将命中条目作为固定引用插进当前对话草稿
```

## 已确认的范围

1. **双源合并检索架构**：个人私有会话正文只存在本机，通过桌面端本地轻量全文索引（如 SQLite FTS）检索，**绝不为了搜索把个人私有会话上传云端**；云端知识、Task、系统地图与有权限的共享消息复用服务端既有检索能力。
2. **严格的权限与可见性隔离**：检索结果中明确标注来源标签（个人私有 / Workspace / Project 名），服务端接口严格按调用者当下所属 Workspace 与 Project 成员权限过滤，被移出团队/项目的内容立即不可检索。
3. **命令面板常用动作整合**：除全文检索外，支持快捷切换 Workspace/Project、新建个人或团队会话、打开 Inbox、切换主题等高频键盘操作。
4. **一键定位与引用**：对检索命中的知识或历史会话片段，支持“直达原处查看”与“作为引用插入当前输入框草稿”两个动作。

## 不在本卡范围

- 跨机器扫描或检索其他成员未发布、未同步的私有本机会话与本机源码。
- 在线代码仓库的跨仓语义级代码搜索（本机单/多仓库代码搜索继续由本机工具和 Agent 处理）。

## 职责与前置

- 服务端（由后端同事维护）负责完善跨 Project 授权的共享消息、Task、团队知识与系统地图统一检索端口（复用已有 Elasticsearch 基础）；缺口按分工交同事，前端不私自新增后端 API。
- 桌面端负责构建与维护本地私有会话的按账号隔离全文索引、前端命令面板交互、防抖请求与双源结果融合排序、消息定位高亮。
- 依赖 [HC-239](HC-239-个人优先使用本机Agent.md) 的个人会话本机存储模型与 [HC-241](HC-241-知识分级与审核沉淀.md) 的分级知识模型。

## 待定问题（Spec 阶段确定）

1. 本机历史会话全文索引的重建时机、中文分词策略与磁盘占用上限。
2. 未手动同步正文的他人共享会话，在搜索命中云端片段后点击跳转时如何提示并触发按需同步定位。
3. 命令面板的快捷键自定义及与本机编辑器/文件面板快捷键冲突避让。
