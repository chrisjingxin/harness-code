# HC-208 协作导航与桌面布局

属于 [HC-192 总任务](./HC-192-协作工作台与会话交接.md)。需求由用户在 2026-11-06 明确补充，本文登记为可认领任务，未编写 Spec/Plan/Todo 或开始实现。共同边界见[总体设计](../architecture/多人协作工作台顶层设计.md)、[源码复用清单](../research/192-既有界面复用边界.md)及[并行开发约定](../project/协作任务并行开发约定.md)。

## 需求与交付

左侧承担新的工作区、设备、共享会话和待接手入口，参考 Lody 的信息组织；中央对话及右侧文件/变更保留原 UI。桌面外壳只负责布局和导航，不再写第二套消息区或 Git 面板。

## 范围与目标归属

- 目标：packages/workbench-ui/src/navigation 与 layout，提供工作区/设备/共享会话导航、当前账号入口、协作上下文/交接入口和可组合布局。
- 复用 HC-205 的颜色变量、品牌/图标和公共部件；中间 conversation、右侧 project 通过输入/插槽装配，不拷贝 HC-206/207。
- 顶栏只表达必要的当前会话、原执行设备/项目、接续人/待接手和连接事实，次要动作收进菜单；用户身份没有岗位/角色。
- 明确列表选择、搜索范围、空态/加载/失联/待接手、右区开合和窄窗口时的布局规则；原生窗口拖动/点击区由 HC-202 与 Electron 适配。

## 依赖、并行与负责边界

代码前置为 HC-205 公共出口。UI 本区输入/动作先在 Spec 固定，可用受控数据与 HC-206/207、HC-194/195/196/198 并行开发；真实用户/会话/设备和交接由 HC-202 装配。不会因为后端未完成就在 UI 内自造账号或另一套业务状态源。

本任务只写新导航/布局，不重画原消息/工具、右侧文件/变更或共享主题，不直接联网/执行、不替换 DesktopHost。Lody 截图不是新增定时任务、云更新、worktree 管理等功能的授权；没有后端能力时明确未接入，不放无效入口。

## 验收结果

- [ ] 左侧工作区/设备/共享会话/待接手信息层级清楚，选中可辨识且延续纯色选中风格，图标与文字对齐。
- [ ] 账号入口消费普通用户状态；切换工作区/账号只触发具名动作，不在导航实现登录凭据或业务请求。
- [ ] 中央和右侧由插槽/公开组件组合，同一原组件可显示；新布局不覆盖对话头像、工具卡、文件页签或 Git 交互。
- [ ] 冷紫浅/深主题统一，左栏宽度和可调/响应式行为有明确约束；不同高度/缩放不挤坏右侧上下结构或原生窗口按钮。
- [ ] 原设备/项目、接续人、交接进展和失联状态可以从输入展示，当前选择不被他人发言或交接擅自覆盖。
- [ ] 键盘、焦点与设置入口可用，设置保持居中弹窗；开发夹具不进入生产数据，不自动加入截图里的额外功能。

## 验证与交付

用受控状态独立检查导航和多尺寸双主题布局，组合实际公共组件做最小 Electron 冒烟；文件/Git/共享执行的真实链路由 HC-202/204 验证。交付导航模型、动作、布局插槽和与 HC-194 身份视图的接合说明。
