# HC-255 工作台双层交互原型落地

## 当前阶段

2026-11-24 已在 `harness_lody` 分支完成 **停点 1 → 停点 5** 全部桌面渲染/UI 改造、单测补齐、用户与架构文档同步及自动化全量校验（停点 1–3 提交：`3087d85c`，停点 4 提交：`f2de4ca5`），现标记为 **待验收**，等待在 `npm run dev` 中实机交互验收后定稿。

## 要解决的问题

- 当前桌面端仍采用“单层 280px 侧栏 + 居中设置大弹窗”的旧壳层（由 [desktop-workbench.tsx](../../../desktop/src/renderer/desktop-workbench.tsx) 在个人与团队之间分别挂载 `WorkbenchLayout`），Inbox、看板、任务、团队知识与系统设置入口挤在会话导航栏中，切空间易导致壳层重建，且 `⌘K` 命令面板仅在团队空间可用。
- 新版正式交互原型 [collaboration-workbench](../previews/collaboration-workbench/README.md) 已确立「56px 固定全局图标栏 + 304px 双模次级侧栏 + `no-sidebar` 1200px 宽屏业务页」双层架构，把高频开关收进左下角头像 Popover、把设置与治理收进 1200px 管理台、把看板与任务列表融合进带右侧详情抽屉的宽屏看板。
- 当前已交付但分散的功能（个人优先本机工作台 `HC-239`、项目导航与资料 `HC-217`、跨机只读同步 `HC-218`、任务与团队知识 `HC-219`、项目看板与轻量通知 `HC-220`、角色与离职交接 `HC-240`、消息排队与追发 `HC-235`/`HC-236`、划选引用与粘贴图片 `HC-237`/`HC-238`、全局 Inbox 与通知偏好 `HC-246`）需要统一迁移到新版原型体验中，并用 `impeccable`（Operate 模式）与 `stageshow` 动效规范回检用户旅程与动画因果性。
- 同时，原型中还包含部分尚待后续立项开发的功能（如 Playbook/SOP、系统地图、企业模型网关等）；本卡必须严格守住“**只还原已开发功能、不做假数据、不改服务层**”边界，并清晰记录后端/内核/IPC 缺口供后续任务承接。

## 预期使用过程

```text
56px 固定全局图标栏（Rail，只放已实现入口）
  ├─ [工作台] ──> 304px 次级侧栏（「个人｜团队」严格分栏会话树）
  │                 ├─ 个人会话：按本机目录分组，零弹窗首屏直接起聊，支持排队/引导托盘与右栏文件/变更
  │                 ├─ 团队会话：按 Workspace 切换 + Project 手风琴展开，支持只读同步 `.brief-card`
  │                 └─ 跨轨发布 / 停止共享：自动切轨、展开目标分组并触发 `row-land` 落位高亮
  ├─ [Inbox]  ──> `no-sidebar` 1200px 宽屏收件箱（HC-246）
  │                 ├─ 顶部：本机等待确认（waiting_approval / error）纯本机跳回提示条（不上云、不代批）
  │                 └─ 下方：跨团队待办 / 我发起的 / 已处理（30天）双栏审阅 + IM 通知入口闭环
  ├─ [看板]   ──> `no-sidebar` 1200px 宽屏 Project 看板（合并 HC-220 看板 + HC-219 项目任务）
  │                 ├─ 视图切换：状态四列（todo/doing/review/done） ↔ 成员进展（设备在线态 + 会话简报）
  │                 └─ 点击卡片：右侧滑出 `.t-drawer` 详情抽屉（状态流转 / 关联本机开聊 / 材料预览）
  ├─ [知识]   ──> `no-sidebar` 1200px 宽屏团队知识库（双栏阅读 + 版本历史 + 一键引用回会话）
  └─ 底部全局工具：
       ├─ [搜索 ⌘K] ──> 全局命令面板（覆盖个人会话 + 当前团队会话/任务/知识）
       ├─ [管理与设置] ──> 304px 管理分组导航 + 1200px 管理台（外观密度/通知偏好/本机目录记忆/账号/成员交接/仓库）
       └─ [个人头像] ──> 左下角 `UserPopover`（账号态 + 浅/深色一键切换 + 快捷直达设置/退出）
```

## 已确认的范围（纯 UI，100% 对齐已实现能力）

1. **统一单壳层与 56px + 304px 双层导航**：
   - 收敛 `desktop-workbench.tsx` 中个人/团队双套壳层为唯一 `WorkbenchLayout`，切换个人/团队空间或宽屏业务页时不卸载会话容器。
   - 56px Rail 顶部保留 4 个已开发入口（工作台 / Inbox / Project 看板 / 团队知识）；底部提供全局搜索 `⌘K`、管理与设置、个人头像 `UserPopover`。
   - 适配 macOS `hiddenInset` 标题栏红绿灯安全区与可拖拽区域，确保左上角窗口控制键与 Rail 按钮互不遮挡。
2. **304px 双模次级侧栏与 1200px 管理台**：
   - 工作台模式对齐原型「个人｜团队」分段切换：个人按工程目录折叠，团队按 Workspace 切换 + Project 手风琴展开（保持单激活 Project 实时拉取以避免 `HC-225` 请求风暴）。
   - 管理模式接入已开发的设置分区：`外观、密度与快捷键`（`WindowPreferences`）、`本机 Agent`（Provider 探测与「重新检测」）、`通知与提醒`（`NotificationPreferencesSection`，`HC-246`）、`本机目录记忆`（`DirectoryMemory`，`HC-233`）、`账号与登录`（`IdentityPanel`）、`成员角色与离职交接 & Workspace 仓库目录`（`TeamSettings`，`HC-240`），并移除旧居中设置弹窗；首页正常就绪时隐藏预检条以保持零噪点。
3. **对话工作台、排队托盘、跨机只读与右栏对齐**：
   - 零弹窗首屏（`PersonalNewSessionPage` / `NewSessionPage`）、`.c4-chat-head` 元信息栏与 `.hui-badge[data-tone]` 统一状态徽标、CSS Grid `0fr → 1fr` 平滑折叠的思考/工具块、紧贴输入框顶部的 `PromptQueuePanel` 排队/引导托盘。
   - 跨机只读页（`RemoteSessionPage`）按 `.brief-card` + `.peer-foot` 固定底栏排版；右侧 `ProjectDock` 对齐 `.rail` + `.dock-head` 下划线 Tab（保留真实的「文件」「变更」双页签与中央分屏预览）。
4. **Inbox 与 Project 看板双入口分离与任务融合**：
   - `Inbox` 作为独立一级入口（中断决策队列），完整保留 `HC-246` 跨团队待办与顶部本机等待确认跳转区。
   - `Project 看板` 作为独立一级入口（态势全景地图），合并已实现的 `HC-220` 看板与 `HC-219` 项目任务：支持「状态四列 / 成员进展」切换，点击任务卡片从右侧滑出 `.t-drawer` 抽屉完成创建、状态流转、关联本机开聊与固定材料预览（同时接通 Inbox / DeepLink 跳转定位与「返回收件箱」按钮）。
   - `TeamKnowledge` 接入 1200px 居中双栏审阅布局，保留版本历史与引用回会话能力。
5. **`impeccable` + `stageshow` 用户旅程与因果动效校准**：
   - 补齐个人空间 `⌘K` 命令面板、发布/停止共享 `row-land` 落位高亮、看板抽屉零跳转断层与离线/未入团空态降级。
   - 动效严格控制为 150–240ms 因果过渡（Grid 折叠、慢进快出浮层、排队列行高顺滑伸缩、`row-land` 焦点高亮），仅使用 GPU 合成或 Grid 行高动画，完整适配 `prefers-reduced-motion`。
