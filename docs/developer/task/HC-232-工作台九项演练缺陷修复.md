# HC-232 工作台九项演练缺陷修复

## 要解决的问题

1. **计划展示无 Markdown 渲染且不支持放大**：`elicitation-form.ts` 把计划正文直接放在纯文本 `description` 中，`#` / `-` / 反引号原样输出，且受限于卡片高度难以通读。
2. **Plan 审批提交按钮冲突**：点击「批准并开始执行」后仍保留「反馈（可选）」输入框并需再按右下角「提交」才能生效，而用户通常只在「需要修改」或「放弃」时才需要填写说明。
3. **`/undo list` 交互繁琐**：仅输出 Markdown 无序列表，需用户手动敲 `/undo <N> [mode]`。
4. **引用知识库仍强制选会话**：已在会话内敲 `@` 选中知识或刚切去知识库点「引用到会话」时，仍弹出全量本人会话列表让用户单选。
5. **输入框内 `@引用` 与普通文字无视觉区分**：输入 `@README.md` 后与普通正文同色同底。
6. **输入框内 `Command+K` 冲突**：`composer.tsx` 拦截 `Meta/Ctrl+K` 切换斜杠命令，阻断了全局 `⌘K` 命令面板。
7. **「退出 / 切换账号」失效**：`desktop-workbench.tsx` 要求 `persistence.flush()` 成功才放行退出，当存在失败草稿项时退出被静默拦截。
8. **左下角频繁报错「当前账号尚未确认该个人视图范围。重试保存」**：`PersonalStore.#authorize` 在 60 秒 TTL 过期后先行 `delete(cacheKey)`，并发到达的 `save()` 命中未授权分支报错。
9. **新建会话发送按钮不一致且提示重复**：保留矩形文字按钮与「⏎ 开始 / 按 Enter 直接开始」重复文案。

## 核心改动

- `apps/desktop/src/main/personal-store.ts` & `apps/desktop/src/renderer/personal-persistence.ts` & `apps/desktop/src/renderer/desktop-workbench.tsx`：TTL 过期期间保留占位缓存复用在途校验、`flush()` 失败时 `load` 重建授权后自动递增修订重试、退出账号不再受 `flush` 失败阻塞、记录最近本人会话 `preferredConversationId`。
- `packages/workbench-ui/src/conversation/{types,interaction,composer,timeline-model}.ts(x)` & `conversation.css`：取消 `⌘K` 拦截、`approval` 选项按需显示反馈框与提交按钮、`finalEntry` 支持 `extension` 条目、输入框背景镜像层零偏移 `@引用` 胶囊高亮与固定引用卡片样式升级。
- `apps/desktop/src/renderer/features/session/{elicitation-form.ts,local-session-page.tsx,new-session-page.tsx,use-local-execution.ts,session.css}` & 新增 `undo-choice.ts` / `undo-choice-card.tsx`：Plan Markdown 渲染与「放大查看」弹窗、批准一键直发、`UndoChoiceCard` 选择题、圆形新建发送按钮。
- `apps/desktop/src/renderer/features/collaboration/references/{conversation-references,workbench-references}.tsx`：知识引用直达当前或最近本人会话。
