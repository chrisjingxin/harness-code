# HC-206 既有对话视图复用

属于 [HC-192 总任务](./HC-192-协作工作台与会话交接.md)。需求由用户在 2026-11-06 明确补充，本文登记为可认领任务，未编写 Spec/Plan/Todo 或开始实现。共同边界见[总体设计](../architecture/多人协作工作台顶层设计.md)、[源码复用清单](../research/192-既有界面复用边界.md)及[并行开发约定](../project/协作任务并行开发约定.md)。

## 需求与交付

保留用户认可的中间对话体验，迁代码而不重新画一套消息区。共享用户作者、交接记录、@会话/消息引用是必要增量；已有头像、工具卡和输入交互仍以原实现为起点。

## 范围与目标归属

- 来源：packages/cli/src/web/presentation/timeline.tsx、composer.tsx、interaction-form.tsx、审批部件，以及对应样式和纯显示策略。
- 目标：packages/workbench-ui/src/conversation 下的组件、本区视图模型/动作、个人草稿/工具展开/滚动等表现状态。
- 消息/工具/推理、Markdown、发送/取消、输入自动增长、文件提及、键盘与焦点行为复用；公共渲染调用 HC-205 出口。
- 通用输入区预留引用、附件、设备/排队状态及能力控件的输入/动作，不在组件内实现云端查询或 ACP。
- Harness Compose/Goal/Task 等专有卡片和特殊审批经 HC-201 扩展接入；保留源清单，不能简单删除或在通用 Timeline 判断 Harness。

## 依赖、并行与负责边界

代码前置是 HC-205 的公共出口；本区模型和动作在 Spec 审查后可用受控夹具独立开发，与 HC-207 文件/变更、HC-208 导航和云端/Runner/ACP 各线并行。不要求 HC-195/196/197/198 全部完成才迁组件；真实状态由 HC-202 装配，未接线时不宣称真实协作完成。

本任务只修改 conversation 及其迁移来源/测试，不重做侧栏、Dock/文件页签、公共主题、主进程网络或模型循环。不把 WebAdapterSnapshot/InteractiveSnapshot 改名复制，不跨路径引用旧 adapter/runtime/selectors；UI 本区模型不写成线上 DTO。
