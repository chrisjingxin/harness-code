# HC-229 多代理适配与会话全量接线

## 要解决的问题

此前独立桌面端虽然已打通通用 ACP 运行时与单路 `WORKBENCH_ACP_EXECUTABLE` 试验通道，但存在三处断层：

1. **代理发现分散且未多代理化**：Harness 的 `.venv`/PATH 探测硬编码在桌面主进程中，缺少 Pi（含 macOS 下 `PI_CODING_AGENT_DIR` 真实主目录修复与 GUI PATH 增强）与 Qwen CLI 的标准 Provider 描述符及按优先级自动兜底的注册表；
2. **ACP 会话丰富能力未过桥到桌面前端**：`modes`、`configOptions`、`availableCommands`、`plans`、`usage`、`restoreStatus`、`sessionTitle` 与 `elicitation/create` 表单请求尚未通过 `DesktopLocalExecutionHost` / Preload / IPC 透传给渲染层，也未支持工作区相对路径 `@file` 转 ACP `resource_link`；
3. **会话 UI 仍停留在纯文本壳子**：新会话页与本机会话页还缺少 Agent 切换、动态斜杠命令与能力下拉、执行计划看板、上下文用量、恢复回退提示、以及交互表单（含 `q_N` 问答、目标/计划审批、`reject_with_feedback` 原因反馈及通用 Schema）。

## 核心方案与实施内容

1. **Layer ③ 多代理包与宿主注册表**
   - `packages/providers/harness/`（`@workbench/harness-provider`）：迁移 `.venv/bin/harness-agent` → `.venv/bin/python3|python -m harness_agent acp` → PATH 顺序探测，导出 `_meta.harnessCode` 解析辅助函数，声明 `enableElicitation` 与 `enableClientFs`。
   - `packages/providers/pi/`（`@workbench/pi-provider`）：使用增强 GUI PATH 探测 `pi-acp`，当外部未显式指定时按 `os.userInfo().homedir` 注入 `PI_CODING_AGENT_DIR`。
   - `packages/providers/qwen/`（`@workbench/qwen-provider`）：使用增强 GUI PATH 探测 `qwen` 并以 `--acp` 模式启动。
   - `apps/desktop/src/main/local-acp-host.ts`：实现 `LocalAcpProviderRegistry`，按顺序注册 `harness`、`pi`、`qwen`，在 `WORKBENCH_ACP_EXECUTABLE` 存在时注册并优先默认选中 `custom`，为托管 `LocalAcpHost` 开启 `enableElicitation: true`、`enableClientFs: true` 与 `restorePolicy: "fallback-new"`，通过 `createDesktopLocalExecutionRuntime` 统一回收实例。

2. **完整 ACP 会话桥接（Host / Preload / IPC）**
   - 扩展 `DesktopLocalExecutionHost`、`preload/local-execution-api.ts` 与 `main/local-execution-ipc.ts`，新增 `listProviders`、`prepare(scope, dir, providerId?)`、`setMode`、`setConfigOption`、`answerElicitation` 与工作区附件沙箱校验（`realpath` 防软链逃逸与越界，生成 `resource_link` 传 `session.sendPrompt`，对极简无 `sendPrompt` 会话优雅回退到 `send(prompt)`）。
   - 订阅 `session.subscribeSession` 并推送 `session-state` 与 `elicitation` 通知，同时保持既有 `accepted`/`text`/`thought`/`tool`/`permission`/`finished`/`upload` 行为完全兼容。

3. **会话 UI 全量接线与 DTO 收敛**
   - `session/contracts.ts` 直接复用并重导出 `@workbench/contracts` 中的会话与历史消息类型，清理重复手写 DTO。
   - 新增 `session/elicitation-form.ts`，双向映射 `q_N`+`q_N_other`、`decision`+`criteria`、`decision`+`feedback`、必填 `feedback` 与通用 Schema 字段，并针对桌面表单结构限制保证平滑可用与安全降级。
   - 更新 `local-execution-view.ts`、`use-local-execution.ts`、`local-session-page.tsx`、`new-session-page.tsx`、`session-provider.tsx`、`use-project-sessions.ts`、`session.css`，实现动态斜杠命令、多代理/模式/配置选择器、`workflow` 优先 `Tab` 轮转、执行计划卡片、上下文用量徽标、恢复回退横幅、`@file` 附件提取以及审批 + 表单提交通道。
