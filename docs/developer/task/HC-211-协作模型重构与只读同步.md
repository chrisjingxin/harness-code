# HC-211 协作模型重构与只读同步

## 本期目标

原协作模式由 Java 向他人设备派发执行，项目与共享目录混在一起。本卡交付团队下的业务项目、成员、仓库引用和本人定稿上传，让同事可以先看简报，再主动读取已上传内容。

2026-11-18 用户确认首版内网每人一台设备，并授权用户（本机）接手本期收口。保留 Devin 的历史拆解归属。当前 187f7c9 / 56e6fd3 已移除设备登记、认证、心跳与本机仓库绑定，会话归属按 ownerUserId 判断，上传走用户 Cookie + CSRF 的 Project sync。当前唯一 schema 包含 19 张表，已纳入 HC-212 的增量。

## 范围与流程

本期以 [Spec](../spec/HC-211-协作模型重构与只读同步.md)为行为口径，按 [Plan](../plan/HC-211-协作模型重构与只读同步.md)及 [Todo](../todo/HC-211-协作模型重构与只读同步.md)补齐必要验证。

```text
A 登录 → 登记当前 Project 的本人会话 → 上传定稿和简报
 → Java 检查成员、owner、连续序号 → 回执同步水位
B 登录同一 Project → 看简报 → 主动拉取 afterSequence 之后的正文
```

成员权限、负责人管理、本人上传、连续序号、同批幂等与跳号期望值继续适用。客户端本机目录与执行绑定由桌面任务维护，旧远程 inputs / execution / WSS / 会话正文 SSE 已退出。HC-212 的快照、任务、知识和用户级轻量通知沿用其当前实现。
