# HC-194 协作契约与云端基础

## 需求与交付

## 范围与目标归属

- packages/workbench-contracts：独立 HTTP/SSE/设备命令、回执、事件与扩展接口，具体载荷在 Spec 评审。
- services/collaboration-server：单一 Java 应用内的 identity、workspace、数据访问与传输基础。
- 版本化 MySQL 方言 SQL、JDBC/迁移工具依赖、普通用户和工作区成员初始化。
- 桌面主进程登录网络适配与用户状态接入；设备凭据与用户登录会话保持独立。
- 最小身份视图限定 workbench-ui/identity；公共主题由 HC-205 迁出，新导航由 HC-208、真实装配由 HC-202 负责。契约按业务命名空间唯一源分文件，公共聚合/根锁/preload 等共享文件顺序集成。

## 验收结果

- [ ] Java 和 TypeScript 可从共同输入生成或校验载荷，错误字段/不兼容载荷有明确结果，不静默强转旧类型。
- [ ] 服务可启动并返回普通当前用户/工作区；未登录或非成员无法越过工作区读取边界。
- [ ] 初始化产生 user01、user02、user03，无岗位角色字段；重复执行不改变原 ID、不重复建用户或覆盖历史。
- [ ] 桌面切换调试账号后当前身份正确，旧订阅/缓存隔离，Cookie 等凭据不交给 React 或写入日志。
- [ ] 迁移脚本和基础事务在匹配版本 MySQL 验证；目标 TDSQL 的 JDBC、SQL 与约束独立验证，未取得实例时明确待验收。
- [ ] 通用 Java 服务和桌面登录不依赖 Harness/Python、旧 Web server 或其私有协议。

## 规格决定与环境边界

规格固定同源 JSON Schema/OpenAPI 与 Java/TS 双端校验；Java 单应用采用 JDK 21、Spring Boot 4.1.2、Maven 3.9.11，父 BOM 管理 Connector/J 9.7.0 和 Flyway 12.4.0。仅三张用户/工作区/成员表，显式迁移与幂等演示初始化；演示免密码登录由主进程持有内存 Cookie/CSRF 凭据，renderer 只消费身份状态与具名接口。用户 UI 会话和未来设备身份保持独立。共享会话/SSE、设备/WSS、ACP 分别留 HC-195/196/197。

JAR 版本取根 VERSION，SQL 迁移序号独立；Java 工具仅在显式服务端命令需要，不能成为现有纯桌面构建的隐式前置。上述为拟实施契约，不是运行结论，官方核对链接与细节见 Spec。
