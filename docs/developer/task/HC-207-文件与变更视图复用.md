# HC-207 文件与变更视图复用

属于 [HC-192 总任务](./HC-192-协作工作台与会话交接.md)。需求由用户在 2026-11-06 明确补充，本文登记为可认领任务，未编写 Spec/Plan/Todo 或开始实现。共同边界见[总体设计](../architecture/多人协作工作台顶层设计.md)、[源码复用清单](../research/192-既有界面复用边界.md)及[并行开发约定](../project/协作任务并行开发约定.md)。

## 需求与交付

把已经实现的右侧文件、变更以及中央可关闭文件页签完整保留，换成新项目数据接口。用户继续在熟悉的阅读器看文件和 Diff，不因改桌面或多设备协作而退回小条预览或重写 Git 面板。

## 范围与目标归属

- 来源：packages/cli/src/web/presentation/context-dock/context-dock.tsx、context-dock/code/、context-dock/git-panel.tsx，以及 workspace-sidebar/file-explorer.tsx、file-tree.tsx。
- 从 workbench-views.tsx 提取文件页签/关闭/键盘切换及只读阅读器；公共高亮/Markdown 使用 HC-205，不复制渲染器。整体中央页签装配留 HC-202。
- 目标：packages/workbench-ui/src/project 的文件/Git 组件、本区视图模型/动作和个人页签/选择/提交说明状态。
- 复用 Dock 开关/宽度、文件树、路径/元信息/加载/错误/截断、Diff、勾选/全选、提交和推送分离结果。

## 依赖、并行与负责边界

代码前置为 HC-205 公共出口；本区模型/动作与 HC-199 项目端口在 Spec 共同审查后即可用夹具开发，与 HC-206、HC-208 和项目服务/设备通道并行。真实数据和操作必须由 HC-202 接 HC-199/196，不能把开发夹具称为远端读取/提交。

本任务只负责 project 视图；不写 Node/Git/文件系统、不实现 Java 授权、WSS 或新侧栏。原目录名含 workspace-sidebar 的文件树迁出后仍在右侧，不把文件树重新放回左侧。共享主题/总导出交对应主责及统筹集成。

## 验收结果

- [ ] 右侧“文件/变更”、文件树、只读预览、元信息/高亮/行号、刷新和打开中央文件页签沿用原组件和样式。
- [ ] 中央和右侧文件页签各自切换/关闭、焦点恢复和键盘导航可用，关闭按钮对齐，窗口变化时不依赖固定像素高度。
- [ ] Diff、单选/全选/部分选择、提交说明、提交/推送分离结果与重试提示保持；旧指纹/快照校验等业务值由新端口提供，不绕开 HC-199 的写入限制。
- [ ] 个人状态按账号/工作区/执行设备/项目隔离，文件另含相对路径；同名文件不串内容，他人操作不替本用户切页签或勾选。
- [ ] 原设备离线、只读/无权、加载失败与截断有真实可表达状态；渲染器不访问查看者同名路径或本机 Git。
- [ ] 无旧 adapter/coordinator/selectors 依赖，必要浅/深主题、窗口/缩放及文件/Git 交互冒烟通过；真实提交由项目服务集成另验。

## 验证与交付
