# HC-202 桌面工作台视图迁移

## 当前可做与等待范围（2026-11-11）

HC-205～208 已交付公共主题、对话、文件与变更、协作导航及布局组件。前三个停点复用这些组件装配正式桌面入口，接入现有身份、工作区、设备项目及共享会话历史和实时更新。停点五的原项目文件/Git 只读部分已通过统筹复核；停点四的个人状态恢复与原生后台已通过统筹复核。交接、引用与 Git 写入随实际端口就绪再接入。界面对尚未接通的操作显示可用性和原因。

所有 ACP 能力/事件映射、内容块、实际发送/取消/人工回答、Agent 运行与 Harness 扩展的开发、接线和调试，都等同事完成 ACP 交付后再安排；不把组件预览或云端排队成功当实际执行完成。见[当前并行约定](../project/协作任务并行开发约定.md#0-当前调度等待同事交付-acp2026-11-10)。
