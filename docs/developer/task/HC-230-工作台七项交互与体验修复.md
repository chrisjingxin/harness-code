# HC-230 工作台七项交互与体验修复

## 问题定位与根因

1. **团队知识无法新建保存**：`collaboration.schema.json` 限制 `termKey` 只能包含小写英文与数字等字符（`^[a-z0-9][a-z0-9._-]{0,63}$`），但旧表单把无格式提示的 `术语键` 放在第一位且校验静默置灰 `保存条目` 按钮，输入中文标题/标识键后完全无法点击，也没有说明原因；同时详情页缺少直达的「引用到会话」入口。
2. **非 Git 目录变更面板提示重复生硬**：`use-local-directory.ts` 注入了面向开发者的内部提示“仅提供本地文件浏览；Git 写操作已暂缓”，`git-panel.tsx` 在 `!repository` 时仍渲染 `⑂ 未检出分支`、`工作区 0 / 提交记录 0`、两段重复文案和底部禁用提交区。
3. **斜杠命令缺失与模式轮转不顺畅**：
   - `packages/acp-runtime/src/session.ts` 的 `openNewSession()` 在 `await this.nativeBinding.write(nativeId)` 磁盘 I/O **之前**就清除了 `openingNewSession = false`（此时 `agent.sessionId` 仍为 `undefined`），导致 `newSession` 响应同时到达的 `available_commands_update` 被丢弃；
   - Git worktree 下未向上追溯主仓库 `.git/worktrees/...` 的 `packages/agent/.venv`；
   - `tabCycle` 默认绑到 `workflow` 而非 `mode`（模式），缺少 `Shift+Tab`、乐观更新、`Tab` 微标及可见的 `/ 命令` 按钮；新会话准备页尚未统一成支持 `Enter` 提交的输入卡片。
4. **输入框底部裁剪与样式杂乱**：`.wb-conversation-view` 使用了 `overflow: clip`，而 `.wb-composer-inner` 底部与两侧 `padding` 为 `0`，切平了输入框底边与焦点光环；工具栏4项能力控件全带冗长前缀且胶囊缺乏收口，极易折成三行。
5. **`@` 菜单无分类、提示局限且默认漏掉知识库**：`desktop-workbench.tsx` 未把团队知识元数据传入 `useWorkbenchReferences`，且旧逻辑仅在手动输入 `@知识` 前缀时才查询知识库；`@` 菜单缺少分类筛选栏、分组标题和类型图标。
6. **文件行「预览」与「打开」语义不清**：两者只是打开文件的右侧栏/中央栏位置不同，给用户造成“有什么区别”的困惑。
7. **单题提问卡片问题展示两遍**：`q_0` 单题场景下 `request.message` 与 `prop.title` 为同一句问题文本，旧映射与 UI 同时渲染外层 `<h3>⚠️ 问题...</h3>` 与内层 `<fieldset><legend>问题...（必答）</legend>`，且用橙色警告三角展示普通提问。

## 核心改动

- **知识管理**：新增 `knowledge-key.ts`（`resolveKnowledgeTermKey` 自动为留空标识键生成合规短标并校对自定义键）与 `team-knowledge-key.test.ts`；升级 `KnowledgeEditor` 字段顺序、分类快捷预设及缺失提示；详情页新增直达 `引用到会话` 按钮。
- **非 Git 状态与发现**：精简 `use-local-directory.ts` 状态输出，在 `git-panel.tsx` 与 `project.css` 中对无 Git 目录直接呈现单张友好空态卡片并支持 `重新检测`；`packages/providers/harness/src/discovery.ts` 增加 `resolveGitMainWorktreeRoot` 支持从 Git worktree 定位主仓库 `.venv`。
- **ACP 竞态与输入体验**：修复 `session.ts` `openNewSession`/`resumeSession` 中 `openingNewSession` 生命周期至 `agent.sessionId` 赋值为止；`local-execution-view.ts` 优先将 `tabCycle` 绑定 `mode`、`use-local-execution.ts` 增加乐观切换回滚；升级 `composer.tsx`、`conversation.css` 与 `new-session-page.tsx`，修复裁剪、收敛单行胶囊、支持 `Tab`/`Shift+Tab`、新增 `/ 命令` 按钮。
- **`@` 分类菜单与单题卡片**：在 `desktop-workbench.tsx` 与 `workbench-references.tsx` 打通知识库与会话短标识，并在 `composer.tsx` 增加分类标签页（`全部 / 文件 / 知识库 / 会话 / 任务`）、分组小标题、语义图标与单一 `分屏查看` 按钮；更新 `elicitation-form.ts` 与 `interaction.tsx`/`conversation.css` 修复单题/反馈重复标题及长选项单选框换行。
