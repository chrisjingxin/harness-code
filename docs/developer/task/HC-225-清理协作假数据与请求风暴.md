# HC-225 清理协作假数据与请求风暴

## 要解决的问题

1. **生产工作台残留 `useCollabStore` 假数据**：`ProjectWorkbench` 仍挂载 `localStorage["hc221.collab.v1"]` 种子任务与知识、硬编码成员岗位 `KNOWN_ROLES`、以及未被实装服务替换的死页面/死弹窗；且 `desktop-workbench.tsx` 在传入真实 provider 的同时仍展开了被覆盖的 `createCollaborationPageProviders(...)`。
2. **三处 HTTP / IPC 请求放大风暴**：
   - `PersonalStore.#authorize` 每次 `load` 都删除权限缓存并重新请求服务端 `getProject` / `getProjectConversation`，且并发请求不会合并；
   - `useWorkbenchReferences` 将 `pageKey` 与 `referenceScope` 对象引用绑定到 `restored` 缓存，切页（看板 ↔ 任务 ↔ 知识 ↔ 会话）即丢弃已恢复的固定材料并重新全量拉取；
   - `dispatchProjectUpdates` 未判断看板页是否激活，在会话/任务/资料页收到轻量通知时仍无条件触发 `refreshBoard()`。

## 改动摘要

- **清理假数据并接通真实元数据**：
  - 在 `live-team-knowledge.tsx` 新增并导出 `useWorkspaceKnowledgeMetadata(host, scope, revision)`（通过 `readPages` 分页拉取 `host.listKnowledge(workspaceId, "", afterId)` 并过滤 `!item.archived`），在 `desktop-workbench.tsx` 中读取并向 `ProjectWorkbench` 传递真实 `tasks`、`knowledge`、`taskCount`、`knowledgeCount`。
  - 删除 `board-and-tasks-page.tsx`、`knowledge-page.tsx`、`collab-store.ts`，移除 `StartTaskDialog`、`KnowledgeCreateDialog`、`DispatchTaskDialog` 与 `useCollabStore`；保留 `demo-avatars.ts` 及其头像资源。
  - 将 `CommandPaletteModal` 改造为检索真实 `TaskSummary[]` 与 `KnowledgeSummary[]`（选中知识条目跳转 `{ kind: "knowledge" }`）；将 `memberRoleLabel` 收敛为 `member?.orgName || ""`（不预设岗位角色），并同步修正 `project-info-page.tsx` 的 `roleOf` 拼接格式。
  - 移除 `desktop-workbench.tsx` 中被真实 `tasks`/`knowledge` provider 遮蔽的 `createCollaborationPageProviders(...)` 调用，仅在 `taskContext` 缺失时回退使用。
- **修复三处请求放大风暴**：
  - `personal-store.ts`：`#permissions` 按 `${identity.generation}:${identity.accountId}:${this.#permissionKey(key)}` 缓存 60 秒 TTL（`expiresAtMs`），新增 `#authorizing` 对并发在途权限校验去重；身份代次变化或校验失败时主动淘汰缓存，TTL 过期后的 `save` 自动重新核验。
  - `workbench-references.tsx` + `desktop-workbench.tsx`：从 `referenceScope`（`useMemo`）与调用参数中移除 `pageKey`，并将 `restored` 缓存作用域对齐到项目与设备标识（`restoredKey`），切页不再失效重建或重拉固定快照/知识版本。
  - `use-project-updates.ts` + `desktop-workbench.tsx`：在 `ProjectUpdateTargets` 增加 `isBoardActive?: boolean`（由 `currentPage.kind === "board"` 传入），仅在 `isBoardActive !== false` 时分派 `targets.refreshBoard()`。
