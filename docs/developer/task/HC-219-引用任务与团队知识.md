# HC-219 引用任务与团队知识

## 要解决的问题

成员需要借用同 Project 的讨论结论，或者明确把工作分派给另一位成员。阅读和引用不能变成远程操作，发布任务也不能直接让对方 Agent 写代码。

本卡负责客户端 UI 和接口消费。Project 内的产品任务是工作台中的协作记录。引用、任务发布与知识阅读的受控界面已通过统筹复核，任务与知识的工作台页面装配也已通过统筹复核。整卡继续进行中。
