# HC-237 本机会话划选添加到对话

用户在本机会话中阅读 Agent 回复、工具输出、执行计划或中央分屏打开的代码与 Diff 时，经常需要针对其中一处或多处片段修改摘录或附带批注后继续提问。当前只能手动复制粘贴到输入框，缺少轻量的划选引用与行内批注能力。

本任务完整收敛在 `desktop/` 层实现（`ui`、`shared`、`main/personal-store`、`renderer/features/session`），不改动 `packages/*`、`contracts/`、`server/`、`agent/` 或执行 IPC，从而以“文本作为唯一事实源 + 展示层可点击行内引用块”的方式天然兼容所有 ACP Agent、消息排队（[HC-235](HC-235-本机会话消息排队.md)）、运行中追发（[HC-236](HC-236-Agent运行中追发.md)）及跨机器只读同步展示。见[规格](../spec/HC-237-本机会话划选添加到对话.md)、[计划](../plan/HC-237-本机会话划选添加到对话.md)与[清单](../todo/HC-237-本机会话划选添加到对话.md)。
