# HC-193 独立桌面工程与分包

## 需求与交付

建立可独立启动的 Electron 桌面与新产品工程边界。用户可打开原生窗口查看基础工作台，后续功能在新包中接入，无需先启动旧 CLI、TUI 或 Web server。

属于 [HC-192 总任务](./HC-192-协作工作台与会话交接.md)，共同边界以 [独立桌面总体设计](../architecture/多人协作工作台顶层设计.md) 为准，参考来源见 [Lody 对照](../research/192-Lody协作能力对照.md)。设计基线为本地提交 `0250561`。本任务由 Codex 在 harness_lody 认领；[Spec](../spec/HC-193-独立桌面工程与分包.md)已经统筹审查并按意见补齐，[Plan](../plan/HC-193-独立桌面工程与分包.md) / [Todo](../todo/HC-193-独立桌面工程与分包.md)已获统筹审查并派发实施，基础停点现已实现，待验收。

## 范围与目标归属

- apps/desktop、apps/runner：Electron/执行器的装配入口；不在装配层重复实现协作业务。
- packages/workbench-ui、workbench-contracts、runner-core、acp-runtime、project-service：建立清晰清单与导出，具体业务分别归后续任务。
- 原生窗口、基础主题、目录选择等受限 preload 入口；React 不直接访问 Node 或 Electron 主进程。
- 根 AGENTS.md、README、workspaces、工程脚本和锁文件：明确本分支为独立产品，新增入口不再走 packages/cli。

## 依赖与范围边界

实现前置：无其他新子任务前置；以已确认的 HC-192 需求/架构为输入。 子任务的需求/Spec 可先评审，前置依赖未满足时不得宣称集成已经完成。目标包名和具体接口需在对应 Spec 固定，当前目录建议不等于已有源码。

旧源码中的可用组件仍是后续迁移来源，本任务只切换默认工程路径，不提前删除尚未迁出的功能。旧源码与残余依赖的最终清理由 HC-203 负责；公共视图、对话、文件/变更和新导航分别归 HC-205～208，HC-202 装配，安装包验收归 HC-204。
