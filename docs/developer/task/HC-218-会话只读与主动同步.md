# HC-218 会话只读与主动同步

## 要解决的问题

原装配允许在其他电脑继续操作原设备，现在所有跨机器访问都只能阅读。需要把“这是我的会话”和“这是本机可执行会话”分开，并让正文只在用户主动同步时下载。

本卡只登记前端工作范围，当前待认领。认领后依次补同名 Spec → Plan → Todo，经评审再实施；不开发 Runner 内部上传或 ACP 运行时。

## 本卡负责

- 新建会话明确显示“选择文件夹”，由用户通过已有原生能力选择一个本机工作目录；可以不是 Git，也不把此目录解释为 Agent 只能访问的路径。云端 Project 与目录名称分开展示。
- 本人原设备会话复用 ConversationView、头像、用户 SVG、工具、输入、人工交互和本机文件/中央可关闭文件页签。发送、取消等动作仅消费同事交付的本机宿主入口，未交付时如实不可用，不用模拟结果当成功。
- 他人会话及同账号其他设备会话统一只读，不显示或派发发送、取消、审批及跨机器文件/Git 动作。只读正文中的工具仅展示实际上传的摘要。
- Project 会话列表向 HC-217 提供会话条目、稳定所有者标识与同步状态，由 HC-217 结合项目成员名单分组，行内显示标题、时间及未同步/更新标识，设备详情放会话上下文。展开成员不读取正文；选中会话先显示简报。点击同步、继续翻页或明确引用取材，才按已交付接口获取相应内容。
- 新建会话的目录选择、Agent 可用性、创建结果和本人列表更新由本卡闭环。取消目录选择返回原准备页；目录或 Agent 未就绪时保留草稿并反馈原因。现有个人历史不因切换 Project 或选择目录而自动发布。
- 消费 HC-211 的登记、简报、按需历史等现有客户端接口，保留消息顺序、已下载位置和阅读状态。同步失败保留已有内容并可重试；“已同步”只表示本账号在本设备已应用相应内容。
- 本卡提供“定位会话”和“选择本人本机会话或新建并带入材料”的前端动作，HC-219 使用该动作带入引用或任务上下文。本卡统一维护目录选择、草稿及本机可执行判断，HC-219 负责取材/任务动作及用户确认；已有会话沿用自己的目录，新会话主动选择目录。
- 向 HC-220 暴露前端元数据刷新接点，收到轻量通知只更新简报/标识，不自动取正文、不跳转当前页面。向 HC-219 提供引用来源定位和“引用到我的会话/创建任务”的入口。
- 中央会话页签与右栏显隐由本卡按会话模式装配，任务/知识/看板页只保留本人会话的草稿、文件和阅读状态。已交付轨迹/设置扩展沿 HC-201 的公开入口保留装配，实际采集与 ACP 调试依赖原卡和同事交付。
- 右侧文件只面向本机工作目录，消费已有本机文件服务；Git 提交/推送入口暂缓，保留实现和历史证据。

## 建议停点

| 停点 | 用户能看到什么 | 真实接线前置 |
| --- | --- | --- |
| 1. 两种会话模式 | 本机对话与远端简报/只读页、目录选择、同步状态 | 既有公共组件及 HC-217 的页面接点；可先独立预览 |
| 2. 主动同步 | 真实简报列表，点击后读取已上传正文并保留本机阅读状态 | HC-211 对应接口和已有身份消费能力 |
| 3. 本机装配 | 原有输入、工具、本机文件页签以及协作入口接入 | 同事交付的本机目录/执行公开宿主能力；引用动作接 HC-219 |

## 目录归属与并行

- 建议独立模块：`apps/desktop/src/renderer/features/session/`，负责会话模式、同步显示和本区个人状态；消费既有 conversation/project 公共出口，不复制组件源码。
- 会话简报/历史请求的客户端消费适配由本卡主责；新增具名前端宿主接点与 HC-217 串行集成，具体文件归属在 Spec 确认。Runner 核心、设备上传、ACP 和共享线上类型不在本卡范围。
- 与 HC-217、HC-219、HC-220 的 Spec/独立界面可并行；真实会话接线不等待 HC-212 整卡。引用/任务按钮的目标动作交 HC-219，通知连接及看板交 HC-220。
- 目录选择、同步状态、文件页签和草稿遵循同一账号/Project/会话/设备身份，不另造与既有个人状态并行的业务真相。

## 验收标准

- [ ] 新建会话前目录为空并由用户选择，普通文件夹可作为工作目录；一个会话仍绑定一个目录。
- [ ] 创建成功后会话出现在当前 Project 的“我的会话”，取消或失败保留准备信息；切换项目、账号或目录不会发布既有个人历史。
- [ ] 本人原设备可用动作按实际宿主能力展示；跨机器会话即使同账号也不能发送、取消、审批或读取实时文件/Git。
- [ ] 进入远端会话只显示简报，点击同步后才读取正文；通知不触发正文批量下载。
- [ ] 未同步、同步中、已同步、有更新及失败可辨识；失败保留已有正文，切换会话不会串用下载位置或草稿。
- [ ] 原有 AI/用户图形、工具卡、输入、文件阅读及中央文件关闭交互保留；只读页没有可发送输入区。
- [ ] 从引用或任务入口选择已有本人会话时保留原目录与草稿，新会话才要求选目录；带入材料不自动发送，真正执行来自用户明确动作。
- [ ] 只读页的引用与任务入口交给 HC-219，正文或通知更新不会擅自变更已选引用、焦点和当前会话。

## 必要验证与非范围

实施时做受影响构建/类型/边界检查，冒烟一条“选择文件夹 → 查看本机会话 → 打开远端简报 → 主动同步并只读查看”的正常路径。真实本机执行仅在同事宿主能力交付后验证；受控界面不算 ACP 接通，完整双设备和双平台由 HC-204 统一验收。

不改服务端同步/存储设计、Runner 内部上传/恢复或 ACP；不迁移原生 Agent 上下文、不接管其他电脑、不同步整份目录。HC-202 已完成的视图和个人状态成果继续保留，本卡承接新版只读/主动同步客户端适配。
