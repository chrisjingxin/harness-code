# HC-238 输入框复制粘贴图片

用户在本机会话中经常需要直接截图或复制图片粘贴到输入框，结合报错截图、界面效果图或设计稿与 Agent 沟通。剪贴板内容是瞬态的，且 macOS Retina 截图往往超过 `2000px` 边长或数 MB，若直接把 Base64 塞进 `PersonalStore` 会触及 1 MB JSON 上限并污染工程仓库，若只给模型本机绝对路径则会撞上工作区沙箱限制。

本任务跨两层协同落地：
1. **桌面层（`desktop/`）**：粘贴捕获与并发占位保序、客户端 `≤ 2000px` 等比缩放压缩、基于应用 `userData/local-images/` 的两阶段不可变缓存、`PersonalStore` 仅存轻元数据、输入框顶部缩略图条（带移除按钮）+ 全局灯箱放大预览 + 时间线气泡缩略图回显，以及透传 `promptCapabilities.image` 与发送前读取组装标准 ACP `image` 内容块；
2. **Harness Code 内核层（`agent/`）**：在 `PromptCapabilities` 声明 `image=True`，解析并校验 ACP `image` 块为 `PromptImage` 进入 `UserRunInput`，向模型组装标准多模态 `HumanMessage(content=[text, image_url])`，同时保留 SQLite Transcript 可读文本占位（不含 Base64）。

详见[规格](../spec/HC-238-输入框复制粘贴图片.md)、[计划](../plan/HC-238-输入框复制粘贴图片.md)与[清单](../todo/HC-238-输入框复制粘贴图片.md)。
