# HC-255 工作台双层交互原型落地 · 实施计划

[需求卡](../task/archive/HC-255-工作台双层交互原型落地.md) · [行为规格](../spec/HC-255-工作台双层交互原型落地.md) · [执行清单](../todo/HC-255-工作台双层交互原型落地.md) · [桌面前端交互设计](../architecture/桌面前端交互设计.md) · [当前协作工作台交互原型](../previews/collaboration-workbench/README.md)

按五个可演示停点仅在桌面渲染与 UI 层推进（沿用当前 `harness_lody` 工作区与未提交变更保护规则，不切分支、不自动提交推送）。每完成一个停点即执行对应检查与桌面实机预览验证，并停下等待用户确认后再进入下一停点；全部完成后更新用户手册与架构设计文档。

## 模块改动与职责归属

| 层 | 本卡改动范围 | 严守边界 |
| --- | --- | --- |
| `desktop/src/ui/` | 主题令牌（`theme/`）、公共控件与徽标（`common/`）、双层布局外壳与 56px Rail / `UserPopover`（`layout/`）、304px 双模侧栏（`navigation/`）、时间线折叠/排队样式（`conversation/`）、右侧栏 Tab 样式（`project/`） | 不引入 Node/Electron/业务接口依赖；新增外壳 props 一律可选，保持 `hc217-preview` / `hc218-preview` 无损编译 |
| `desktop/src/renderer/` | `desktop-workbench.{tsx,css}` 统一单壳层装配、全局 `⌘K`（`collaboration-views/`）、1200px 管理台（新建 `features/admin/` 聚合既有设置面板）、对话首屏/元信息栏/排队托盘/跨机只读对齐（`personal-sessions/`、`session/`）、宽屏 Inbox / 融合看板+抽屉 / 知识双栏（`inbox/`、`board/`、`collaboration/`、`workspace/`） | 严格只消费已有宿主与 IPC 端口；零假数据、零空壳占位；不改多 Project 并发拉取策略（守住 `HC-225`） |
| `desktop/tests/` | 壳层全局命令面板索引、看板合并视图与状态筛选模型、跨轨落位与 DeepLink/Inbox 抽屉路由映射等纯逻辑单测 | 不依赖真实网络或后端环境变量 |
| `docs/` | 同名 Spec/Plan/Todo、[独立桌面工作台](../../../docs/user/独立桌面工作台.md) 与 [桌面前端交互设计](../../../docs/developer/architecture/桌面前端交互设计.md) 增量 | 所有本地 Markdown 链接与任务编号必须通过 `npm run project:check` |

> **显式锁定不变边界**：本卡全程不触碰 `server/`、`agent/`、`contracts/`、`packages/`，以及 `desktop/src/main/`、`desktop/src/preload/`、`desktop/src/shared/`。

## 停点 1 · 视觉令牌收敛、统一双层壳层与全局 `⌘K` / 头像 Popover

1. **视觉令牌与统一基础部件**：
   - 更新 [colors.css](../../../desktop/src/ui/theme/colors.css)、[accent.css](../../../desktop/src/ui/theme/accent.css)、[base.css](../../../desktop/src/ui/theme/base.css)：引入 `--rail-surface`、`--sidebar-surface`、`--rail-w: 56px`、`--sidebar-w: 304px`、`--ease-flow`、`--accent-text` 及 `--*-ring` 语义环令牌，保留原有基础变量向后兼容。
   - 更新 [common.css](../../../desktop/src/ui/common/common.css)：沉淀统一 `.hui-badge[data-tone][data-size]`（含 `.hui-lamp` 状态灯）、补齐 `.wb-button-soft` / `.wb-button-danger` 及统一的轻压/焦点微反馈样式。
2. **56px 全局图标栏与统一 `WorkbenchLayout`**：
   - 在 `desktop/src/ui/layout/` 新增 `app-rail.tsx` 与 `user-popover.tsx`，导出至 [ui/index.ts](../../../desktop/src/ui/index.ts)：
     - `AppRail`：顶部 4 个真实入口（工作台 / Inbox / Project 看板 / 团队知识）+ 底部全局搜索 `⌘K`、管理与设置、个人头像按钮；处理 macOS `hiddenInset` 左上角 `38px` 红绿灯安全区与 `-webkit-app-region: drag/no-drag`。
     - `UserPopover`：锚定左下角头像，展示登录用户头像/姓名/角色/在线状态，支持快速切换主题（跟随系统/浅色/深色）、一键直达管理台与退出登录。
   - 改造 [layout/index.tsx](../../../desktop/src/ui/layout/index.tsx) 与 [layout.css](../../../desktop/src/ui/layout/layout.css)：支持可选 `rail` 与 `noSidebar`（宽屏自动隐藏次级侧栏，200ms `--ease-flow` 平滑收展）及 `≤980px` 窄屏抽屉遮罩；未传 `rail` 时兼容旧版独立预览页。
3. **收敛顶层单壳层与全局 `⌘K`**：
   - 重构 [desktop-workbench.tsx](../../../desktop/src/renderer/desktop-workbench.tsx) 与 [project-workbench.tsx](../../../desktop/src/renderer/features/project-navigation/project-workbench.tsx)：移除团队态嵌套第二套 `WorkbenchLayout`，将 `WorkbenchLayout` 提升到 `ConfirmedUserWorkbench` 单壳层统一渲染；切换「个人 ↔ 团队」或宽屏页时保持会话视图不卸载、草稿和滚动锚点不丢失。
   - 升级 [collab-overlays.tsx](../../../desktop/src/renderer/features/collaboration-views/collab-overlays.tsx) 与 [collab-views.css](../../../desktop/src/renderer/features/collaboration-views/collab-views.css)：`CommandPaletteModal` 支持个人/离线模式（本机会话 + 快捷页跳转）与在线团队模式（个人 + 当前 Project 会话/任务/知识）全局检索，随单壳层响应 `⌘K`。

**演示与验证方式**：启动 `npm run dev` 或 `npm run build` 后的桌面应用，验证左上角红绿灯与 56px Rail 按钮互不遮挡且可拖拽窗口；点击左下角头像弹出 `UserPopover` 一键切换浅/深色；在个人与团队空间任意页按 `⌘K` 呼出命令面板并切换「工作台 / Inbox / 看板 / 知识 / 管理与设置」；验证 [hc217-preview](../../../desktop/src/renderer/hc217-preview/main.tsx) 与 [hc218-preview](../../../desktop/src/renderer/hc218-preview/main.tsx) 构建无报错。

## 停点 2 · 304px 双模次级侧栏、跨轨 `row-land` 动效与 1200px 管理台

1. **304px 双模次级侧栏（工作台会话树 + 管理导航）**：
   - 改造 [navigation/index.tsx](../../../desktop/src/ui/navigation/index.tsx) 与 [navigation.css](../../../desktop/src/ui/navigation/navigation.css)：
     - 剥离原侧栏内嵌的收件箱、看板、任务、知识与设置入口（统一交由 56px Rail 承担）。
     - 工作台模式收敛为纯净「个人｜团队」分段切换器：个人空间按工程目录 CSS Grid `0fr → 1fr` 折叠；团队空间提供 Workspace 切换胶囊、单激活 Project 手风琴（hover 露出资料与成员齿轮按钮，内部展示本人会话 `我`/`仅摘要` 标签与队友会话未同步蓝点，点击非激活 Project 再切换加载以守住防请求风暴约束）与离线/未入团简洁引导卡片。
     - 为个人与团队会话行接入 `landingId` 750ms `row-land` 脉冲高亮：当发布个人会话到 Project 或停止共享移回个人空间时，自动切到目标空间并触发落位高亮。
     - 管理模式切换为分组导航清单（个人与本机：外观密度与快捷键 / 通知与提醒 / 本机目录记忆；账号与团队：账号与登录 / 成员角色与仓库），顶部带「返回工作台」按钮。
2. **1200px 居中管理台与退役设置大弹窗**：
   - 新建 `desktop/src/renderer/features/admin/`（如 `admin-page.tsx` 与 `admin.css`），使用 1200px 居中 `.page-wrap` 与 `.panel` 卡片统一承载已实现的 5 类设置：
     - `appearance`：复用 `WindowPreferences` 与快捷键一览网格；
     - `notifications`：复用 [notification-preferences-section.tsx](../../../desktop/src/renderer/features/inbox/notification-preferences-section.tsx)；
     - `memory`：当存在活跃团队会话作用域时直接挂载 [directory-memory.tsx](../../../desktop/src/renderer/features/workbench-context/directory-memory.tsx)，无活跃团队会话时显示清晰指引（提示进入任一团队会话后关联维护本机工程副本）；
     - `account`：复用 `IdentityPanel`；
     - `team`：将 [team-settings.tsx](../../../desktop/src/renderer/features/workspace/team-settings.tsx) 与 [team-settings.css](../../../desktop/src/renderer/features/workspace/team-settings.css) 对齐 `.panel`、`.hui-badge` 与离职交接流程。
   - 在 [desktop-workbench.tsx](../../../desktop/src/renderer/desktop-workbench.tsx) 移除旧居中设置大弹窗，未登录/连接异常仍保留简洁登录入口。

**演示与验证方式**：启动 `npm run dev`，验证工作台 304px 侧栏「个人｜团队」切换、工程目录折叠与 Project 手风琴切换流畅无请求风暴；将个人会话「发布到 Project」与「停止共享」，观察自动切轨及 750ms `row-land` 落位高亮；点击左下角齿轮进入 1200px 管理台，逐项检查外观、通知偏好、本机目录记忆、账号与成员离职交接功能正常可用。
