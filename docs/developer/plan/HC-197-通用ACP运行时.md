# HC-197 通用 ACP 运行时计划

关联 [Spec](../spec/HC-197-通用ACP运行时.md)。

## 停点一 本机目录绑定与文本首轮

1. 将标准 ACP SDK 加入新平台的唯一根锁。公开进程宿主、会话句柄和首轮事件。
2. 实现会话目录绑定、stdio 子进程与顺序推送，供 Electron 主进程通过独立模块配置。由 HC-218 接入正式主进程装配和 IPC。
3. 用隔离目录经真实 Harness Agent 发送两轮。检查受理、重复发送拒绝、顺序、完成后可发送、会话隔离与退出。记录必要构建、类型及依赖边界结果。

演示时运行必要冒烟命令，观察受理、三个顺序增量和终态，然后在同一目录会话继续发送。

## 停点二 停止与人工审批

实现轮次内停止和权限应答，接入现有桌面输入区和审批卡。冒烟走批准、停止、再发送，并核对成功定稿仅上传一次。

## 停点三 原生会话恢复与通用性

保存并校验原生会话绑定，接入能力协商、回放隔离、标准工具通知和受控 stderr。用独立进程、Harness 和第二 Agent 验证，再复用正式双设备脚本验证 A 定稿上传、B 主动同步。
