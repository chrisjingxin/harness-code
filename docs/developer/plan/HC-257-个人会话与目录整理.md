# HC-257 个人会话与目录整理计划

[规格](../spec/HC-257-个人会话与目录整理.md)

依赖顺序：主进程能力 → 渲染层模型与 hook → 左栏视图 → 装配与便利功能 → 文档与验证。每一步先写失败测试再实现。

1. **停点 1 · 本机能力就绪（无界面变化，用单测观察）**
   - `shared` 增加 `archivedAtMs`、`pinnedAtMs` 与三个宿主方法；`LocalConversationStore` 实现 `setArchived`、`setPinned`，`appendTurn` 清除归档，`isRecord` 接受可选字段；
   - `PersonalStore.removeConversation`、`CodeCheckpoints` 按会话清理、协调器 `hasActiveTurn` 与 `forgetConversation`；
   - `local-conversations-ipc.ts` 新通道、`remove` 收紧、`revealDirectory`（可注入 `revealPath`）与清理钩子；`collaboration-ipc.ts` 装配；`preload` 与 `env.d.ts` 同步。
   - 观察方式：`npm --workspace @workbench/desktop test` 中新增用例通过。
2. **停点 2 · 左栏整理核心（用户可见）**
   - `personal-sessions-model.ts` 分区扩展与 `conversationToMarkdown`；`usePersonalSessions` 增加置顶、归档、取消归档、删除、批量与新建预填；
   - `ui/navigation` 增加置顶区、已归档区、会话菜单项与置灰原因、确认弹窗、搜索“含已归档”开关；`desktop-workbench.tsx` 装配数据与动作。
   - 观察方式：`npm run dev`，个人空间右键会话可置顶、归档、删除；底部出现“已归档 (n)”。
3. **停点 3 · 目录分组与便利功能（用户可见）**
   - 目录分组标题行“更多”菜单：在此目录新建、复制目录路径、在文件管理器中显示、整组归档、整组删除；
   - 会话右键与会话页的“复制为 Markdown”；`SessionMetaHeader` 展示“已归档”与“取消归档”。
   - 观察方式：`npm run dev`，目录分组悬停出现“更多”；整组删除弹窗要求勾选确认。
4. **停点 4 · 文档与交付验证**
   - 更新 `docs/user/独立桌面工作台.md` 与架构说明；
   - 运行依赖安装、构建、类型检查、桌面全量单测、边界检查与工程检查，结论与命令写回 Task `test_evidence`。
