# 实施计划

## 唯一停点 A：同目录文件并行可完整使用

按以下依赖顺序推进；文件预留、命令协调和验收版本组成同一交付包。

1. 先写真实 SQLite、排队、快照和 Host 回归，确认旧实现失败。
2. 建立新预留、队列和短期操作结构，完成一次数据迁移及范围冲突计算。
3. 接入 Service 自动等待、取消和扩范围，保留代号及停止检查。
4. 文件契约、命令、普通模式、Compose 与历史还原接入同一保护；检查锁顺序。
5. 分开任务范围与源码快照，绑定检查轮及最终审阅版本。
6. 更新 Protocol 生成物、共享界面、用户指南和长期架构，运行相关与包级检查并审核。

观察：两个会话分别修改 a.py / b.py 可同时派单；改同一文件显示“自动等待”，结束前一任务后后者自动执行。Ctrl+C 或 /fusion cancel 不留下等待记录。
