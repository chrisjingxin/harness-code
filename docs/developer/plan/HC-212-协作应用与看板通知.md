# HC-212 协作应用与看板通知

## 停点一 会话快照

1. 按 [Spec](../spec/HC-212-协作应用与看板通知.md) 补齐共享契约、快照表和 Java 启动核对。
2. 复用项目访问策略、同步水位、历史存储及响应包络。创建读取同一快照记录。限额与摘要按实际 UTF-8 正文计算。
3. 构建 Java，运行双端契约校验，并用独立 MySQL 测试库跑一次 HTTP 主链。A 登记设备和会话并上传，B 取材预览和读取，A 追加后 B 仍读到同一快照。用同团队非项目成员验证不可读，另从同一会话取超过 64 KiB 的范围验证实际响应。
4. 记录响应示例、复跑方法、已知存储缺口，更新 Task、Todo 与看板。后续停点按 Task 单独推进。

可演示结果是两次 GET 返回同一份固定正文、来源、范围与摘要，且非成员读取返回 404。

### 本机复跑

在空的隔离 MySQL 数据库上先执行 [schema.sql](../../../services/collaboration-server/src/main/resources/db/schema.sql)，再执行 [demo-data.sql](../../../services/collaboration-server/src/main/resources/db/demo-data.sql) 准备演示账号和项目。沿用 [README 的 Java 启动方式](../../../README.md#显式启动-java-数据基础)设置 JDK 21、Maven 和数据源。在仓库根目录执行以下构建及契约命令。

```sh
npm run server:build
npm run contracts:smoke
npm run server:contracts
npm run server:start
```

服务启动后，在另一个终端运行冒烟。使用自选端口时一并设置服务的 `SERVER_PORT`、`WORKBENCH_ORIGIN` 和脚本的 URL 参数。

```sh
node scripts/workbench/smoke-snapshot.mjs http://127.0.0.1:18084
```

脚本打印固定快照和权限、字节边界结果。它会创建演示设备、会话和三份快照，以便在隔离库复查 `wb_snapshot` 的 `OCTET_LENGTH(text)`、`SHA2(text, 256)` 和 `storage_uri`。脚本每次使用新的设备和来源会话 ID。

## 停点二 产品任务

1. 完成任务表、审计、材料链接和事务请求回执，补齐 Java 与共享契约。
2. 实现创建指派、详情列表、角色流转、关联与审计。固定知识引用随停点三联通。
3. 隔离库冒烟发布到完成，核对原响应重放、过期版本、角色和本机会话关联。

## 停点三 团队知识

1. 新增团队条目与固定版本表，按团队术语键保证唯一，落地列表、历史和归档。
2. 将已提交的条目版本接入集群检索，standalone 保留本机查询。补齐任务的固定知识材料校验。
3. 冒烟新建、编辑、读老版本、搜索和归档，记录集群实际覆盖。

## 停点四 看板与通知

1. 接通现有简报和在线心跳，按成员组织会话与任务。将任务、知识、快照、简报和成员变更接入通知端口。
2. 同事务保存轻量通知，按用户和游标分页、重连续读，接入集群 Kafka 信号。
3. 冒烟聚合、用户过滤和重连。完成共享契约、工程检查、卡片和看板回写。

### 停点二至四本机复跑

用上文相同命令准备空库并启动服务，再运行：

```sh
node scripts/workbench/smoke-collaboration.mjs http://127.0.0.1:18084
npm --workspace @workbench/contracts run typecheck
npm run project:check
```

脚本写演示设备、会话、任务和知识，检查同编号并发创建、角色和反向关联、历史版本、术语搜索、心跳、用户事件实时接收及断线补读。复跑集群模式时，通过 `WORKBENCH_MIDDLEWARE_MODE=cluster` 和 application.yml 中同名环境属性配置 Redis、Kafka、ES。Kafka 准备 `wb.search.index` 与 `wb.collab.notifications` 主题，每个 Java 节点配置不同的 `WORKBENCH_MIDDLEWARE_NODE_ID`。ES 创建或允许按现有动态映射方式创建 `wb_knowledge_v1`；已有模板需支持 `workspaceId/termKey/category/knowledgeId` 的 `.keyword` 字段以及 `archived` 布尔字段。知识搜索在索引可见后才返回匹配项。
