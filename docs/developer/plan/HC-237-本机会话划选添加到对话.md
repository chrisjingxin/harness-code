# HC-237 本机会话划选添加到对话计划

[规格](../spec/HC-237-本机会话划选添加到对话.md)

1. 建立 HC-237 任务文档并更新用户指南说明。
2. 扩展 `shared/personal.ts` 与 `PersonalStore` Schema 支持可选 `draft.annotations`（含 `comment`），在 `ui/conversation/` 实现纯编解码与行号计算模块 `annotations-codec.ts` 与相关类型导出。
3. 实现通用划选浮窗 `SelectionToolbar` 及文件/Diff 来源与行号解析，并接入时间线、中央文件/Diff 分屏与执行计划预览。
4. 实现输入框行内引用块与上方编辑浮层（同时支持编辑所选文本与追加批注，纯表意图标）、用户消息气泡折叠引用展示与浅深双主题样式。
5. 完成会话状态管理、发送/排队/追发拼装、`extractFileAttachments` 隔离及 `hc206-preview` 适配，补齐单测并运行类型、构建、测试、边界和项目检查。
