# HC-220 项目看板与轻量通知实施计划

按 [Spec](../spec/HC-220-项目看板与轻量通知.md)推进，服务端基线为 `acf2600`。桌面代码先在本卡独有文件里落地。公共装配由统筹协调 HC-219 交出文件后串行写入。

## 停点一 独立看板

1. 在 `features/board/` 将 HC-212 聚合映射成成员及任务列，复用头像、主题和 HC-218 同步状态。
2. 保留会话和任务定位回调。使用响应形状的样例在独立预览或本地构建中打开看板，确认窄宽度布局。

## 停点二 聚合查询

1. 消费具名看板端口，按项目切换查真实聚合，显示加载、空态、截断、失败和手动更新。在原页面数据存在时合并后台刷新。
2. 宿主由现有身份和网络客户端发出 GET。使用隔离 MySQL 和 Java 演示数据确认查询。串行接入正式页面及定位。

## 停点三 轻量更新

1. 使用现有认证客户端接入 SSE，校验帧和载荷。主进程管理范围、重连和游标文件，preload 只提供固定动作和事件。
2. 在账号和团队外壳层启动订阅。调用 HC-217/218/219 的刷新入口，项目变化不新建流。当前页面保留手动刷新路径。
3. 走正式窗口的必要主路径，记录从看板定位、后台事件更新、正文仍未下载、退出取消连接的实际证据。运行受影响构建、类型及边界检查。
