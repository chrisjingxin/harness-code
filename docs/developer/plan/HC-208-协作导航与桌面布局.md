## 1. 唯一可演示停点：协作导航与三栏骨架

一次交付可打开的左侧导航和三栏布局，在隔离 Electron 预览中用受控数据展示一个普通账号、工作区、设备/项目与会话；用户展开项目并选择会话后，中间显示既有 `ConversationView`，右侧显示既有 `ProjectDock`。顶栏显示该会话及其原设备/项目；搜索过滤已加载条目。设置以居中弹窗打开；待接手未接入时仅显示状态说明。预览中的动作只更新夹具，不能证明真实业务或 ACP 已接通。

实施依次完成输入/动作及导航、顶栏和自适应布局、隔离预览；这些是同一可见停点的内部步骤，不分别要求窗口验收。源码就绪回调统筹并冻结本区，待共享接入和独占构建/窗口时隙派发后做必要检查与一条正常路径冒烟；结束回调一次并等待统筹复核，不自动推进其他任务。

## 2. 实现边界和数据流

`packages/workbench-ui/src/navigation/` 独占导航组件、类型、动作及其样式；`packages/workbench-ui/src/layout/` 独占协作顶栏、三栏布局、面板开合及其样式。实际文件拆分可调整，但不修改其他区域源码。仅消费 HC-205 公共主题变量与公共品牌/图标；不改公共色表。`NavigationView`、`CollaborationContextView`、`LayoutView` 与具名动作按 Spec 实现，根出口使用有区分度的 `Navigation`/`Collaboration`/`WorkbenchLayout` 名称，具体导出清单在源码回调时交统筹确认，不新增线上协议。

宿主输入账号、工作区、设备/项目及同一会话的共享入口、当前选择、分页和各自可用状态；身份范围为 `namespace/accountId/workspaceId`，原项目另带设备和项目 ID。用户动作通过 Spec 的 `selectWorkspace`、`createConversation`、`selectConversation`、`toggleDevice`、`toggleProject`、`setSearch`、`loadMore`、`openPendingHandoffs`、`openSettings`、`signIn`、`signOut`、`setPanelOpen`、`retry` 回传，是否可用及原因由宿主提供。新建入口和空态共用动作，不能自行选 Agent。搜索只过滤已加载内容，保留清空前展开状态；共享更新仅更新输入，不改变当前选择或草稿。加载、空、失联、无权、待接手和未接入按 Spec 区分；待接手未接入不提供伪操作。账号先退出再登录及工作区失败规则由宿主负责，组件只展示其状态和发出意图，不缓存凭据或恢复旧身份。

左栏默认 280 逻辑像素，两侧允许受限调整，内部独立滚动；优先保障中央可用宽度。实施时根据左右面板最小可用宽度和中央阅读最小宽度确定断点：不足三栏总最小宽度先收右，不足左栏与中央总最小宽度再收左；断点采用实际容器宽度并在代码中集中定义，避免沿用旧页面整页最小宽度。窄窗覆盖面板、Escape、焦点恢复、用户手动偏好与自动收合分离均遵循 Spec；尺寸或缩放不依赖固定高度。设置由注入内容与居中弹窗承载，维护焦点，真实设置功能由装配方提供。

中央、右侧为插槽；预览从 `@workbench/ui` 公开出口消费 `ConversationView`、`ProjectDock` 和中央文件部件 `ProjectFileTab` / `ProjectFilePanel`，并加载已有 `conversation.css`、`project.css` 和 `theme.css`。中央文件仅在受控预览展示部件接合，不在 HC-208 实现总页签或复制消息、输入、文件树和 Git。HC-202 负责真实业务数据与动作、创建成功后的选择、原生窗口拖动/点击区及跨区页签和焦点协调；HC-198 负责真实交接和引用，HC-199/196 负责项目服务路径。ACP 发现、配置、能力、运行及接线调试等待同事交付；不启动或模拟 ACP。

右侧 `ProjectDock` 已有关闭按钮和拖宽控件，继续由它发出 `setDockOpen` 与 `setDockWidth`。预览装配按宿主唯一的右栏偏好给布局输入，由右侧插槽将布局计算的有效开合与宽度投影到 `ProjectPersonalView.dockOpen` 和 `dockWidthPx`。覆盖面板的关闭与宽度限制由布局协调。正式装配沿用同一接点。[ProjectDock](../../../packages/workbench-ui/src/project/project-dock.tsx)
