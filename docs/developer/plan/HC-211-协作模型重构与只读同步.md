### 步骤三，可演示停点

为本轮建立独立资料目录、MySQL 数据目录与回环端口，按唯一 schema.sql 和 demo-data.sql 初始化。

```text
A 登录并登记 Project 本人会话
 → Cookie + CSRF 上传两条定稿和简报
 → Java 回执与 MySQL 会话水位为 2
 → B 读到简报
 → B 主动 afterSequence=1 仅读取第二条正文
```

同一会话附带最少判定，重复同批返回 2 且无重复正文，跳号返回 409 与 expectedSequence=3，B 上传本人以外会话返回 403。实际发现缺口时仅修现行链路的相关实现。

查看方式为必要 HTTP 冒烟输出、Java 访问日志、证据 JSON 和 MySQL 会话行。结束本轮启动的进程，保留日志。
