# 个人与团队协同工作台交互原型（当前基线）

本目录是采用「56px 固定全局图标栏 + 304px 双模悬浮卡片次级侧栏 + `no-sidebar` 宽屏业务页」信息架构的最新正式交互原型，结合 Harness Code [个人与团队协同用户旅程](../../architecture/个人与团队协同用户旅程.md)（`HC-233`、`HC-239`～`HC-254`）与未来 Playbook / SOP 扩展需求设计。

> 本原型已取代原单层侧栏原型 [personal-team-workbench（已过期）](../personal-team-workbench/README.md)；仅作交互与视觉对照，**不进入正式桌面应用或服务端生产打包**。

## 本地运行与构建

```sh
# 启动本地开发预览服务（默认 http://127.0.0.1:57843/）
npm run preview:workbench

# 仅执行生产静态产物构建（输出至 tmp/collaboration-workbench-preview）
npm run build:workbench-preview
```

## 与原方案 B 原型（已过期）的核心结构差异

| 维度 | 原方案 B（`personal-team-workbench`，已过期） | 当前正式原型（`collaboration-workbench`） |
| --- | --- | --- |
| **一级导航** | 单层 264px 侧栏内做「个人 / 团队」分段切换 | **56px 固定图标栏（Rail）**，顶部分区为「工作台 / Inbox / 看板 / 知识与地图 / Playbook · SOP」，底部为「搜索 / 管理与设置 / 个人头像」 |
| **次级侧栏** | 固定为会话列表 + 团队功能混排 | **304px 圆角悬浮卡片双模侧栏**：工作台模式展示「个人会话（按目录）+ 团队协作会话（按 Project）」；管理模式切换为 1200px 管理后台导航；Inbox / 看板 / Playbook 自动隐藏次级侧栏释放宽屏 |
| **空会话体验** | 居中提示按钮，先弹窗再进入对话 | **零弹窗首屏直接开聊**：默认呈现居中输入框 + 目录/团队上下文胶囊 + Playbook 快捷起步卡 |
| **长回合与故障排障** | 静态时间线 | 增加 **生成中消息排队托盘 +「引导」插队** 与 **分阶段现场诊断卡**（`HC-254` 前移） |
| **管理与企业治理** | 全部塞在居中弹窗 `#dlgSettings` 中 | 个人外观/视角放在 **左下角头像 Popover**；团队成员交接（`HC-240`）、模型网关（`HC-244`）、团队 Skills/MCP（`HC-245`）、出口脱敏与审计（`HC-249`）拆入独立 **1200px 居中管理台** |
| **右栏与徽标** | 文件树 + 变更两页签，多种标签样式 | 新增 **产物预览**（Markdown 排版/源码、SVG/Mermaid 图表），全站收敛为统一的 `.hui-badge[data-tone]` 状态徽标 |
