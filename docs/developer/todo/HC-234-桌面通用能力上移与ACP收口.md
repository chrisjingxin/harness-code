## 停点 1 · 桌面直接改名

- [x] 扩展个人会话记录的 `customTitle`。旧记录可读，所有改写入口在主进程校验本人会话，个人设置的并发保存保住其他字段。
- [x] 合并手动、Agent 建议与服务端标题。左栏、顶栏和搜索读取同一结果，重启后未打开的本人会话显示已保存标题。
- [x] 接左栏改名菜单，处理空值、确认、取消与保存失败。确认相同的 Agent 建议可固定为手动标题。
- [x] 用个人存储和会话模型的现有测试验证归属与标题优先级。正式窗口演示改名、重启和外部 Agent 标题更新，记录证据并回调统筹。

## 停点 2 · 轮次 Diff 与隔离工作树回退

- [x] 在 `project-service` 接入限时隔离索引快照、本机轮次索引与引用校验。主进程在 prompt 前抓基线，在确认已停止写入后抓终态，协调同一目录的下一轮和回退。捕获失败时按 Spec 显示快照不可用。
- [x] 用受限 IPC 按轮次获取变更文件和单文件 Diff，接现有文件变更视图。普通 Git 根目录可查看，非 Git 目录可照常发消息。
- [x] 核对专用 linked worktree、原目录实体及本机重叠目录记录。预览待改写文件并要求确认。保护快照、忽略路径或目录冲突校验未通过时拒绝写入。
- [x] 实现只改文件的还原与保护快照恢复入口。报告部分写入，刷新右侧文件树和 Diff，保住用户索引、HEAD 和分支。
- [x] 移除中文文本匹配卡片及调用。若提供 Harness 对话撤销提示，使用现有 `conversation` 模式。
- [x] 用临时仓库验证共享、忽略文件冲突、部分失败和暂存区。正式窗口演示轮次 Diff、专用工作树回退及非 Git 发送，记录证据并回调统筹。

## 停点 3 · ACP 兼容与 Harness 扩展

- [x] 将可信宿主传入的附加目录和 MCP 参数接到建会、加载和恢复，按 SDK 能力协商过滤，保留诊断。
- [x] 合并 v1 `modes` 和 `mode` 类配置，覆盖初始化响应、配置更新通知及写入响应。验证一个选择器与正确 RPC 路由。
- [x] 覆盖恢复成功、回放静默、无帧硬超时和迟到帧。校验 `strict` 和 `fallback-new` 的绑定与进程处理。
- [x] 复用同会话本机定稿缓存，最多一次向重建后的新会话发送 8 KiB 历史引用，验证绑定时和发送时重置，以及定稿上传保留用户原文。
- [x] 按协商结果接 Harness 元数据，展示父子工具卡、审批作用域、旁路和用量。上传入口排除 `ephemeral` 轮次，`historyChanged` 使用既有同步规则。
- [x] 执行 ACP 一致性与上传回归。正式窗口最小验证标准 Agent 和 Harness 的相关路径，记录实际环境和证据并回调统筹。
