## 冻结的非范围

- 不使用 1.6.0、版本范围、混合平台包、下载/升级/缓存自愈或系统 Node。
- 不创建 `.codegraph/`、`.harness/index`、symlink/junction、fork、runtime patch、Git hook 或根 `.gitignore` 修改。
- 不把 raw MCP tool 注入模型，不公开 node/search/callers/status，不让 Plugin Agent 自动继承。
- 不让索引结果绕过 Snapshot，不中断 active Run 来重建，不自动删除 incomplete 数据或外部进程。
- 不阻塞全部对话，不伪造百分比，不透传 stderr/供应商名，不承诺固定收益。
- 不建设图浏览器、向量库、跨仓库后台服务、通用 benchmark 平台或新发布流程。
- 发现需要改变 protocol、数据形状、版本、生命周期或用户行为时，先修订 Task/Spec/Plan；不得在 Todo 执行中自行决定。
