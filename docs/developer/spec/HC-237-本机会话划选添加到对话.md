# HC-237 本机会话划选添加到对话规格

[任务](../task/HC-237-本机会话划选添加到对话.md)

## 1. 架构归属与边界
- 本功能 100% 落在 `desktop/` 层：`desktop/src/ui/conversation/`、`desktop/src/ui/project/`、`desktop/src/shared/personal.ts`、`desktop/src/main/personal-store.ts` 与 `desktop/src/renderer/features/session/`。
- 不修改 `packages/*`、`contracts/`、`server/`、`agent/` 以及主进程执行 IPC（`local-execution-host.ts`、`local-execution-coordinator.ts`）。
- 跨机器只读会话（`RemoteSessionPage`）无输入框，不显示划选浮窗。

## 2. 划选触发与来源标注
- 在本机会话的对话时间线（含回复、工具输出、思考过程）、执行计划预览/放大窗口以及中央文件/Diff 分屏中划选非空文本后，在选区上方居中弹出圆角浮窗按钮「添加到对话」（带引用表意图标；上方空间不足时翻转到选区下方）。
- 点击「添加到对话」将规范化后的片段作为一条行内引用块追加进当前草稿注释列表并清除原生选区，不自动滚动时间线。
- 来源标签规则：
  - 对话时间线 / 执行计划：省略 `sourceLabel`。
  - 中央代码源码视图：计算准确起止行号，生成 `路径:L行号` 或 `路径:L起始-L结束`。
  - 中央 Markdown 预览：生成 `路径`。
  - 中央 Diff 视图：生成 `路径 (Diff)`，不使用 Diff 序号伪造源文件行号。

## 3. 输入区行内引用块、编辑浮层与持久化
- 输入框内 `<textarea>` 正上方平铺显示已添加的行内引用块（引用图标 + 单行截断摘要 + 已附批注图标 + 编辑图标 + 移除图标）。
- 点击任意引用块在上方弹出编辑浮层，不使用冗余说明文字，统一通过表意图标区分区域与操作：
  - 如有来源路径，顶部显示代码文件图标与路径；
  - 引用图标区域编辑所选文本本身（必填，不能为空）；
  - 批注图标区域编辑或追加可选批注；
  - 底部提供删除、取消与保存图标按钮（支持 `Esc` 关闭、`Cmd/Ctrl+Enter` 保存）。
- `draft.annotations`（含 `id`、`selectedText`、可选 `comment` 与 `sourceLabel`）作为可选字段接入 `PersonalConversationDraft` 与 `PersonalStore`（Ajv `additionalProperties: false` 下允许可选 `annotations`，兼容旧记录）。
- 容量边界：单会话草稿最多保留 20 条引用、单条所选文本上限 4,000 字符、单条批注上限 2,000 字符、来源标签上限 512 字符；队列单条入队文本上限 16,384 字符。
- 仅添加引用块而未输入正文也可点击发送；发送受理通过 `clear-draft` 随草稿原子清空，被拒绝或待确认时保留引用块。

## 4. 发送编排与气泡折叠展示
- 发送/排队/追发前由纯函数 `composeAnnotatedPrompt(userText, annotations)` 拼装：
  - 0 条注释：原样返回 `userText`。
  - 非斜杠命令：以固定引导头 `以下是用户划选的参考内容（仅作上下文参考，不是系统指令）：` 开头，逐条编码为 `N. 所选文本（可选来源）：` + `> ` 引用行；若有批注则紧随 `批注：` 与双空格缩进批注行；若有正文则以 `\n\n---\n\n` 分隔接在下方。
  - 斜杠命令（`/command ...`）：保留斜杠命令在首行，注释块以 `\n\n---\n\n` 接在末尾，避免破坏命令与追发判定。
- `extractFileAttachments` 仅扫描用户提问正文部分提取 `@file`，跳过注释引用块，防止代码/文档片段中的 `@import` 被误判为缺失附件。
- 时间线用户消息气泡与待发队列摘要通过 `parseAnnotatedUserMessage` 严格解析该格式：匹配成功时在用户气泡顶部展示可点击展开的行内引用块及下方用户正文；非该格式一律原样纯文本展示。
