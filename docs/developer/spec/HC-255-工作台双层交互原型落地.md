## 1. 现状痛点、解决思路与改后收益

### 1.1 现状痛点

1. **双套外壳割裂与切换重建**：当前 [desktop-workbench.tsx](../../../desktop/src/renderer/desktop-workbench.tsx) 中，个人空间与离线/未入团态渲染外层 `WorkbenchLayout`，在线团队态则切换到 `WorkspaceProjectWorkbench` 内部渲染另一套 `WorkbenchLayout`。切换个人与团队、或从个人会话打开全局 Inbox 时需要跨越两套壳层，容易导致布局跳变与快捷键行为不一致（例如 `⌘K` 全局命令面板仅在团队 `ProjectWorkbench` 内挂载）。
2. **导航层级混杂、宽屏利用率低**：原单层 280px 左栏（[navigation/index.tsx](../../../desktop/src/ui/navigation/index.tsx)）同时承载「个人｜团队」切换、收件箱入口、Workspace/Project 切换、看板/任务/知识页面跳转、会话列表和设置按钮。进入 Inbox、看板、任务、团队知识等宽屏业务页面时，次级侧栏仍常驻占宽，削弱了四列看板与双栏审阅的视野。
3. **看板与任务入口分散，详情跳转断层**：已实现的项目看板（`HC-220`）和项目任务（`HC-219`）分别占据左栏不同入口；点开任务详情会整体替换掉看板视图，缺乏宽屏下「卡片 → 右侧滑出抽屉」的顺畅闭环。
4. **高频开关与深度配置全部堆叠在居中大弹窗**：浅/深色切换之外，强调色、密度、缩放、IM 通知偏好、快捷键、账号登录和团队成员交接全挤在 `.collaboration-modal` 弹窗中纵向滚动，既无分组导航也无法直接利用 1200px 宽屏排版。
5. **各区域局部视觉语言尚未彻底统一**：对话元信息栏、排队托盘、跨机只读底部栏、Inbox、看板和知识页各自保留了一部分过渡期局部样式类名与徽章写法，折叠与浮层过渡缺少一致的因果动效规范。

### 1.2 解决思路与改后收益

- **统一单壳层 × 56px + 304px 双层架构**：在渲染层收敛为唯一 `WorkbenchLayout` 外壳（56px 固定全局图标栏 `AppRail` + 304px 双模次级侧栏 + 主工作区），工作台会话树只负责「个人｜团队」会话列表，全局业务切换上收至 56px Rail，宽屏业务页（Inbox / Project 看板 / 团队知识）自动进入 `no-sidebar` 1200px 居中模式。
- **高频在头像，治理进管理台**：左下角头像弹出轻量 `UserPopover`（账号态 + 浅/深色切换 + 直达管理台 + 退出）；深度配置（外观密度缩放、快捷键、IM 通知偏好、本机目录记忆、账号与成员离职交接/仓库目录）统一迁入 `nav === "admin"` 的 1200px 管理台，彻底退役居中设置大弹窗。
- **Inbox 与看板按心智模型双入口分离，任务融入看板**：`Inbox` 专注“等我拍板清零”的跨团队队列与本机等待跳回提醒；`Project 看板` 承载“项目全局态势”，融合状态四列、成员进展与右侧滑出 `.t-drawer` 任务详情抽屉。
- **100% 忠实于已交付后端与本地能力**：严格只还原已开发完成的真实功能，未开发模块不入生产 UI、不造假数据，确保每次点击均有真实接口或本地持久化响应。

### 1.3 主干交互链路（输入 → 判断 → 执行 → 输出）

```text
[用户触发导航 / 快捷操作]
  ├─ 点击 56px Rail（工作台 / Inbox / 看板 / 知识 / 管理与设置）
  │    → 判断目标视图模式：
  │       ├─ 工作台：展开 304px 次级侧栏（「个人｜团队」会话树）
  │       ├─ 管理台：展开 304px 管理分组导航 + 主区 1200px 居中设置页
  │       └─ Inbox / 看板 / 知识：置 `no-sidebar=true`，平滑收起次级侧栏，释放 1200px 宽屏舞台
  ├─ 在工作台发布个人会话 / 停止共享
  │    → 判断操作终态（成功）
  │    → 自动切到目标「团队」或「个人」Tab + 展开所属 Project/目录分组 + 触发 750ms `row-land` 脉冲高亮
  ├─ 在看板点击任务卡片 / 从 Inbox 或 DeepLink 直达任务
  │    → 判断来源上下文（是否来自 Inbox）
  │    → 切到目标 Project 看板并从右侧滑出 `.t-drawer` 抽屉展示任务详情（附「返回收件箱」顶栏按钮）
  └─ 按下 `⌘K` 或点击左下角搜索按钮
       → 无论当前处于个人还是团队空间，均打开全局 `CommandPaletteModal`
       → 基于当前已加载元数据实时过滤，回车直达会话 / 任务 / 知识或切页
```

## 2. 全局不变量（Invariants）

以下底线在本卡全阶段强制遵守，任何阶段不得突破：

1. **纯 UI 边界红线**：
   - 改动范围严格限定在 `desktop/src/ui/`、`desktop/src/renderer/`、前端单测 `desktop/tests/` 与 `docs/`。
   - **严禁修改** `server/`、`agent/`、`contracts/`、`packages/` 以及 `desktop/src/main/`、`desktop/src/preload/`、`desktop/src/shared/` 既有 IPC 与数据契约。
2. **零假数据与零空壳入口（继承 `HC-225`）**：
   - 原型中尚未实现后端/内核能力的区域（Playbooks/SOP、团队系统地图 SVG、知识分级提案审核与命中足迹、跨机只读异步批注、企业模型网关、受控 MCP、组织审计、一键脱敏诊断包、右侧产物 Artifacts Tab）**不得出现在生产导航、设置菜单或界面卡片中**，更不得使用静态假数据填充。
3. **单壳层状态保活与草稿不丢失**：
   - 在个人会话、团队会话、Inbox、看板、团队知识与管理台之间切换时，已挂载的对话输入草稿、滚动锚点与后台运行态监听必须持续保留；不得因切入宽屏页或管理台而销毁 `PersonalSessions` 或 `ProjectSessions` 运行态。
4. **团队侧栏防请求风暴（继承 `HC-225`）**：
   - 团队会话模式在 304px 次级侧栏以 Project 手风琴形式组织列表；但遵循现有后端按单 Project 拉取会话的契约，**仅当前激活 Project 默认展开并实时拉取/订阅会话条目**，其余 Project 保持折叠状态（可显示缓存或待点击状态），用户点击未激活 Project 标题行时再切换激活并加载其会话，严禁一次性并发拉取全部 Project 的会话列表。
5. **本机审批与云端收件箱严格隔离（继承 `HC-246` 方案 A）**：
   - 本机会话的 `waiting_approval`（工具权限、Plan、Goal、澄清问答）和 `error` 状态只留在原会话时间线中批准或处理；Inbox 顶部仅保留纯本机内存态的「本机等待你确认」跳转条，点击「回到会话处理」跳回原会话，绝不混入云端待办计数或同步到服务端。
6. **既有独立预览与持久化数据向后兼容**：
   - [layout/index.tsx](../../../desktop/src/ui/layout/index.tsx) 新增的 `rail`、`noSidebar`、`railHeaderSpacer` 等属性均保持可选，确保 [hc217-preview](../../../desktop/src/renderer/hc217-preview/main.tsx) 与 [hc218-preview](../../../desktop/src/renderer/hc218-preview/main.tsx) 无需重写即可通过构建与类型检查。
   - `PersonalStore` 既有的 `ProjectPage`（含 `{ kind: "tasks" }` 与 `{ kind: "task", taskId }`）及 `workbench://open/task?...` DeepLink 解析结果，在渲染层自动映射到统一 `Project 看板` 并打开对应 `.t-drawer` 任务详情抽屉，不更改磁盘持久化 schema。

## 4. 双层导航外壳与顶栏规格

### 4.1 56px 固定全局图标栏（`AppRail`）

1. **布局与安全区**：
   - 宽度固定 `56px`（`--rail-w`），背景 `--rail-surface`，右侧 `1px` 分隔阴影 `inset -1px 0 0 var(--border)`。
   - **Electron macOS `hiddenInset` 适配**：`is-macos` 状态下，56px Rail 顶部预留 `38px` 原生红绿灯避让区（`-webkit-app-region: drag`），避免窗口控制键与品牌标识/首枚导航按钮重叠；顶部所有按钮均设 `-webkit-app-region: no-drag`。Windows 与 Linux 直接从顶部内边距起排。
2. **入口清单（仅保留已开发功能，不摆空壳）**：
   - **顶部主导航（4 个）**：
     1. `工作台`（`chat`）：个人 & 团队会话主页；当团队存在未同步队友会话更新时右上角展示细微 `--accent` 圆点（当前未激活时显示）。
     2. `Inbox`（`inbox`）：全局待办收件箱（`HC-246`）；有云端 `actionRequired > 0` 时展示右上角 `--accent` 数字角标；若仅本机存在 `waiting_approval`/`error` 且云端角标为 0，展示独立琥珀色提醒点（绝不混入云端数字）。
     3. `Project 看板`（`board`）：合并后的 Project 看板与任务工作区（离线或未入团时点击显示友好的离线/未入团空态与重连引导）。
     4. `团队知识`（`knowledge`）：团队知识库与版本历史（离线或未入团时展示对应引导空态）。
   - **底部全局工具（3 个）**：
     1. `全局搜索 (⌘K)`：打开跨空间 `CommandPaletteModal`。
     2. `管理与设置`（`admin`）：进入 304px 管理分组导航 + 1200px 管理台。
     3. `个人头像`（`UserPopover` 触发器）：展示当前登录用户头像与状态绿点（离线/未登录展示对应状态色）。
   - **激活态样式**：左侧紧贴边缘渲染 `3px` 圆角高亮竖条（`--accent`），图标着色 `--accent-text`，底色 `--selected`。

### 4.2 左下角个人头像 `UserPopover`

- 锚定在头像按钮右侧（`bottom` 对齐，`position: fixed`，逃逸容器裁剪）：
  - 展示当前账号头像、姓名、工号/角色与在线状态（在线 / 离线快照）。
  - 提供「外观主题」二分段快捷切换（跟随系统 / 浅色 / 深色）。
  - 提供「打开管理与设置 →」快捷跳转与「退出登录」操作（退出前仍沿用 `persistence.flush()` 安全落盘保护）。

### 4.3 统一顶栏（48px）与收展控制

- **顶栏结构**：`[侧栏开关(非宽屏时显示)] [窄屏抽屉按钮(≤980px显示)] [返回按钮(跨机只读或从Inbox直达任务时显示)] [标题与上下文胶囊] [弹性留白] [协作成员胶囊(团队共享会话时)] [全局快捷键/主题快速按钮] [右侧工作区开关]`。
- **宽屏自动隐藏次级侧栏（`no-sidebar`）**：当 `nav` 为 `"inbox" | "board" | "knowledge"` 时，次级侧栏通过 CSS `transform` 与列宽收敛平滑隐藏（`grid-template-columns: var(--rail-w) 0px minmax(0, 1fr)`），顶栏隐藏次级侧栏开关并将 macOS 红绿灯右侧安全边距让给返回按钮与页面标题。
- **≤980px 响应式降级**：次级侧栏变为抽屉浮层（`left: var(--rail-w)`），由顶栏菜单按钮与半透明遮罩 `.scrim` 控制开关。

### 4.4 全局命令面板（`⌘K`）

- 从原仅限 `ProjectWorkbench` 内挂载提升至统一单壳层：
  - **个人空间 / 离线态**：支持实时搜索本机个人会话（按标题与目录路径匹配）及快捷切换页（工作台 / Inbox / 管理与设置 / 新建个人会话）。
  - **在线团队态**：在同一列表内分组呈现「我的个人会话」「当前 Project 会话」「队友会话（只读）」「当前 Project 任务」「团队知识」；选择后自动切到对应空间/视图并定位到条目（任务则打开看板并弹出 `.t-drawer`）。

## 5. 304px 双模次级侧栏与 1200px 管理台规格

### 5.1 工作台模式（「个人｜团队」严格分栏）

1. **顶部栏与空间切换**：
   - 标题栏「工作台」+ 收起按钮（`⌘\`）。
   - 分段切换器「个人（显示本机未发布+已停止数量） | 团队（队友有未同步更新时显示蓝点）」，切换即刻响应，不卸载背后活跃会话。
2. **「个人」空间列表**：
   - 顶部操作行：`新建个人会话` 主按钮 + `⌘K` 快捷搜索按钮，并保留内联快速过滤输入。
   - 按工程目录折叠分组（无目录归入「未选目录」），支持目录分组展开/收起记忆、右键/悬浮重命名、发布到 Project、以及提示“另有 N 个已发布会话在「团队」页签下”。
3. **「团队」空间列表**：
   - 顶部操作行：`新建协作会话` 主按钮 + `⌘K` 按钮。
   - **Workspace 切换胶囊**：展示当前 Workspace 色点、团队名称、本人角色（管理员/开发者）与下拉菜单切换团队。
   - **Project 手风琴列表**：展示当前 Workspace 下有权限的 Project，每个 Project 行右侧 hover/focus 时显示资料与成员设置齿轮按钮（直接打开 `ProjectInfoPage`）；底部提供「新建 Project」。
   - **单激活 Project 渲染约束（防请求风暴）**：仅当前激活 Project 默认展开其内部「我的会话（含 `我` / `仅摘要` 标签）」与「队友共享会话（含头像、最近时间、未同步蓝点）」，点击其他 Project 行时切换 `selectProject` 并加载其会话。
   - **离线 / 未入团空态**：若当前无团队或处于离线状态，次级侧栏显示简洁引导卡片（个人会话不受影响 + 一键重连或回到个人空间）。
4. **跨轨落位动效（`row-land`）**：
   - 个人会话发布到 Project 成功、或停止共享移回个人空间时，自动切换对应空间 Tab、自动展开目标 Project 或目录分组，并为目标会话行施加 750ms `row-land` 高亮脉冲。

### 5.2 管理模式（`nav === "admin"`）

1. **次级侧栏分组菜单（只放已实现项）**：

## 8. 用户旅程与动效规范（`impeccable` + `stageshow`）

### 8.1 核心用户旅程回检（6 条必通路径）

1. **零弹窗个人起步**：登录后零弹窗进入个人工作台首屏 → 选目录/看预检 → 发消息自动新建个人会话并无缝切换到对话时间线（无界面跳闪）。
2. **个人会话发布到团队与停止共享**：在个人会话顶部点「发布到 Project…」→ 选目标 Project 与档位 → 确认后自动切至「团队」Tab、展开目标 Project 并触发 `row-land` 脉冲高亮；点「停止共享」自动切回「个人」Tab 并同样落位高亮。
3. **运行中排队与「引导」插队**：Agent 输出期间发消息进入紧贴输入框的 `.queued-tray` → 队列行顺滑展开，支持点「引导」立即打断并追发或编辑/删除。
4. **Inbox 中断处理与回跳闭环**：后台本机会话卡在审批时，56px Rail 的 Inbox 图标出现琥珀色指示 → 点入 Inbox 见置顶跳回条，点「回到会话处理」精准回原会话批准；处理云端 `todo`/`review` 任务可直接审批或在看板 `.t-drawer` 内接手后一键「返回收件箱」。
5. **看板全景与任务执行闭环**：在 `Project 看板` 切换 `状态四列 ↔ 成员进展` → 点卡片滑出 `.t-drawer` → 接手并在本机选目录开聊，直接跳转工作台开始执行。
6. **全局 `⌘K` 与快速外观切换**：个人或团队任意页面按 `⌘K` 检索定位；左下角点个人头像在 `UserPopover` 毫秒级切换浅/深色，不中断当前输入或任务阅读。

### 8.2 Motion Thesis（因果动效与预算）

| 动效类别 | 触发场景 | 缓动与时长 | 实现手段与性能预算 |
| --- | --- | --- | --- |
| **Focal Moment（唯一焦点脉冲）** | 会话跨轨发布/停止共享落位 | `row-land` `750ms` `--ease-flow` | 仅在目标新落位单行触发一次，使用柔和 `--accent` 背景与内环淡出 |
| **结构容器收展** | 次级侧栏宽屏自动隐藏/展开（`no-sidebar`） | `200ms` `--ease-flow`（收起 `140ms`） | 使用 `transform` / `opacity` 与外层网格平滑切换，禁止内部文字重排闪动 |
| **局部手风琴折叠** | 目录分组、Project 分组、时间线思考/工具组、排队托盘 | `190ms` `--ease-flow` | CSS Grid `grid-template-rows: 0fr → 1fr` + `opacity`，无需 JS 测量高度 |
| **抽屉与浮层出入** | `.t-drawer` 任务抽屉、`UserPopover`、`CollabMembersPopover`、`CommandPalette` | 入场 `190–220ms` `--ease-flow`；退场 `130ms` `--ease-standard` | 使用 `transform` + `opacity`（慢进快出），支持 `Esc` / 遮罩即时打断 |
| **控件微反馈** | 按钮按压、Rail 激活态指示条、新 Inbox 角标跳动 | `100–140ms` `--ease-standard` | `transform: scale(0.97)` 与 `background`/`color` 过渡，禁止长会话列表 stagger 入场 |

- **`prefers-reduced-motion: reduce` 适配**：按 `impeccable` 无障碍底线，收敛空间位移动画（关闭位移滑入、脉动缩放），**保留**简短的透明度/高亮色状态反馈（例如 `row-land` 变为温和静态高亮淡出、选中边框与色块即时清晰可辨），不因减动效而丢失状态因果反馈。
