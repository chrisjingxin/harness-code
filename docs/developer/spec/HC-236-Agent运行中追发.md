# HC-236 Agent运行中追发规格

[任务](../task/HC-236-Agent运行中追发.md)

- Agent 忙时仍能排队。可对当前草稿或某条待发消息选择立即发送。只对当前轮具备追发能力的 Agent 开放。无该能力时保留排队。
- Harness 普通 Build 轮支持纯文本追发。下一次模型调用加入真实用户消息。当前模型已给出最终输出时，仍在原 Run 和原会话里接着处理已收到的追发。现有工具执行和审批按原规则处理。Compose、目标续跑、附件和固定引用先沿用排队。
- 追发绑定桌面当前轮及原生会话。同一轮仅允许一项等待确认，最多确认八条追发。发送失败时草稿或待发项还在原处，确认被当前轮接收后才在时间线展示。队列中的其他项顺序保留。取消、换 Agent、旧轮结束和拒绝都不会让追发落到另一个轮次。
- Harness 通过现有扩展命名空间协商。客户端按当前轮的能力和原生标识发请求。其他 Agent 的已知扩展经各自适配后走统一桌面入口。保持远端线上契约兼容。

## 输入框布局

- 底栏的 Agent／模型和权限入口紧邻。Agent／模型菜单左侧切换 Agent，右侧搜索并选择当前 Agent 的模型，按实际能力显示推理强度。权限菜单各档配图标，完全访问用警示色，选中后提示操作可能无需确认。Build / Compose 选择从输入框移除。
- 空草稿提示「输入消息 · @ 引用 · / 命令」。输入 `@` 或 `/` 打开候选菜单。
- 输入框只有一个主按钮。Agent 运行时，空草稿显示停止，有可发送内容时显示发送。发送将草稿加入队列，草稿清空后恢复停止。支持追发的会话可按 Command / Ctrl + Enter 追发草稿，或通过待发消息右侧的箭头追发指定消息。
