# HC-220 项目看板与轻量通知

以 [Task](../task/HC-220-项目看板与轻量通知.md)、原 `project-collaboration` 视觉预览（已清理）和 [HC-212 Spec](HC-212-协作应用与看板通知.md#停点四-看板与通知)为准。成员打开看板即可浏览最近简报和进行中的任务。停留在会话等其他页面时，桌面仍接收变更提示。

## 看板与定位

- 在 Project 中央区显示项目名和概况，按预览排列成员进展与任务列。用已确认的公共按钮、头像和浅深主题，宽度不足时换行，中央区域独立纵向滚动。
- 项目聚合来自 `GET /api/v1/workspaces/{workspaceId}/projects/{projectId}/board`。成员、会话及任务归属使用同一响应的 ID 和状态。服务端截断时说明最多展示最近 100 条，并提供会话导航、任务列表入口。待办、进行中和待验收对应响应中的 `todo`、`doing` 和 `review`。
- 每个成员和会话的设备在线以看板响应为准。最近上传使用简报时间，有已上传正文时显示。当前电脑的正文同步状态沿用 HC-218 本地水位与服务水位的比较，并单独标识本机会话。
- 用户点击会话后展开对应成员并选中会话，由 HC-218 判定本机或远端只读。点击任务进入 HC-219 对应详情。
- 手动刷新和后台刷新期间保留当前同范围数据与滚动。暂时失败保留已有数据并提示重试；认证失效、权限丢失或切换范围时移除该范围的可见结果。导航条任务数使用 HC-219 当前列表口径，完成接线后随任务元数据刷新。

## 轻量通知

- 主进程在当前已认证账号和选中团队的范围内维持一条 SSE，项目或页面切换共用此连接。复用同一个生产网络客户端、Cookie、Origin、版本头和现有身份代次。退出、切换团队、重载或关闭窗口立即取消旧订阅。
- 按服务端 `id` 递增处理，帧 ID、事件名与 JSON 字段须一致，心跳无业务动作。渲染端接受范围内的刷新意图后，宿主才保存游标。游标按服务 Origin、账号和团队隔离，重连发送 `Last-Event-ID`，首次从 0 开始。瞬时错误退避重连，认证或团队权限失败停止并提示；损坏帧保留最近已接受游标。
- `conversation.brief_updated` 通过 HC-218 刷新会话简报，并标记当前项目看板待刷新。`task.assigned` 和 `task.changed` 刷新相应项目任务元数据和看板。`knowledge.updated` 只使团队知识列表及版本提示更新。`project.member_changed` 刷新可见项目清单，当前项目受影响时同时刷新详情、会话和任务元数据。`snapshot.created` 不涉及上述数据的刷新。
- 同一批事件的刷新可以合并。其他项目下次进入时读取当前数据。页面定位、草稿、固定引用及正文下载继续由原入口控制。通知订阅状态在看板可见，暂时中断时可继续手动刷新。
