用户于 2026-11-10 确认按现有方案开发。侧栏搜索沿用已加载列表过滤，工作区和设置沿用本方案的位置。Lody 的共用搜索面板和侧栏底部入口留到后续讨论。范围、总体约束及参考来源见 [HC-208 Task](../task/HC-208-协作导航与桌面布局.md)、[顶层设计](../architecture/多人协作工作台顶层设计.md)、[并行开发约定](../project/协作任务并行开发约定.md)、[Lody 对照](../research/192-Lody协作能力对照.md)和[既有界面复用边界](../research/192-既有界面复用边界.md)。

## 1. 使用方式与信息位置

用户需要先找到工作区和原设备上的项目，再进入会话；接手工作时也需要快速发现待处理项。把这些入口放左侧，中央保留正在阅读和输入的内容，右侧保留当前项目的文件与变更，切换入口时不必重新学习消息或文件操作。

```text
┌──────────────────────────────────────────────────────────┐
│ 当前会话名称 · 原设备 / 项目 · 连接 / 接续状态       更多 │
├──────────────┬───────────────────────────┬───────────────┤
│ 账号 / 设置  │ 对话或中央文件标签        │ 文件 / 变更   │
│ 工作区切换   │                           │ ProjectDock   │
│ 搜索         │ ConversationView          │               │
│ 待接手       │                           │               │
│ 设备         │                           │               │
│  └ 项目      │                           │               │
│    └ 会话    │                           │               │
│ 共享会话     │                           │               │
└──────────────┴───────────────────────────┴───────────────┘
```

账号是普通用户，不展示岗位角色。账号入口提供当前身份、登录/退出动作和设置；设置保持居中弹窗，关闭后焦点回到入口。工作区选择限定后续设备、项目、共享会话及搜索范围。设备下列项目，项目下列该项目会话；共享会话是同一工作区中可访问会话的另一入口，同一会话按 ID 对应，不复制业务数据。左侧提供「新建会话」，会话列表空态也提供同一动作。宿主提供是否可创建及不可用原因；没有已授权目标或能力时显示原因，不自行选择默认 Agent。真实创建由 HC-202 负责，成功后由 HC-202 选中新会话；注册配置不代表 ACP 已接通。待接手使用独立入口，未接入时仅展示状态说明。接入后只显示上游明确提供给当前用户的待接手项。搜索仅过滤当前工作区已加载的设备、项目和会话，明确标注“搜索已加载内容”，清空后恢复原展开状态。

首次登录选唯一工作区；有多个时提示用户选择，不按名称猜测。进入工作区后优先恢复当前账号、服务域与工作区下仍可访问的上次会话；没有可恢复项时展示选择提示，不自动创建或选择他人的会话。选择设备或项目只展开/定位，不自动改变中央会话；明确选择会话才切换。工作区切换由宿主检查权限并隔离选择与草稿；切换失败时，仅在原身份和权限仍有效的情况下保留原上下文并提示。账号切换按 HC-194 先退出再登录：开始退出即隔离旧订阅与视图，新登录失败时保留登录错误和重试入口，不能恢复旧账号上下文；个人草稿按身份隔离。共享事件仅更新列表与状态，不触发导航选择、草稿替换或焦点转移；当前会话失权时停止提供需授权的操作并说明原因，保留未发送草稿，等待用户选择下一步。

顶栏只显示当前会话、原设备/项目、可用的连接和接续事实；其他动作放菜单。无当前会话时显示选择提示，不显示虚构上下文。接续人和待接手只消费明确上游事实，不能由设备在线、消息作者或执行状态推断。

## 2. 布局与交互

正常宽度为左导航、可伸缩中央、右项目区；左栏默认以 280 逻辑像素为设计基线，参考[旧 Web 样式](../../../packages/cli/src/web/presentation/styles.css)，不沿用旧页面整体最小宽度。中央优先保留可用阅读宽度，两侧可调整并限制最小/最大宽度，区域高度随窗口伸缩，内部独立滚动，不以固定高度挤压文件树或 Git。窗口变窄时先自动收起右侧，再收起左侧，保留中央；两侧由具名按钮临时打开为覆盖面板，关闭后焦点回到触发按钮，Escape 关闭最上层面板。变宽时恢复用户原先手动开合偏好；自动收合不覆盖该偏好。用户主动关闭面板时若焦点在其中，先移至触发按钮；尺寸变化导致收合也如此。弹窗打开时焦点进入弹窗并在其中循环，关闭恢复触发位置。阈值和尺寸在 Plan 中依据实际组件最小可用宽度确定，不能用固定像素承诺适配所有缩放。

使用 HC-205 公共主题变量与品牌/图标，浅深色均使用冷紫语义色，选中项为实心背景且与文字保持可读对比；图标与文字按同一行基线对齐。键盘可达、可见焦点，选中不只靠颜色。缩放和高窗口变化时不遮挡原生窗口按钮。

HC-208 提供导航、顶栏和布局插槽及开合行为；HC-202 负责真实数据装配、窗口拖动与可点击区域、跨区总页签顺序和焦点协调。中央使用 HC-206 的 `ConversationView`；右侧使用 HC-207 的 `ProjectDock`，中央文件继续使用 `ProjectFileTab` / `ProjectFilePanel`，由 HC-202 组合。接口见 [HC-206](HC-206-既有对话视图复用.md)、[HC-207](HC-207-文件与变更视图复用.md) 和 [UI 公开出口](../../../packages/workbench-ui/src/index.ts)。不重画头像、消息工具、输入、文件树或 Git，不把 Git 文件树搬至左侧。

## 3. 视图输入与动作

以下为组件与宿主之间的视图模型。宿主按稳定 ID 组装并负责联网与凭据。范围 `namespace/accountId/workspaceId` 隔离服务域、账号和工作区；会话及原项目另带 `conversationId/deviceId/projectId`，不按显示名或本机路径匹配。

- `NavigationView`：账号显示信息、工作区列表和当前 ID；设备及项目树；会话摘要及原设备/项目 ID；共享入口；搜索文本与已加载范围；当前会话 ID；各列表可用状态及分页是否还有更多。
- `CollaborationContextView`：当前会话标题、原设备/项目名称与连接事实；可选接续人、交接进度和待接手事实，附来源状态。缺失即不显示或标未接入，不推断。
- `LayoutView`：用户手动的左右面板偏好、当前可用宽度下的实际显示，以及中央/右侧插槽；可见状态由布局计算，不修改业务选择。
- 具名动作：`selectWorkspace(id)`、`createConversation()`、`selectConversation(id)`、`toggleDevice(id)`、`toggleProject(id)`、`setSearch(text)`、`loadMore(scope)`、`openPendingHandoffs()`、`openSettings()`、`signIn()`、`signOut()`、`setPanelOpen(side, open)`、`retry(scope)`。动作只表达用户意图；宿主返回结果或更新输入；创建需要宿主提供已授权的设备、项目和 Agent 配置，契约字段见 `CreateConversationRequest`，失败时提供可理解反馈。账号退出后的失败处理遵循上文身份隔离规则。无能力或无权限时禁用相应动作并解释，不能用空回调伪装成功。

右侧的手动开合与宽度由宿主保留一份。布局计算当前能否并排显示，以及覆盖面板的临时开合和有效宽度，再交右侧插槽渲染。用户使用项目面板的关闭和拖宽控件时，通过同一装配接点处理。临时覆盖面板收合和窗口变化保留并排布局偏好，以及已打开的文件和 Git 草稿。

现有 [身份契约](../../../packages/workbench-contracts/src/identity.ts) 提供普通用户、工作区及身份状态；[会话契约](../../../packages/workbench-contracts/src/conversation.ts) 提供会话摘要、分页与事件；[设备契约](../../../packages/workbench-contracts/src/device.ts) 提供设备连接状态、项目共享及分页。它们不等于完整导航聚合或交接接口；由 HC-202 适配，不能把 `agentConfigs` 当作已接通的 Agent 入口。真实交接与引用属于 [HC-198](../task/HC-198-会话交接与内容引用.md)，其尚未提供的字段保持未接入。ACP 的发现、配置、能力、运行及接线调试等待同事交付，受控预览不证明 ACP 可用。

## 4. 状态与使用场景

| 状态 | 用户看到的结果 |
| --- | --- |
| 加载 | 对应区域显示加载，保留已有可见内容并标明正在刷新；不把加载当空列表。 |
| 空 | 已成功加载但无条目时说明范围为空；分页未结束不能声称全部为空。 |
| 失联 | 显示连接中断及可重试入口；已有摘要如继续展示须标明可能过时，不能声称可执行。 |
| 无权 | 说明当前账号无权访问，禁用受限动作；由宿主重新校验，不泄露额外内容。 |
| 待接手 | 仅在有明确交接事实时展示，选择后由上游完成检查，不自动接管。 |
| 未接入 | 明确标识能力尚未接入，不伪造数据或可操作结果。 |

例如，用户选工作区、展开设备和项目、点选会话后，中央显示该会话，右侧显示对应原项目。收到另一个会话的新消息时只更新列表。上游提供待接手事实后列表更新，用户主动选择并通过后续授权流程才能接续。窄窗口查看文件时打开右侧覆盖面板，关闭后回到打开按钮，对话草稿保持原样。

## 5. 可观察的验收与实施顺序

受控数据下可观察账号和工作区切换、设备项目展开、会话选择、搜索范围以及事件更新时焦点保留。浅深主题下选中清晰，窄窗口可以收合并恢复焦点，既有组件能在插槽中显示，设置居中。实施阶段打开正常入口走一遍核心路径，完整场景归 HC-204。
