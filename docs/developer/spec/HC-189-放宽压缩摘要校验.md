# HC-189 放宽压缩摘要校验规格

需求来源：[Task](../task/HC-189-放宽压缩摘要校验.md)。范围已由用户选择 Pi 方案并授权执行。

## 通俗说明

模型返回可以继续工作的摘要即可，不要求它逐字遵循报告模板。程序只对可用性、来源和安全提交作硬检查，章节和自然语言风格交给模型。

当前工作投影 → 提取摘要文本 → 校验可用性和归档引用 → 计量收益 → 原子提交 → 从真实结构化状态恢复。

## 接受规则

`ContextCompactor` 是 manual、auto、overflow 的唯一入口。沿用 `_summary_text()` 的文本提取与 trim；无需新的数据类型或解析器。

| 输入结果 | 行为 |
| --- | --- |
| 非空自由文本、列表、Markdown 或中英文标题 | 继续来源与收益检查 |
| 标题缺失、改名、乱序、增加，或可选章节为空 | 不作为失败原因 |
| 正常记录 AGENTS.md、Skill、工具 schema、审批策略、系统规则 | 不以命中词语拒绝 |
| 提取后为空或仅有非文本内容 | 失败，summary_empty |
| 返回工具调用 | 失败，summary_model_tools_forbidden |
| 厂商报告 length/max_tokens/MAX_TOKENS | 失败，summary_output_truncated |
| 摘要达到既有输出 token 上限 | 失败，summary_output_limit |
| 引用输入历史中没有的 Artifact | 失败，summary_source_artifact_boundary_invalid |

提示词继续建议目标、事实、决定、改动、测试、未决事项和归档信息，但允许省略无内容章节、合并和调整标题；明确不执行工具、不增加输入之外的事实、不复制凭据或运行指令。

删除仅用于旧门槛的 `_SUMMARY_HEADINGS`、`_FORBIDDEN_SUMMARY_MARKERS` 和 `_summary_sections()`，不保留旧接受模式或配置开关。

## 不变量

- 摘要始终是历史文字，不负责决定 RuntimeExecutionPolicy、Todo、snapshot 或工具权限。
- `_validate_request()`、消息原子组与 snapshot/Thread 归属继续校验。
- 手动保留最近两轮，只要求严格缩小投影；auto/overflow 继续要求至少节省 20%。
- micro、压力水位、输入选择、预算、熔断和传输重试不变；不增加格式纠正模型调用。
- Artifact、Summary、ContextState 和 checkpoint 仍通过既有单事务提交；失败不得部分落盘或改写 Transcript。
- 不改变 Protocol、SQLite、检查点编码或 HISTORY_REWRITE_VERSION；现有合法摘要无需迁移。

## 回归与验收

参数化 fake model 覆盖三种触发、自由文本/多种章节变化/正常关键词；断言 full checkpoint、投影恢复、Transcript 保留及真实状态来源。负例覆盖空白/非文本、工具调用、各种截断元数据、输出超限及未知 Artifact，并验证无部分写入。既有收益、原子组、状态恢复与生命周期回归继续通过。

内网验收：已有足够历史的空闲 Thread 执行 /compact 后显示“上下文已压缩”，继续对话能够接续工作。不得将 fake model 的本地结果描述为内网模型验收。

## 设计依据与限制

参考规划工作区 Pi `c820aa26fe0907e053e881a957722693fc094c9c` 的 `generateSummaryWithUsage()`：从模型响应提取文本，不逐项校验章节。只借鉴格式接受原则，不复制代码。Harness 的事务、归档、收益和权限来源约束继续保留。

自由文本可能遗漏事实，固定标题齐全同样不能证明内容完整；完整 Transcript 与归档继续作为追溯依据。不增加新的模型质量评分服务。用户后续明确本轮暂不补充内容退化检查或内容重试；非空但无信息的输出仍可能通过既有来源与收益校验，作为已知内容质量限制留待真实环境验收。
